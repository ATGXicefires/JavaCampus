# 介面設計

## 原則

- **全部直角**，沒有任何圓角。
- **不加多餘的說明文字**，讓版面自己說明。沒有副標題，也沒有「點這裡開始」這類句子。
- **Q 彈的動態**：按下時壓扁（`Motion.installPress`），滑過時浮起（`Motion.hoverLift`），面板用彈簧彈入。三段可調。
- **縮放**：沿用 `Viewport`，設計尺寸 1440×900；最小 1200×720。支援 16:9 和 16:10，1K 到 2K，也要支援 Windows 的顯示縮放。
- **字體**：介面用思源黑體 TC，程式碼用 Maple Mono NF CN，手寫的筆記本、紙條、卡片用霞鶩文楷 TC（新增，OFL-1.1）。

## 畫面流程

```
標題 ──新遊戲──→ 選視角 ──→ 劇情 ⇄ 程式題
 │                         │
 ├─繼續──────────────────→ 劇情（最後玩的視角，從自動存檔繼續）
 ├─章節──→ 章節選擇 ──→ 劇情（從那一章開頭重玩）
 ├─筆記──→ 程式基礎教學筆記
 └─設定

劇情 ──@章末──→ 章末筆記本 ──→ 下一章（沒有下一章就回到標題）
劇情中可以打開：手機、文件、紀錄、筆記、設定（都是疊在上面的面板）
```

```
│                                              │
│      （作品名，暫定）                          │
│                                              │
│      繼續                                     │
│      新遊戲                                   │
│      章節                                     │
│      筆記                                     │
│      設定                                     │

```

- 沒有存檔時不顯示「繼續」。
- 「章節」在至少玩完一章後才出現。
- 播放 BGM「放學後的電腦教室」。

## 選視角 `RouteSelectView`

```
┌──────────────────────┬───────────────────────┐
│                      │                       │
│   二弘剪影（藍灰）    │    亭瑄剪影（珊瑚粉）   │
│                      │                       │
│   吳二弘              │    梁亭瑄              │
└──────────────────────┴───────────────────────┘
```

- 左右對分，滑過的那一半變亮、放大一點，另一半變暗。
- 點選後會先確認一次。那個視角已經有存檔的話，確認文字會寫明「會覆蓋該視角的進度」。

## 劇情畫面 `StoryView`

```
┌──────────────────────────────────────────────┐
│                                   [自動][快進]│ ← 快捷列
│                                   [紀錄][筆記]│
│         角色（左）     角色（中）    角色（右） │
│                                              │
│ ┌────────┐                                   │
│ │ 梁亭瑄 │ ← 名牌，底色是角色代表色             │
│ ├────────┴────────────────────────────────┐ │
│ │ 「學長，你在跟我說外星語嗎？」              │ │
│ │                                     ▼   │ │
│ └─────────────────────────────────────────┘ │
└──────────────────────────────────────────────┘
```

- **圖層**，由下到上：背景、濾鏡（夕陽、回憶）、雨等粒子、角色、特效（閃白、暈影）、對話框、快捷列、AP/TP 回饋。
- **對話框**：佔畫面下方約四分之一，半透明的 `c-panel`。
  - 台詞：有名牌，文字逐字出現，配角色嗶聲。
  - 旁白：沒有名牌，文字置中。
  - 內心 OS：沒有名牌，文字用斜體和 `c-muted`，前後加全形括號。
  - 舞台指示（單獨一行的「（⋯⋯）」）：當作旁白顯示。
  - 動作描述（`亭瑄：（瞪）「你再說一次？」`）：動作用較小的字顯示在台詞前面。
- **選項**：畫面中央直排，一個選項一列，彈入時配「選項出現」音效。對話框會先收起。
- **AP/TP 回饋**：選完後從右下角飄起，不顯示數字。
- **快捷列**：自動、快進、紀錄、筆記，四個文字按鈕，沒有圖示說明。設定用 Esc 打開。
- 前進的方式：點畫面、空白鍵、Enter。文字還在出現時，第一次按會先把整句顯示出來。

## 手機 `PhoneOverlay`

```
              ┌─────────────────┐
              │ 小芸             │
              ├─────────────────┤
              │ ┌──────────┐    │
              │ │那個學長長怎樣？│ ← 對方：靠左、白底
              │ └──────────┘    │
              │    ┌──────────┐ │
              │    │很機車！講話超冷！│ ← 自己：靠右、代表色底
              │    └──────────┘ │
              │ ┌────────────┐  │
              │ │📄 程式基礎教學筆記.pdf│ ← 附件，點了打開文件
              │ └────────────┘  │
              └─────────────────┘
```

- 直立的手機框從畫面右側滑入，左側的劇情畫面變暗。
- 介面是原創的，不模仿 LINE 的外觀。劇本裡角色可以照常說「LINE」。
- 對方回訊前先出現「⋯」。前進方式和對話框相同。
- 通話模式（`@電話`）：手機框顯示對方名字和通話時間，台詞照常出現在對話框。

## 文件 `DocumentView`

所有「可以打開來看的東西」共用一個檢視器，依種類換外觀：

| 外觀 | 用在 | 樣式 |
|---|---|---|
| PDF | 程式基礎教學筆記 | 白紙、頁碼、左右翻頁 |
| 術語文件 | 第一章二弘的專題規劃 | 密密麻麻的文字和方框圖，故意難讀 |
| 程式檔 | README.md、txt、Easter egg | 深色底、等寬字，像在編輯器裡打開 |
| 手寫 | 紙條、聖誕卡、二弘的筆記本 | 米色紙、手寫字體，可以有一點傾斜 |

- 關閉方式：點外面、Esc，或按右上角的 ✕。
- 文件內容放在 `story/scripts/docs/<id>.md`，第一行寫外觀。

## 程式題 `LessonView`

由現有的 `WorkspaceView` 改造。

```
┌───────────────────────────────────────────────────────────┐
│ 有名字的盒子                                [提示] [設定]   │
├──────────────┬──────────────────────────────┬─────────────┤
│ 1 ✓ 宣告盒子  │  1  String laptop = "小白";   │ 筆記        │
│ 2 ● 放進數字  │  2                           │ ・變數是⋯   │
│ 3   又抽到一個 │                              │ ・int 與⋯   │
│              │  [▶ 執行]  [完成]  [重設]      │             │
│ 說明⋯⋯       ├──────────────────────────────┤ 可用資料    │
│ ┌ ─ ─ ─ ─ ┐  │ 主控台                        │             │
│  預期的樣子    │ 小白                          │  ┌───────┐  │
│ └ ─ ─ ─ ─ ┘  │                              │  │ 二弘： │  │
│              │                              │  │⋯⋯恭喜。│ ← 搭檔的反應
└──────────────┴──────────────────────────────┴──┴───────┴──┘
```

- 拿掉「← 案件列表」和「結案報告」。程式題是從劇情進來的，中途要離開用 Esc → 設定 → 回到標題。
- 右側原本的「證物」換成「筆記」，顯示這一題相關的條目。「可用資料」保留。
- 按鈕「提交推理」改成「完成」。
- 「推理成立／不成立」的橫幅改成搭檔的反應氣泡：學妹視角是二弘，學長視角是二弘自己的 OS，或在場的亭瑄。台詞放在 `lessons/reactions.json`。
- 過關後出現「繼續」，按下回到劇情的下一行。
- 已經完成的題目（重玩章節時）一進來就是完成狀態，保留之前的程式碼，可以直接按「繼續」。
- 編輯器、主控台、錯誤卡片、四層提示、自動存程式碼、預先檢查，全部沿用現有功能。

## 程式基礎教學筆記 `HandbookView`

```
┌──────────────┬───────────────────────────────┐
│ 第一章        │ 變數是有名字的盒子              │
│ ・讓電腦說話  │                               │
│ ・字串要用⋯   │ 想像你有一個盒子，上面貼著       │
│ ・變數是⋯ ◀  │ 名字「gacha」，裡面放著 7。     │
│ ・int 與⋯     │                               │
│ 第二章        │   int gacha = 7;              │
│ ・（未解鎖）   │                               │
└──────────────┴───────────────────────────────┘
```

- 未解鎖的條目只顯示「⋯⋯」。
- 從標題、劇情快捷列、程式題右側都能打開。
- 內容依視角共用。兩個視角解鎖的條目合併計算，因為同一份 PDF 本來就是同一份。

## 對話紀錄 `BacklogOverlay`

- 由下往上捲，最新的在最下面。名牌顏色和對話框相同，內心 OS 用斜體。
- 選過的選項顯示為「→ 選項文字」。
- 只記錄這次遊玩的這一章，不存檔。

## 章節選擇 `ChapterSelectView`

```
┌──────────────────────────────────────────────┐
│  [學長] [學妹]                ← 視角切換        │
│                                              │
│  01 編譯錯誤        ← 玩過的章節                │
│  02 Hello World    ← 還沒玩到或還沒寫：變暗加鎖  │
│  ⋯                                           │
└──────────────────────────────────────────────┘
```

- 每個視角各自計算玩到哪一章。
- 點選玩過的章節會先確認：「從這一章開頭重玩，之後的進度以這次為準。」

## 章末 `ChapterEndView`

```
┌──────────────────────────────────────────────┐
│   ┌──────────────────────────────┐           │
│   │ 二弘的筆記本（手寫字）           │           │
│   │                              │           │
│   │ Day 1：教會梁同學什麼是變數。    │ ← 逐字寫出 │
│   │                              │           │
│   └──────────────────────────────┘           │
│                                              │
│   專題進度  ███░░░░░░░░░░░░░░░░               │
│                                     [繼續]   │
└──────────────────────────────────────────────┘
```

- 筆記本的內容寫在劇本的 `@章末` 指令裡。學長視角是二弘的筆記本（大綱的進度紀錄），學妹視角是亭瑄自己的筆記本，文字和紙的樣式都不同。
- 專題進度條從上一章的數值長到這一章。
- 「繼續」進入下一章。第一章版本沒有下一章，會回到標題。

## 設定 `SettingsView`

沿用現有的版面和元件（`segmented`、`slider`、`onOff`）：

| 分類 | 項目 |
|---|---|
| 顯示 | 全螢幕、介面大小 90／100／110／120% |
| 文字 | 程式字體大小、劇情速度（慢／中／快／立即）、自動播放間隔（短／中／長）、快進範圍（已讀／全部） |
| 動效 | Q 彈／一般／關閉 |
| 聲音 | 主音量、音樂、音效、環境音、角色嗶聲、打字音效 |
| 進度 | 重設學長視角、重設學妹視角，都會先確認 |
| — | 回到標題（從劇情或程式題打開設定時才出現） |

## 快捷鍵

| 按鍵 | 作用 |
|---|---|
| 點擊、空白鍵、Enter | 前進；文字還在出現時先顯示整句 |
| 按住 Ctrl | 快進 |
| A | 自動播放開關 |
| 滾輪往上、L | 對話紀錄 |
| H | 筆記 |
| 1～4 | 選擇對應的選項 |
| Esc | 關閉最上層的面板；沒有面板時打開設定 |
| F11 | 全螢幕 |
| Ctrl+Enter、Ctrl+Shift+Enter | 程式題的執行、完成（現有功能） |
