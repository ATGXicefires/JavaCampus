# 介面設計

## 原則

- **全部直角**，沒有任何圓角。例外是劇情裡的手機：外殼照 iPhone 畫，機身、螢幕和動態島保留實物的圓角。
- **不加多餘的說明文字**，讓版面自己說明。沒有副標題，也沒有「點這裡開始」這類句子。
- **Q 彈的動態**：按下時壓扁（`Motion.installPress`），滑過時浮起（`Motion.hoverLift`），面板用彈簧彈入。三段可調。
- **縮放**：沿用 `Viewport`，設計尺寸 1440×900；最小 1200×720。支援 16:9 和 16:10，1K 到 2K，也要支援 Windows 的顯示縮放。
- **字體**：介面用思源黑體 TC，程式碼用 Maple Mono NF CN，手寫的筆記本、紙條、卡片用霞鶩文楷 TC（新增，OFL-1.1）。

## 畫面流程

```
標題 ──新遊戲──→ 選視角 ──→ 劇情 ⇄ 程式題
 │                         │
 ├─繼續──────────────────→ 劇情（最後玩的視角，從自動存檔繼續）
 ├─章節──→ 章節選擇 ──→ 劇情（從那一章開頭重玩）
 ├─筆記──→ 程式基礎教學筆記
 └─設定

劇情 ──@章末──→ 章末筆記本 ──→ 下一章（沒有下一章就回到標題）
劇情中可以打開：手機、文件、紀錄、筆記、設定（都是疊在上面的面板）
```

## 劇情畫面 `StoryView`

```
┌──────────────────────────────────────────────┐
│        [便利貼] [便利貼]   ← 選項              │
│         角色（左）     角色（中）    角色（右） │
│                                              │
│ ╭梁亭瑄╮ ← 紙膠帶名牌，角色代表色               │
│ ┌─┬───────────────────────────────────────┐ │
│ │●│ 「學長，你在跟我說外星語嗎？」  ← 橫線紙  │ │
│ │●│                                     ▼ │ │
│ └─┴───────────────────────────────────────┘ │
│   [自動 快進 跳過 紀錄 隱藏 筆記 設定] ← 快捷選單│
└──────────────────────────────────────────────┘
```

- **圖層**，由下到上：背景、濾鏡（夕陽、回憶）、雨等粒子、角色、特效（閃白、暈影）、對話框、選項、手機、快捷選單、AP/TP 回饋。
- **對話框**：筆記本的一頁（`NotebookPage`）：米色紙、淡藍橫線、粉紅邊線、活頁孔，字坐在橫線上，高度以整行為單位長。
  - 台詞：有紙膠帶名牌，文字逐字出現，配角色嗶聲。整句出現後右下角閃 ▼；自動播放時變 ▶，快進時變 ▶▶。
  - 旁白：沒有名牌。
  - 內心 OS：沒有名牌，用手寫字（霞鶩文楷）和藍筆色，前後加全形括號。
  - 舞台指示（單獨一行的「（⋯⋯）」）：當作旁白顯示。
  - 動作描述（`亭瑄：（瞪）「你再說一次？」`）：動作用較小的字顯示在台詞前面。
- **選項**：便利貼，四種顏色輪流、微微歪斜，一排排在筆記本上方，滑過時浮起轉正。對話框留著，看得到在回哪一句。
- **AP/TP 回饋**：選完後從右下角飄起，不顯示數字。
- **快捷選單**：跨在筆記本右下緣的深色標籤條：自動、快進、跳過、紀錄、隱藏、筆記、設定。手機聊天時筆記本收起，選單還在原位。
- **跳過**：先確認，再一路跳到下一個選項、程式題或章末，舞台直接換成那時候的樣子，然後用面板列出劇本裡的 `@簡介`，按「繼續」才出現選項或進入程式題。跳過的台詞不算已讀、不進對話紀錄，路上的文件也不會打開。只有停在台詞上時能按。
- **隱藏介面**：右鍵、H 或「隱藏」收起筆記本、選單和選項；之後任何點擊、按鍵或滾輪只會叫回介面，不會往下走。
- 前進的方式：點畫面、空白鍵、Enter、滾輪往下。文字還在出現時，第一次按會先把整句顯示出來。

```
              ╭─────────────────╮
              │ 16:03 (▬▬▬) ▂▄▆ ▭│ ← 狀態列：時間、動態島、訊號、Wi-Fi、電池
              │      小芸        │
              ├─────────────────┤
              │ ┌──────────┐    │
              │ │那個學長長怎樣？│ ← 對方：靠左、白底
              │ └──────────┘    │
              │    ┌──────────┐ │
              │    │很機車！講話超冷！│ ← 自己：靠右、代表色底
              │    └──────────┘ │
              │ ┌────────────┐  │
              │ │📄 程式基礎教學筆記.pdf│ ← 附件，點了打開文件
              │ └────────────┘  │
              │      ▬▬▬▬       │ ← 底部橫條

```

- 直立的手機框從畫面右側滑入，左側的劇情畫面變暗。
- 外殼是 iPhone：原色鈦金屬邊框、黑邊、圓角螢幕、動態島、側鍵、底部橫條。狀態列的時間是劇情裡的時間，跟著背景的變體走（白天 12:20、傍晚 17:35、雨 17:50、雨夜 19:40、夜 22:10），不用玩家電腦的時間。不畫品牌標誌。
- 聊天介面是原創的，不模仿 LINE 的外觀。劇本裡角色可以照常說「LINE」。
- 對方回訊前先出現「⋯」。前進方式和對話框相同。
- 通話模式（`@電話`）：手機框顯示對方名字和通話時間，台詞照常出現在對話框。

## 文件 `DocumentView`

所有「可以打開來看的東西」共用一個檢視器，依種類換外觀：

| 外觀 | 用在 | 樣式 |
|---|---|---|
| PDF | 程式基礎教學筆記 | 白紙、頁碼、左右翻頁 |
| 術語文件 | 第一章二弘的專題規劃 | 密密麻麻的文字和方框圖，故意難讀 |
| 程式檔 | README.md、txt、Easter egg | 深色底、等寬字，像在編輯器裡打開 |
| 手寫 | 紙條、聖誕卡、二弘的筆記本 | 米色紙、手寫字體，可以有一點傾斜 |

- 關閉方式：點外面、Esc，或按右上角的 ✕。
- 文件內容放在 `story/scripts/docs/<id>.md`，第一行寫外觀。

## 程式題 `LessonView`

三個區塊各是一張卡片，中間留縫，標題列等高，配色整個畫面一致（設定裡切亮色／暗色）。

```
┌───────────────────────────────────────────────────────────┐
│ 有名字的盒子                                [提示] [設定]   │
├────────────┐ ┌───────────────────────────┐ ┌─────────────┤
│ 題目        │ │ 片段.jsh │ Main.java │ ＋  │ │ 筆記│可用資料│
│ 1 ✓ 宣告盒子│ │  1  String laptop = "小白";│ │ 變數是⋯   ▸ │
│ 2 ● 放進數字│ │                           │ │ 一句重點     │
│ ┃ 重點一句  │ │ [▶ 執行] [完成] [重設]  [繼續]│ │ int 與⋯   ▸ │
│ ┌ ─ ─ ─ ┐  │ └───────────────────────────┘ │             │
│  預期的樣子 │ ┌───────────────────────────┐ │ ┌─────────┐ │
│ └ ─ ─ ─ ┘  │ │ 執行結果                    │ │ │ 二弘：   │ │
│ ▸ 完整說明  │ │ 小白                        │ │ │⋯⋯恭喜。 │ │ ← 搭檔的反應
└────────────┘ └───────────────────────────┘ └─┴─────────┴─┘
```

- **由簡入繁**：左邊先給一句重點（`goal`）和預期的樣子，背景和寫法收在「完整說明」，點了才展開。右邊的筆記平常只有標題和一句重點（`summary`），滑鼠停一下旁邊浮出完整內容，點一下在原地展開。
- **分頁**：寫片段的題目只有「片段.jsh」一個分頁；完整程式每個檔案一個分頁，可以用「＋」新增類別，自己加的檔案可以刪。錯誤卡片會標出檔名並跳到那個分頁。
- **自動完成**：打字時列出關鍵字、常用寫法、宣告過的變數和題目資料，打「.」列出成員；選到的那一項附一句白話說明。
- **成對符號**：打 `(`、`[`、`{`、`"`、`'` 會順便補上右邊那個，游標停在中間；再打右邊那個只是跳過去，在空的一對中間按 Backspace 兩邊一起刪，`{` 之後按 Enter 會把 `}` 推到下一行。字串和註解裡不補。
- **說明可複製**：左邊題目區的字（重點、預期的樣子、完整說明、過關後的話）、右邊的筆記卡片和提示抽屜，都可以用滑鼠拖曳選取，跨段也行，按 Ctrl + C 或右鍵「複製」。筆記卡片拖曳是選字，不拖直接點才是展開或收合。
- 按鈕不搶焦點，按了「執行」可以直接繼續打字。
- 搭檔的反應氣泡：學妹視角是二弘，學長視角是二弘自己的 OS，或在場的亭瑄。台詞放在 `lessons/reactions.json`。
- 左邊步驟清單裡已完成的題目，編號換成 ✓，標題加刪除線。
- 過關後出現「繼續」，按下回到劇情的下一行。已經完成的題目（重玩章節時）一進來就是完成狀態，保留之前的程式碼。

## 程式基礎教學筆記 `HandbookView`

```
┌──────────────┬───────────────────────────────┐
│ 第一章        │ 變數是有名字的盒子              │
│ ・讓電腦說話  │                               │
│ ・字串要用⋯   │ 想像你有一個盒子，上面貼著       │
│ ・變數是⋯ ◀  │ 名字「gacha」，裡面放著 7。     │
│ ・int 與⋯     │                               │
│ 第二章        │   int gacha = 7;              │
│ ・（未解鎖）   │                               │
└──────────────┴───────────────────────────────┘
```

- 未解鎖的條目只顯示「⋯⋯」。
- 從標題、劇情快捷列、程式題右側都能打開。
- 內容依視角共用。兩個視角解鎖的條目合併計算，因為同一份 PDF 本來就是同一份。

## 對話紀錄 `BacklogOverlay`

- 由下往上捲，最新的在最下面。名牌顏色和對話框相同，內心 OS 用斜體。
- 選過的選項顯示為「→ 選項文字」。
- 每一句右邊有回去的箭頭。確認後從那一句重新播：數值、旗標、舞台和手機都回到那一句剛出現時的樣子，之後做過的選擇取消。畫面上正在看的最後一句沒有箭頭；演暗場、等待這類指令時也不能回去。
- 只記錄這次遊玩的這一章，不存檔。

## 章節選擇 `ChapterSelectView`

```
┌──────────────────────────────────────────────┐
│  [學長] [學妹]                ← 視角切換        │
│                                              │
│  01 編譯錯誤        ← 玩過的章節                │
│  02 Hello World    ← 還沒玩到或還沒寫：變暗加鎖  │
│  ⋯                                           │
└──────────────────────────────────────────────┘
```

- 每個視角各自計算玩到哪一章。
- 玩到章末的章節，章名加刪除線。
- 點選玩過的章節會先確認：「從這一章開頭重玩，之後的進度以這次為準。」

```
┌──────────────────────────────────────────────┐
│   ┌──────────────────────────────┐           │
│   │ 二弘的筆記本（手寫字）           │           │
│   │                              │           │
│   │ Day 1：教會梁同學什麼是變數。    │ ← 逐字寫出 │
│   │                              │           │
│   └──────────────────────────────┘           │
│                                              │
│   專題進度  ███░░░░░░░░░░░░░░░░               │
│                                     [繼續]   │
└──────────────────────────────────────────────┘
```

- 筆記本的內容寫在劇本的 `@章末` 指令裡。學長視角是二弘的筆記本（大綱的進度紀錄），學妹視角是亭瑄自己的筆記本，文字和紙的樣式都不同。
- 專題進度條從上一章的數值長到這一章。
- 「繼續」進入下一章。第一章版本沒有下一章，會回到標題。

## 設定 `SettingsView`

沿用現有的版面和元件（`segmented`、`slider`、`onOff`）：

| 分類 | 項目 |
|---|---|
| 顯示 | 全螢幕、視窗大小（最大化或 16:9／16:10 的預設尺寸，放不進螢幕的不列）、介面大小 90／100／110／120% |
| 程式 | 字型（附帶的字型加上系統裡的等寬字型）、字體大小、配色（亮色／暗色） |
| 劇情 | 文字速度（慢／中／快／立即）、自動播放間隔（短／中／長）、快進範圍（已讀／全部） |
| 動效 | Q 彈／一般／關閉 |
| 聲音 | 主音量、音樂、音效、環境音、角色嗶聲、打字音效 |
| 進度 | 重設學長視角、重設學妹視角，都會先確認 |
| — | 回到標題（從劇情或程式題打開設定時才出現） |
| — | 恢復預設：設定全部回到預設值，先確認；進度不受影響 |

## 快捷鍵

| 按鍵 | 作用 |
|---|---|
| 點擊、空白鍵、Enter、滾輪往下 | 前進；文字還在出現時先顯示整句 |
| 按住 Ctrl | 快進 |
| A | 自動播放開關 |
| 滾輪往上、L | 對話紀錄 |
| H、右鍵 | 隱藏介面 |
| N | 筆記 |
| 1～4 | 選擇對應的選項 |
| Esc | 關閉最上層的面板；沒有面板時打開設定 |
| F11 | 全螢幕 |
| Ctrl+Enter、Ctrl+Shift+Enter | 程式題的執行、完成（現有功能） |
| Ctrl+Space | 程式題編輯器手動叫出自動完成；清單開著時 ↑↓ 選、Enter／Tab 填入、Esc 收起 |
