# 程式教學設計

## 原則

- **對象是完全沒寫過程式的人。** 不管選哪個視角，玩完七章都會學到同一組 Java 概念。
- **題目就是劇情事件。** 每一題都發生在某個場景裡：亭瑄照著 PDF 練習、二弘熬夜改筆記、兩人把各自寫的方法接起來。題目做完，劇情往下走，專題進度也跟著前進。
- **每一題都用輸出或數值驗證。** 沿用現有的 `Verifier`：把玩家的執行結果和參考解答比較，並換幾組資料再跑一次。引擎不檢查「有沒有用 for」這類寫法，所以題目要設計成「不用那個寫法就很難得到正確結果」，例如要印 100 行。
- **寫程式的表現不影響 AP/TP。** 數值只由劇情選擇決定，用了幾次提示都不影響結局。
- **程式形式漸進：** 第 1～3 章寫片段（snippet），第 4～5 章寫方法（method），第 6 章後半到第 7 章寫完整的 `Main.java`（program）。

## 兩個視角的練法

| | 學妹視角（梁亭瑄） | 學長視角（吳二弘） |
|---|---|---|
| 題型 | **寫**：從空白或幾行註解開始寫 | **修**：起始碼是亭瑄寫錯的程式，要修到正確<br>**教**：寫給新手看的教學範例，輸出要是指定的白話文字 |
| 誰在旁邊 | 二弘（反應氣泡是他的吐槽和小聲的「⋯⋯恭喜」） | 一個人寫的時候是他自己的內心 OS；亭瑄在場時是她的反應 |
| 重玩的意義 | 先玩學妹再玩學長：換成「修別人的錯」來複習 | 先玩學長再玩學妹：換成「自己從零寫」來複習 |

同一章的兩個視角涵蓋**同一組概念**，只是題型不同。

| 層 | 學妹視角 | 學長視角 |
|---|---|---|
| 提點 | 二弘的短句（「分號。」「⋯⋯引號是半形。」） | 二弘腦中的術語版（「println 是 PrintStream 的方法⋯⋯」） |
| 白話 | 「程式基礎教學筆記」裡的比喻 | 他把術語改寫成的白話 |
| 骨架 | 挖空的範例（`____`） | 同左 |
| 答案 | 參考解答 | 同左 |

## 第二～七章題目草案

這些是方向，寫到那一章時再和劇本一起細修。

### 第二章「Hello World」
- 學妹：
  - Day1「int 是什麼」：宣告 int、double、String、boolean，做加減乘除。
  - Day3「蠢事做一百遍」：用 for 印出指定次數，次數由題目給的變數決定（換一組資料也要對）。
  - Day5「梁亭瑄天才！」：自己從零寫出第一個完整的小程式，要用到字串串接和 for。
- 學長：
  - 修她的型別錯誤：`int x = 3.5;`、字串加數字的順序。
  - 修她的 for 迴圈：`i <= 100` 會多跑一次。
  - 簡報的技術規格表：用 for 和串接印出對齊的表格。

### 第三章「例外處理」
- 學妹：段考成績陣列（索引、走訪、平均）；看懂 `ArrayIndexOutOfBoundsException` 並修好；用 else if 判斷成績等第。
- 學長：
  - 爆發場景：把她的成績程式整個重寫，題目本身就是劇情裡那段「全部重寫」。
  - 冷戰：寫「段考筆記.zip」裡的等第判斷，處理除以零、處理 `Integer.parseInt` 讀到不是數字的字串。

### 第四章「共同開發」
- 學妹：`static String scoreLine(String name, int score)` 一類的排版方法，用 `repeat` 畫進度條，用陣列處理五種雞蛋糕口味。
- 學長：後端的統計方法（例如 `static int total(int[] counts)`），再呼叫她寫的方法把結果印出來。這題的重點是「方法簽章就是兩人的約定」。

### 第五章「壓力測試」
- 學妹：`static boolean isPass(int score)`，測 59、60、61 三個邊界；`static int max(int[] a)`。每題都用多組資料驗證，就像「壓力測試」。
- 學長：技能檢定練習題（判斷閏年、找質數之類的丙級題型）；找出紙條上的錯。

> **待決定：** 大綱寫紙條有兩個錯，「分號用了全形、return 後面多了空格」。但 `return` 後面有空格在 Java 不是錯，程式照樣能編譯。遊戲裡第二個錯建議改成真的會編譯失敗的寫法，例如 `Return`（大寫）或 `retrun`（打錯字）。第五章章末二弘那句「分號要用半形的」不用改。

### 第六章「無限迴圈」
- 學妹：從聊天紀錄的字串陣列裡數出「學長」出現了幾次，答案是 478，也就是小芸統計的那個數字。先用 for 寫一次，再改成 while。
- 學長：
  - 倒數計時器 `while (days > 0)`。
  - 阿成的玩笑 `while(true)`：先讓玩家實際碰到逾時，再用 break 停下來。
  - Easter egg：`static String easterEgg(String input)`，輸入特定字串才回傳那段話。
  - 聖誕禮物：`class Gift`，從這裡開始寫完整檔案。

### 第七章「Release」
- 學妹：用多個類別組出專題發表的 UI 流程（`import java.util.ArrayList`、`public class Main`、`main`）。
- 學長：整合專題後端，把 Easter egg 接到程式裡。
- 結局小題（依結局不同）：
  - True End：學妹視角要讀懂二弘的程式碼，找出觸發 Easter egg 的那句輸入。
  - Good End：在 txt 裡回覆 `true`。
  - Comedy Bad End：`System.out.println("謝謝");`。

### 引擎限制
- 沙盒目前不能讀 stdin。第 6、7 章的 Easter egg 改用「方法參數」觸發。真的需要 `Scanner` 時，再到 `Sandbox` 加 `in(...)`，等做到那兩章再處理。
- 第六章的無限迴圈直接用沙盒現有的 3 秒逾時和 `Diagnostics.timeout` 的訊息來教。

## 第一章題目細節

第一章的概念分成五組，兩個視角都會全部碰到：

| 代號 | 概念 | 學妹在哪一題 | 學長在哪一題 |
|---|---|---|---|
| C1 | `System.out.println`、字串、分號 | k1 | s1 |
| C2 | 全形半形、看懂編譯錯誤 | k1（打字時自然會碰到） | s3 |
| C3 | 宣告變數 String / int | k2 | s1 |
| C4 | 指定（改變盒子裡的東西） | k2 | s1 |
| C5 | boolean、if、if-else | k3 | s2 |

### 學妹視角

**`ch01-k1`「這是 Java。」**：場景 2，第一次討論，電腦教室。
二弘打開範例叫她跑跑看。她一改就出現紅字，二弘的解釋越講越技術。這題做完，劇情接到她爆發的那一幕。
1. 起始碼是 `System.out.println("Hello, World");`。改成印出 `學長，你在說外星語嗎？`（比對輸出）。
2. 再寫一行，印出兩行：`梁亭瑄`、`資訊科一年級`。學到「一個 println 印一行」（比對輸出）。
- 解鎖筆記：讓電腦說話、字串要用半形雙引號、每句結尾的分號、全形與半形、看懂紅字。

**`ch01-k2`「有名字的盒子」**：場景 3，PDF 第 2 頁。
1. 宣告 `String laptop = "小白";`（比對數值 `laptop`）。這是她的萬物命名癖：筆電叫小白。
2. 宣告 `int gacha = 7;`，再用 `System.out.println(gacha);` 印出來（比對輸出和數值）。
3. 又抽到一個：寫 `gacha = 8;`，再印一次，輸出會是 7 和 8 兩行（比對輸出）。
- 解鎖筆記：變數是有名字的盒子、int 與 String、改變盒子裡的東西。

**`ch01-k3`「如果有滷肉飯」**：場景 3，PDF 第 3 頁。
題目提供 `boolean hasLuRouFan = true;`，驗證時會換成 `false` 再跑一次。
1. 只寫 `if`：有滷肉飯就印 `吃滷肉飯`。
2. 補上 `else`：否則印 `吃便當`。
- 解鎖筆記：if-else 就是選午餐。

### 學長視角

**`ch01-s1`「改寫術語文件」**：場景 2，學長獨有。亭瑄走了，他一個人留在教室，寫了又刪。
1. 起始碼是他原本的術語版範例，內容是印出 `println 會呼叫 PrintStream 的 println 方法`。改成白話版，印出 `電腦會把引號裡的字，原封不動印出來`（比對輸出）。
2. 盒子範例：`String box = "扭蛋";`，再印出來（比對輸出和數值）。範例會用扭蛋，是因為他注意到她的書包了，只是假裝沒看到。
3. `int gacha = 7;` 印出來，再改成 `gacha = 8;` 印一次。他數過她書包上的扭蛋，自己覺得這件事不能讓任何人知道（比對輸出）。
- 解鎖筆記：讓電腦說話、字串要用半形雙引號、每句結尾的分號、變數是有名字的盒子、int 與 String、改變盒子裡的東西。

**`ch01-s2`「滷肉飯比喻」**：場景 3，學長獨有。他打開新文件「程式基礎教學筆記」。
題目一樣提供 `boolean hasLuRouFan`，會換值再驗證。
1. 只寫 `if`。
2. 補上 `else`。
- 解鎖筆記：if-else 就是選午餐。

**`ch01-s3`「她照抄的程式」**：場景 4，學長版。亭瑄說：「我照你的 PDF 打了，可是一直紅字。」
1. 起始碼是她打的滷肉飯程式，裡面有全形分號 `；`、全形引號 `「」`、小寫的 `system`、少一個分號。修到能跑，印出 `吃滷肉飯`。
2. 起始碼是她打的盒子程式：`String laptop = "小白"` 少分號，`System.out.println(Laptop);` 大小寫不對。修到印出 `小白`。
- 解鎖筆記：全形與半形、看懂紅字。

這些錯誤現有的 `Diagnostics` 都已經有繁中說明：全形符號、找不到名稱並提示大小寫、缺分號。

## 程式基礎教學筆記

遊戲內的參考手冊就是二弘在第一章傳給亭瑄的那份 PDF。條目隨程式題解鎖，每條都用他寫的生活化比喻。True End 會用到的「最後一頁備註」預留位置，第一章不顯示。

| 章 | 條目 |
|---|---|
| 1 | 讓電腦說話（println）、字串要用半形雙引號、每句結尾的分號、全形與半形、看懂紅字、變數是有名字的盒子、int 與 String、改變盒子裡的東西、if-else 就是選午餐 |
| 2 | 型別是盒子的尺寸、四則運算與 `%`、字串串接、for 是把同一件事做 N 遍 |
| 3 | 陣列是一排置物櫃、索引從 0 開始、例外是程式在執行時跌倒、try-catch 是先準備好接住 |
| 4 | 方法是分工、參數是交給對方的東西、回傳值是對方交回來的東西 |
| 5 | boolean 方法、邊界值、測資 |
| 6 | while、無限迴圈、break、類別是設計圖、物件是照設計圖做出來的東西 |
| 7 | import、完整的 Main.java、ArrayList |
