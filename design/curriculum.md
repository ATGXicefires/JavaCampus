# 程式教學設計

## 原則

- **對象是完全沒寫過程式的人。** 不管選哪個視角，玩完十二章都會學到同一組 Java 概念。
- **一章一組新概念，不急著塞。** 本篇教到物件導向和集合；更進階的留給大學 DLC（見最後的路線圖）。
- **題目就是劇情事件。** 每一題都發生在某個場景裡：亭瑄照著 PDF 練習、二弘熬夜改筆記、兩人把各自寫的方法接起來。題目做完，劇情往下走，專題進度也跟著前進。
- **每一題都用輸出或數值驗證。** 沿用現有的 `Verifier`：把玩家的執行結果和參考解答比較，並換幾組資料再跑一次。引擎不檢查「有沒有用 for」這類寫法，所以題目要設計成「不用那個寫法就很難得到正確結果」，例如要印 100 行。
- **寫程式的表現不影響 AP/TP。** 數值只由劇情選擇決定，用了幾次提示都不影響結局。
- **程式形式漸進：** 第 1～3 章寫片段（snippet），第 4～5 章寫方法（method），第 6～9 章寫類別（class，還是片段，只是在片段裡宣告類別），第 10～12 章寫完整的多檔案程式（program）。
- **題量：** 第一章兩個視角各 3 題；第 2～11 章各 4～5 題，跟著學校行事曆放複習題（段考、期末）；第 12 章各 3 題，另有結局小題。

## 兩個視角的練法

| | 學妹視角（梁亭瑄） | 學長視角（吳二弘） |
|---|---|---|
| 題型 | **寫**：從空白或幾行註解開始寫 | **修**：起始碼是亭瑄寫錯的程式，要修到正確<br>**教**：寫給新手看的教學範例，輸出要是指定的白話文字<br>**自己**：他自己的事，例如練術科、改寫阿嬤的記帳程式、寫專題的後端 |
| 誰在旁邊 | 二弘（反應氣泡是他的吐槽和小聲的「⋯⋯恭喜」） | 一個人寫的時候是他自己的內心 OS；亭瑄在場時是她的反應 |
| 重玩的意義 | 先玩學妹再玩學長：換成「修別人的錯」來複習 | 先玩學長再玩學妹：換成「自己從零寫」來複習 |

同一章的兩個視角涵蓋**同一組概念**，只是題型不同。

## 第二～十二章的題目

每一題的場景、步驟、驗證方式和解鎖的筆記，寫在 `story/detail/chapter-02.md`～`chapter-12.md` 的「程式題」（細綱，待審）。這一節原本的題目方向已經併進細綱，主要的改動：

- 補了前置概念：第二章的比較運算子和 `i++`／`+=`、第四章的 `equals`、第六章的 `null`、第七章的 `static final`。
- 題量擴充成每章兩個視角各 4～5 題，加上段考、期末的複習題，和第十一章「一年的 bug」。
- 第五章紙條的第二個錯，草案改成 `Return`：她把程式寫成英文句子，開頭習慣大寫。章末那句「分號要用半形的」不用改。
- True End 的「讀懂二弘的程式碼，找出觸發 Easter egg 的那句輸入」移到第十一章告白那一夜；第十二章 True End 改成她終於看得懂術語文件。

### 引擎限制
- 沙盒目前不能讀 stdin。第 11、12 章的 Easter egg 改用「方法參數」觸發。`Scanner` 留到大學 DLC，到時候再到 `Sandbox` 加 `in(...)`。
- 第十一章的無限迴圈直接用沙盒現有的 3 秒逾時和 `Diagnostics.timeout` 的訊息來教。
- 第 6～9 章在片段裡宣告類別。沙盒跑的是 JShell，片段本來就能宣告類別，不用新的執行模式。驗證時比對 `new Item("小白", "筆電").name` 這種運算式的值，或比對輸出。
- 完整程式（第 10～12 章）不吃題目變數，要換資料驗證時，改用方法呼叫當隱藏測資，例如 `Main.count(…)`。
- 這次細化發現的其他引擎需求（`Diagnostics` 缺的繁中說明、要先確認 JShell 會擋 private 存取等），整理在 `story/detail/README.md` 的「引擎需求」。

第一章的概念分成五組，兩個視角都會全部碰到：

### 學妹視角

**`ch01-k1`「這是 Java。」**：場景 2，第一次討論，電腦教室。
二弘打開範例叫她跑跑看。她一改就出現紅字，二弘的解釋越講越技術。這題做完，劇情接到她爆發的那一幕。
1. 起始碼是 `System.out.println("Hello, World");`。改成印出 `學長，你在說外星語嗎？`（比對輸出）。
2. 再寫一行，印出兩行：`梁亭瑄`、`資訊科一年級`。學到「一個 println 印一行」（比對輸出）。
- 解鎖筆記：讓電腦說話、字串要用半形雙引號、每句結尾的分號、全形與半形、看懂紅字。

**`ch01-k2`「有名字的盒子」**：場景 3，PDF 第 2 頁。
1. 宣告 `String laptop = "小白";`（比對數值 `laptop`）。這是她的萬物命名癖：筆電叫小白。
2. 宣告 `int gacha = 7;`，再用 `System.out.println(gacha);` 印出來（比對輸出和數值）。
3. 又抽到一個：寫 `gacha = 8;`，再印一次，輸出會是 7 和 8 兩行（比對輸出）。
- 解鎖筆記：變數是有名字的盒子、int 與 String、改變盒子裡的東西。

**`ch01-k3`「如果有滷肉飯」**：場景 3，PDF 第 3 頁。
題目提供 `boolean hasLuRouFan = true;`，驗證時會換成 `false` 再跑一次。
1. 只寫 `if`：有滷肉飯就印 `吃滷肉飯`。
2. 補上 `else`：否則印 `吃控肉飯`。
- 解鎖筆記：if-else 就是選午餐。

### 學長視角

**`ch01-s1`「改寫術語文件」**：場景 2，學長獨有。亭瑄走了，他一個人留在教室，寫了又刪。
1. 起始碼是他原本的術語版範例，內容是印出 `println 會呼叫 PrintStream 的 println 方法`。改成白話版，印出 `電腦會把引號裡的字，原封不動印出來`（比對輸出）。
2. 盒子範例：`String box = "扭蛋";`，再印出來（比對輸出和數值）。範例會用扭蛋，是因為他注意到她的書包了，只是假裝沒看到。
3. `int gacha = 7;` 印出來，再改成 `gacha = 8;` 印一次。他數過她書包上的扭蛋，自己覺得這件事不能讓任何人知道（比對輸出）。
- 解鎖筆記：讓電腦說話、字串要用半形雙引號、每句結尾的分號、變數是有名字的盒子、int 與 String、改變盒子裡的東西。

**`ch01-s2`「滷肉飯比喻」**：場景 3，學長獨有。他打開新文件「程式基礎教學筆記」。
題目一樣提供 `boolean hasLuRouFan`，會換值再驗證。
1. 只寫 `if`。
2. 補上 `else`。
- 解鎖筆記：if-else 就是選午餐。

**`ch01-s3`「她照抄的程式」**：場景 4，學長版。亭瑄說：「我照你的 PDF 打了，可是一直紅字。」
1. 起始碼是她打的滷肉飯程式，裡面有全形分號 `；`、全形引號 `「」`、小寫的 `system`、少一個分號。修到能跑，印出 `吃滷肉飯`。
2. 起始碼是她打的盒子程式：`String laptop = "小白"` 少分號，`System.out.println(Laptop);` 大小寫不對。修到印出 `小白`。
- 解鎖筆記：全形與半形、看懂紅字。

這些錯誤現有的 `Diagnostics` 都已經有繁中說明：全形符號、找不到名稱並提示大小寫、缺分號。

## 程式基礎教學筆記

遊戲內的參考手冊就是二弘在第一章傳給亭瑄的那份 PDF。條目隨程式題解鎖，每條都用他寫的生活化比喻。True End 會用到的「最後一頁備註」預留位置，第一章不顯示；第十二章細綱把它定成術語文件最後一頁的那段備註，True End 之後解鎖（`last-page`）。

第二章以後每一條的 id 和一句話，寫在各章細綱的「筆記條目」。

| 章 | 條目 |
|---|---|
| 1 | 讓電腦說話（println）、字串要用半形雙引號、每句結尾的分號、全形與半形、看懂紅字、變數是有名字的盒子、int 與 String、改變盒子裡的東西、if-else 就是選午餐 |
| 2 | 型別是盒子的尺寸、四則運算與 `%`、整數除以整數、型別轉換、字串串接、比大小、`i++` 與 `+=`、for 是把同一件事做 N 遍 |
| 3 | 陣列是一排置物櫃、索引從 0 開始、走過每一格、else if 是排隊問問題、例外是程式在執行時跌倒、字串變數字、try-catch 是先準備好接住 |
| 4 | 方法是分工、參數是交給對方的東西、回傳值是對方交回來的東西、方法簽章就是約定、字串的方法、比字串要用 equals |
| 5 | boolean 方法、邊界值、測資、且／或／不是、while 是「還沒好就繼續」、巢狀迴圈、找最大最小 |
| 6 | 類別是設計圖、物件是照設計圖做出來的東西、建構子、this 是「我自己的」、物件的方法、null 是空盒子 |
| 7 | private 是只有自己能開的抽屜、getter 和 setter、在方法裡把關、static 是大家共用的、final 是寫死的 |
| 8 | 繼承、覆寫、@Override 是請編譯器幫你看、super 是父類別、toString 決定印出來的樣子 |
| 9 | 介面是約定、照約定實作、多型、抽象類別 |
| 10 | 完整程式從 main 開始、一個類別一個檔案、ArrayList 是會變長的清單、for-each 是每一個都來一次、角括號寫清楚裝什麼、HashMap 是對照表 |
| 11 | do-while 是先做再問、break 是提早離開、continue 是跳過這一次、無限迴圈 |
| 12 | import 與 package、完整的專題；True End 之後再解鎖最後一頁 |
