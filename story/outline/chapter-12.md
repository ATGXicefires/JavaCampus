# 第十二章：「Release」

## 基本資訊

| 項目 | 內容 |
|------|------|
| 時間 | 6月（專題發表會・畢業典禮） |
| 主題 | 專題發表・畢業・結局收束 |
| 程式隱喻 | Release = 發布——作品完成了，關係也到了可以「對外發布」的階段 |

## 章節概要

專題發表會 + 畢業典禮。所有路線在此收束為四種結局。

## 共通場景：專題發表會

**所有路線都會經過這個場景：**

- 資訊科專題發表會，全校師生和部分家長來參觀
- 二弘和亭瑄的作品：亭瑄設計的介面 + 二弘寫的後端邏輯
- 上台報告時，亭瑄負責介紹 UI 和使用流程，二弘負責技術說明
- 亭瑄比預期的流暢——她真的理解了這個程式在做什麼
- 二弘的技術說明簡潔精準（但依然不看觀眾的眼睛）
- 問答環節，有人問「這個介面是誰設計的」，二弘回答：「我的⋯⋯夥伴。」
- 亭瑄聽到「夥伴」這個詞，側過頭看了他一眼

**台下：**
- 阿成在後排假裝擦眼淚（被旁邊的人白眼）
- 小芸拍了一百張照片
- 王葉聖老師在評審席微笑
- 二弘的阿嬤偷偷來了（二弘不知道），坐在最後一排。看到孫子上台報告時紅了眼眶

## 共通場景：畢業典禮（草案）

> 新擬的場景，請審。

- 發表會的一週後，三年級的畢業典禮
- 亭瑄以在校生的身分坐在後面
- 阿成在典禮上哭得比誰都大聲
- 典禮結束，大家散到校門口拍照。四種結局從這裡分開

---

## 結局分歧

### True End —「1 + 1 > 2」

**條件：** AP≥80, TP≥80, 三個關鍵抉擇至少選對兩個

畢業典禮結束後，人群散去。兩人回到他們「起點」的那間電腦教室。

窗外夕陽，桌上還擺著開學那天讓亭瑄崩潰的術語文件（不知道為什麼一整年都沒收掉）。

亭瑄拿起來翻：「學長，我現在看得懂這個了欸。」
二弘看著她，很輕很輕地笑了：「⋯⋯嗯。你進步很多。」

亭瑄翻到最後一頁——上面有二弘在開學時寫的備註（他以為亭瑄沒看到過）：

> 「她什麼都不會。可是她問的問題，讓我第一次重新想為什麼要寫程式。」

亭瑄眼眶紅了。
二弘慌張：「你、你怎麼了——」
亭瑄：「你這個笨蛋。」
然後抱住了他。

二弘僵硬了大概五秒。然後，慢慢地、笨拙地抱了回去。

**尾聲畫面（時間改到畢業後，草案）：**

九月，亭瑄升上二年級的開學日。二弘的大學還沒開學，陪她走到校門口。

二弘的背包上多了一個亭瑄做的手工鑰匙圈（上面寫著「Bug-Free Zone」）。
亭瑄的筆電桌面換成了他們專題的截圖。

騎機車經過的阿成大喊：「喂——你們兩個夠了啊——學妹要遲到了——」
小芸在旁邊舉著手機：「最終統計報告已生成。共 478 次加上暑假期間的⋯⋯」
亭瑄：「夠了啦！！！」
二弘（看著這一切的混亂，嘴角不自覺上揚）：「⋯⋯真吵。」

但他沒有戴耳機。

---

### Good End —「Merge Request Approved」

**條件：** AP≥60, TP≥60（但未達 True End 條件）

畢業典禮後。兩人走在臺南的老街上，經過永樂市場。

亭瑄買了兩杯楊桃湯，遞了一杯給二弘。

二弘：「⋯⋯暑假，你要不要繼續學？」
亭瑄：「學什麼？」
二弘：「⋯⋯程式。」（沒有看她）
亭瑄笑了：「好啊。但你要繼續教我。」
二弘：「⋯⋯好。」
亭瑄：「而且你不准再只吃飯糰。」
二弘：「⋯⋯我已經很久沒吃飯糰了。」（因為你每天帶便當）
亭瑄：「那是因為——」（停住，臉紅了）
二弘也紅了。兩個人同時看向別的方向。

**尾聲畫面：**

暑假的某一天。臺南的咖啡廳裡。
兩人各自面對各自的筆電。二弘在寫新專案，亭瑄在學 CSS 畫網頁。
桌上放著兩杯木瓜牛奶。

安靜但溫暖。

兩人的手在桌子下偷偷勾在一起。
亭瑄的螢幕上有一個資料夾叫「二弘教我的東西」。
二弘的螢幕上有一個變數叫 `tingXuan`。

---

### Normal End —「Pull Request Pending」

**條件：** AP≥40 或 TP≥40（至少一項中等）

畢業典禮結束了。

校門口，兩人道別。禮貌的、帶著微妙距離的。

亭瑄：「學長，這一年⋯⋯謝謝你。」
二弘：「⋯⋯嗯。你也辛苦了。」
亭瑄：「畢業快樂。」
二弘：「⋯⋯嗯。」

亭瑄轉身走了幾步。二弘也轉身走了幾步。

然後兩個人同時回了頭。四目相對。

二弘：「⋯⋯暑假見。」
亭瑄（輕聲）：「⋯⋯嗯，暑假見。」

兩人各自離開。鏡頭拉遠。

**旁白：** 「有些程式的執行時間比預期長。有些感情也是。」

**尾聲暗示：**

大學開學第一天。二弘打開行李箱，夾層裡有一封信（亭瑄的字跡）。（時間改到畢業後，草案）

信的內容沒有展示。但二弘的表情，從困惑變成了微笑。

---

### Comedy Bad End —「Stack Overflow」

**條件：** AP<40, TP<40

專題勉強及格。完全沒有培養出任何默契。

學年末，亭瑄還是交出了轉科申請表，下學年轉去廣設科。（第八章她沒交的那張表，這條線上最後還是交了。草案）

畢業典禮那天，二弘最後一次回電腦教室收東西，在舊專題的資料夾裡發現一個陌生的檔案：

`給編譯器學長的話.txt`

打開來——

> 學長，你的程式碼真的寫得很好。
> 但你的人際互動真的很差。
> 建議：System.out.println("謝謝"); 就這麼簡單。
> 祝你找到下一個願意聽你碎念的人。
>
> P.S. 木瓜牛奶我還是會幫你買的。
> 不過要自己來廣設科教室拿。

二弘看著螢幕，嘴角不自覺地抽動——是笑還是苦笑，鏡頭沒有給答案。

**旁白：** 「有些 bug 錯過了這個 sprint，下一個 sprint 也許還有機會修。也許吧。」

（帶笑的遺憾——不絕望，暗示未來還有可能性。給續篇留了接口。）

---

## 本章設計備註

- True End 是最完整的情感收束——從第一章的術語文件到最後翻出來，形成完美首尾呼應
- Good End 溫暖但含蓄——感情確認了但用他們各自的方式（不是擁抱，是手偷偷勾在一起）
- Normal End 帶著「未完」的感覺——信的內容留白是刻意的，讓玩家自己想像（也為大學 DLC 留伏筆）
- Comedy Bad End 不苦澀——亭瑄的 txt 檔延續了「程式碼告白」的 running gag，語氣是嘴硬但不是真的放棄
