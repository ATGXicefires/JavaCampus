# 第六章：「建構子」（草案）

> 草案。標「原第六章」的段落是你寫的，從舊的第六章（現在的第十一章）搬過來；標「新增」的和其餘段落是新擬的事件，請審。章名是暫定。

## 基本資訊

| 項目 | 內容 |
|------|------|
| 時間 | 12月中旬～1月（聖誕節・期末考・寒假前） |
| 主題 | 上學期的收尾・離不開的搭檔 |
| 程式隱喻 | 建構子 = 物件被 `new` 出來時第一個執行的方法，負責把它組起來。二弘親手組了一個紙箱機器人送她；這一學期，兩人也一點一點把「搭檔」組了起來 |

## 章節概要

上學期的最後幾週。專題要交上學期的進度、聖誕節有交換禮物、期末考接著就到。兩人已經習慣了每天放學的電腦教室，卻第一次要面對「放寒假就見不到面」這件事。誰都沒有說出口，連自己都不太承認。

## 場景流程

### 場景 1：上學期的進度檢核（電腦教室）

**共通事件：**
- 王老師要各組在寒假前交上學期的專題進度
- 二弘第一次把專題架構裡的「類別」講給亭瑄聽：一個類別就是一張設計圖，照著它可以做出很多個東西
- 亭瑄的萬物命名癖發作：筆電叫小白、USB 叫阿隨，現在每個「物件」她都要取名字

**學長視角：**
- 解釋「類別」的時候，發現自己舉的例子是她的扭蛋
- 和第一章那份術語文件比起來，自己講話的方式已經完全不一樣了

**學妹視角：**
- 第一次覺得專題的架構圖看得懂了
- 在架構圖的角落偷偷畫了一個 Q 版的學長，以為沒人會看到（出自 `comedy-romance.md`「只有我看到的另一面」）

### 場景 2：聖誕節（原第六章）

**共通事件：**
- 學校有交換禮物活動，但二弘和亭瑄不同班

**學長的禮物：**
- 用紙箱做了一個超醜的「機器人」模型
- 裡面塞了一張手寫卡片——他花了三天寫這張卡片，垃圾桶裡有四十幾個草稿
- 最終版本：「感謝你這學期的 contribution。你的 code review 意見（雖然大部分是在抱怨）讓這個專案變得更好。—— 吳二弘」
- 背面很小的字：「P.S. 木瓜牛奶換成冬天的話，熱可可也可以。」

**亭瑄收到後：**
- 拍照傳給小芸：「他到底是在表白還是在寫 commit message？？」
- 小芸：「⋯⋯以他的標準來說，這大概已經是情書等級了。」
- 亭瑄盯著「你的 code review 意見讓這個專案變得更好」看了很久
- 翻到背面，看到那行小字
- 心跳得好快
- （新增）回小芸說才不是情書，那是 commit message。然後把卡片夾進了筆記本

**亭瑄的禮物：**
- 一條手工編織的螢幕擦拭布（因為二弘的眼鏡永遠是髒的）
- 附了一張卡片：「給編譯器學長：希望這個讓你看得更清楚。不只是螢幕。」

**二弘收到後：**
- 看著擦拭布愣了很久
- 拿起來擦了眼鏡
- 世界確實變清楚了——但讓他心跳加速的不是這個
- （新增）他沒有去想那是什麼，只在心裡把這件事標成 `// TODO`，留到以後再處理（第九章才處理）

### 場景 3：期末考與寒假前的最後一天

**共通事件：**
- 期末考前，兩人在電腦教室各自複習。二弘幫她出程式設計的模擬題
- 東北季風很大的放學路，兩人走得比平常近一點（出自 `local-flavor.md`「冬天」）
- 上學期最後一天放學，在校門口道別。說了一整學期的「明天見」，今天說不出口——明天開始就是寒假

**學長視角：**
- 回家路上算了一下：寒假三週，不用去電腦教室
- 第一次覺得假期太長

**學妹視角：**
- 小芸問她寒假的計畫，她說要自學程式
- 小芸只回了一個「喔」（第一章那種「喔」）

### 章末

二弘翻開第一章那本進度筆記，寫下上學期的最後一條。（內容待你決定）

## 本章關鍵情感節點

1. **類別與萬物命名癖** — 二弘的教法已經變成「她的語言」
2. **聖誕禮物** — commit message 卡片 vs 螢幕擦拭布，各自的語言表達在意（原第六章）
3. **說不出口的「明天見」** — 上學期結束，兩人第一次要分開這麼久

## 程式題方向

- 學妹（寫）：照設計圖做物件，`new` 出小白和阿隨；用建構子讓「取名字」在出生的時候就決定
- 學長（修／教）：`class Gift`（紙箱機器人）的欄位和建構子；修她忘了寫 `this.name = name;`、名字一直是 `null` 的程式

## 選項方向（草案）

- 學長：收到擦拭布之後——當面道謝（熱絡）／只傳一個貼圖（冷淡）
- 學妹：禮物怎麼送——親手交給他（熱絡）／放在他桌上就跑（冷淡）

數值照 `branching.md` 的預算。
