# 第一章：「編譯錯誤」

## 基本資訊

| 項目 | 內容 |
|------|------|
| 時間 | 9月上旬（開學第一～二週） |
| 主題 | 相遇・被迫組隊・第一印象 |
| 程式隱喻 | 編譯錯誤 = 從一開始就「跑不起來」的組合 |

## 章節概要

開學第一週，資訊科主任宣布今年專題製作必須跨年級組隊。抽籤事故讓兩個「剩下的人」——遲到的三年級程式天才吳二弘，和猶豫到最後一刻才報名的一年級新生梁亭瑄——被配在一起。第一次見面就因為溝通方式的巨大落差吵了起來。

## 場景流程

### 場景 1：抽籤現場（電腦教室）

**共通事件：**
- 王葉聖老師宣布今年專題規則：跨年級抽籤組隊
- 二弘遲到衝進教室（在另一間教室 debug 到忘記時間）
- 亭瑄是最後一個報名的（截止前五分鐘才交表）
- 亭瑄抽到寫著「吳二弘」的紙條，全班男生齊聲「噢——！」
- 二弘聽到自己名字，抬頭，一臉問號

**學長視角（二弘）：**
- 內心：本來打算一個人做（已經提前準備了半年），被新規定打亂計畫
- 聽到配對對象是一年級時：「⋯⋯一年級？」
- 看到亭瑄：注意到她書包上掛滿了扭蛋（內心 OS：「這個人看起來不像會寫程式的樣子」）

**學妹視角（亭瑄）：**
- 內心：被同學推去抽籤，根本不想做專題（她還在考慮轉科）
- 看到二弘的第一印象：制服很皺、眼神很冷、看起來很難相處
- 聽到旁邊的人小聲說「編譯器」，不知道是什麼意思

### 場景 2：第一次討論（放學後・電腦教室）

**共通事件：**
- 二弘打開事先準備好的專題規劃文件（滿是術語和架構圖）
- 亭瑄看了三秒：「學長，你在跟我說外星語嗎？」
- 二弘：「⋯⋯這是 Java。」
- 溝通完全不在同一個頻率上：二弘講得越技術，亭瑄越茫然
- 二弘不耐煩地說了：「這些是基礎中的基礎。」
- 亭瑄炸了：「我就是什麼都不會才在這裡，不然你覺得我是來幹嘛的！」

**學長視角獨有：**
- 亭瑄走後，二弘一個人留在教室
- 對著螢幕發呆，不太理解為什麼她會生氣
- 試圖重新打開文件，把術語改成更簡單的說法⋯⋯寫了又刪，刪了又寫
- 阿成出現在門口：「喂，聽說你配到一年級的學妹？」
- 二弘：「⋯⋯她什麼都不會。」
- 阿成：「那你教她啊。」
- 二弘：「我不會教人。」
- 阿成（笑）：「那你完了。」

**學妹視角獨有：**
- 亭瑄氣沖沖地離開教室，打給小芸抱怨
- 小芸：「那個學長長怎樣？」亭瑄：「很機車！講話超冷！」
- 走到校門口時回頭看了一眼教室窗戶——二弘還在裡面，認真地對著螢幕打字
- 窗外開始下雨，二弘完全沒注意到
- 亭瑄站了一會兒，有一個念頭閃過：「也許不是那麼討厭⋯⋯吧？」
- 搖搖頭跑走了

### 場景 3：轉科的念頭（隔天）

**共通事件：**
- 亭瑄跟小芸在化工科實驗室外面聊天，提到想轉科
- 小芸：「你確定不是因為那個學長嗎？」亭瑄：「關他什麼事！是我本來就想轉！」

**學長視角獨有：**
- 二弘在教室裡聽到別的同學討論「那個一年級的好像想轉科」
- 停下打字的手，想了想，什麼都沒說
- 打開一個新文件，標題是「程式基礎教學筆記」
- 下課後把文件打包成 PDF，猶豫了很久，傳到了專題的 LINE 群組
- 訊息只有一句：「如果你還想做這個專題的話。」

**學妹視角獨有：**
- 收到二弘傳的 PDF
- 打開來一看——跟昨天的術語文件完全不同，每個概念都用生活化的比喻重寫過
- 「變數就像一個有名字的盒子」「if-else 就像你選午餐：如果有滷肉飯就吃滷肉飯，否則吃便當」
- 忍不住笑了出來
- 發現最後一頁寫著：「以上如果還是看不懂，明天放學來電腦教室。」
- 截圖傳給小芸：「你看這個學長是不是有點⋯⋯」小芸：「有點什麼？」亭瑄：「⋯⋯算了沒事。」

### 場景 4：留下的選擇（★分歧點）

**共通事件：**
- 第二天放學，亭瑄出現在電腦教室門口
- 二弘假裝沒在等但明顯一直看門的方向
- 亭瑄坐下來：「⋯⋯那個 PDF，我看了。」
- 二弘：「⋯⋯然後？」
- 亭瑄：「我還是覺得程式很難。」
- 二弘：「⋯⋯」
- 亭瑄：「但你寫的比喻很好笑。滷肉飯那個。」
- 二弘（耳朵微紅）：「那只是為了讓你理解 if-else。」

**★ 分歧選項：**

**（學長視角時）：** 亭瑄說「如果我真的學不會，你不會覺得很煩嗎？」

- **選項 A「不會」：** 「⋯⋯反正已經配對了。我不習慣留 bug 不修。」（AP+8, TP+5）
- **選項 B「會」：** 「會。但那是我的問題，不是你的。」——頓了一下——「意思是⋯⋯我會想辦法。」（AP+5, TP+8）

**（學妹視角時）：** 二弘說「你⋯⋯還想繼續做這個專題嗎？」

- **選項 A「留下」：** 「嗯。雖然學長你講話真的很機車，但⋯⋯至少你有認真在教。」（AP+8, TP+5）
- **選項 B「猶豫」：** 「我不確定⋯⋯但如果學長願意等我跟上的話。」（AP+5, TP+8）

### 章末

兩人定下了每天放學後在電腦教室討論專題的約定。二弘翻開筆記本寫下第一條進度：「Day 1：教會梁同學什麼是變數。」

亭瑄偷看了一眼，嘴角微揚：「你那個字很醜欸。」
二弘（闔上筆記本）：「⋯⋯又不是寫給你看的。」

## 本章關鍵情感節點

1. **第一印象的反差** — 表面上不合拍，但各自看到了對方意想不到的一面
2. **PDF 筆記** — 二弘用行動（而非言語）表示了在意，這是他的模式的第一次展現
3. **留下的選擇** — 第一個分歧點，確立兩人「願意嘗試」的共識

## 本章 Running Gags 首次登場

- 二弘的術語口癖（「這是 Java」）
- 亭瑄的書包扭蛋（二弘注意到但假裝沒看到）
- 阿成的損友吐槽
