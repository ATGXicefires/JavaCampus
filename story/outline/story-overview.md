# 故事總覽

## 作品名稱

（暫定）待決定

## 一句話概要

資訊科的社恐程式天才學長，被迫和完全不會寫程式的元氣學妹搭檔做專題——一個不想教、一個不會寫，卻在一起 debug 的日子裡，悄悄 compile 出了心動。

## 前提

國立成功大學附屬臺南工業高級中等學校（成大附工），資訊科。

資訊科主任為了推行「學長姐帶學弟妹」制度，今年的專題製作強制跨年級組隊。抽籤當天：

- **吳二弘**遲到了——在電腦教室 debug 到忘記時間
- **梁亭瑄**是最後一個報名的——她本來想轉科，猶豫到截止前一刻才填表

兩個「剩下的人」被配在一起。

## 核心衝突

程式怪物獨行俠 × 完全不會寫程式的元氣少女。

二弘不想教（「自己寫比較快」），亭瑄不想學（「我根本不該在資訊科」）。但學校規定：專題不及格就不能畢業。

他們必須在一個學年內合作完成專題（到二弘畢業為止），同時面對：
- 段考、技能檢定、實習課的各種壓力
- 彼此之間越來越無法忽視的感情
- 各自的人生課題（二弘的社恐與家庭壓力、亭瑄的迷茫與自我認同）

## 主題

**「真正的連結不是效率最高的演算法，而是願意為對方多 debug 一次的耐心。」**

這個故事講的是：兩個看似不相容的人，透過一起解決問題（字面上的程式 bug 和比喻上的人生困境），逐漸理解對方的世界，並在這個過程中發現自己真正想要的東西。

- 二弘學會了：人不是程式，不能只看效率；表達情感不是 bug，而是 feature
- 亭瑄學會了：程式是另一種創作；找到方向不需要一步到位，只需要願意嘗試

## 風格定位

### 甜系日常（60%）
像《擅長捉弄人的高木同學》——日常互動中的小心動、不經意的距離縮短、只有觀眾看得到的暗暗在意。

### 歡樂吐槽（40%）
像《我的妹妹不可能那麼可愛》——高密度吐槽、誇張搞笑、角色之間的妙語連珠。吐槽不傷人，笑點來自角色的反差和誤會。

### 不是什麼
- 不是沉重的青春傷痛文學
- 不是後宮/三角戀
- 不是純搞笑沒有劇情深度的四格漫畫
- 不是超展開的戲劇性故事（沒有車禍失憶轉學離別）

## 世界觀特色

### 成大附工的真實感
- 技職學校的獨特文化（實習、專題、技能檢定）
- 資訊科的「男多女少」生態（天然的喜劇素材）
- 電腦教室就是青春的主場景

### 臺南的溫度
- 放學後的國華街散步、赤崁樓旁的咖啡店、安平的夕陽
- 臺南人的步調——不急不慢，但認真起來很認真
- 在地美食貫穿日常（木瓜牛奶是兩人的代表飲料）

### 程式與情感的雙重隱喻
- 每章標題都是程式術語，對應劇情主題
- 角色用程式語言「翻譯」情感，形成獨特的浪漫語境
- 專題的完成進度 = 感情的發展進度

## 時間軸

本篇涵蓋一個學年，從開學到二弘畢業：上學期 6 章，下學期 6 章。第六～十章的章名是暫定。

| 月份 | 章節 | 主題 |
|------|------|------|
| 9月上旬 | 第一章「編譯錯誤」 | 相遇・組隊 |
| 9月中～下旬 | 第二章「Hello World」 | 磨合・第一次合作 |
| 10月 | 第三章「例外處理」 | 衝突與和解 |
| 10月下旬～11月 | 第四章「共同開發」 | 距離拉近 |
| 11月中～12月上旬 | 第五章「壓力測試」 | 各自的戰場 |
| 12月中～1月 | 第六章「建構子」 | 上學期的收尾・離不開的搭檔 |
| 寒假（1月下旬～2月） | 第七章「封裝」 | 分開・開始想念 |
| 2月中～3月 | 第八章「覆寫」 | 轉科抉擇・亭瑄察覺心意 |
| 3月～4月 | 第九章「介面」 | 技優甄審・二弘察覺心意 |
| 4月～5月 | 第十章「合併衝突」 | 都知道，都不說 |
| 5月～6月上旬 | 第十一章「無限迴圈」 | 畢業倒數・告白 |
| 6月 | 第十二章「Release」 | 專題發表・畢業・結局 |

### 感情節奏

- **上學期：** 只到「離不開的搭檔」。心動有，但都被自己否認：心跳是 bug、臉紅是風吹的、說不清的事標成 `// TODO`。
- **寒假：** 見不到面，才開始想念。
- **下學期：** 亭瑄先察覺心意（第八章），二弘接著察覺（第九章）。兩人都知道，卻都不說（第十章）。
- **告白：** 畢業前夕（第十一章）。四種結局在畢業典禮之後（第十二章）。

## 兩條路線設計

玩家在開頭選擇扮演學長或學妹：

- **共通場景：** 核心事件（抽籤、爭吵、校慶、告白等）的「外在事實」不變
- **視角差異：** 內心獨白、對同一事件的解讀、看到的細節完全不同
- **獨有場景：** 每個視角有 1-2 個只有自己才會經歷的場景，增加重玩價值
- **同一個選擇、不同的意義：** 例如第三章和解，學長的選擇是「要不要主動道歉」，學妹的選擇是「要不要先原諒」
