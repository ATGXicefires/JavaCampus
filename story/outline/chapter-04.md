# 第四章：「共同開發」

## 基本資訊

| 項目 | 內容 |
|------|------|
| 時間 | 10月下旬～11月（校慶前後） |
| 主題 | 距離拉近・說不出口的在意 |
| 程式隱喻 | 共同開發 = 兩人的程式碼終於能合在一起跑了 |

## 章節概要

和解之後，兩人的合作默契明顯提升。校慶（成大附工校慶活動）資訊科要展示專題成品，兩人為了趕工密集相處，距離一點一點拉近。在校慶的夜晚，兩人都察覺到有什麼不一樣了，卻各自找了理由帶過：心跳是 bug，臉紅是風吹的。

## 場景流程

### 場景 1：新的合作模式

**共通事件：**
- 二弘改變了教學方式：不再直接講術語，而是先問「你覺得應該怎麼做？」讓亭瑄用自己的方式思考
- 亭瑄負責了專題的 UI 設計——她畫的介面簡單但有設計感
- 兩人開始有了「分工」而非「教學」的關係
- 阿成路過電腦教室門口看到兩人並肩看著同一個螢幕，默默拍了一張照（二弘完全不知道）

**學長視角：**
- 發現亭瑄問的問題越來越有深度——不是「這是什麼」而是「為什麼要這樣做」
- 第一次覺得「教她」這件事⋯⋯有點成就感
- 注意到自己開始會在意亭瑄的建議（以前不會聽任何人的意見）

**學妹視角：**
- 發現學長變了——會解釋「為什麼」，會等她跟上，會問她的想法
- 不是那種很明顯的溫柔，而是很他的方式
- 開始在回家路上也想著專題的事（不是壓力，而是期待）

### 場景 2：校慶準備（密集相處）

**共通事件：**
- 校慶前兩週，電腦教室變成戰場
- 兩人幾乎每天留到天黑
- 二弘會在亭瑄畫設計稿時默默去買她喜歡的木瓜牛奶
- 亭瑄會在二弘連續打字太久時突然拍他肩膀：「休息！」

**關鍵場景——傍晚的教室：**
- 夕陽從窗戶灑進來
- 亭瑄在紙上畫 UI 草圖，嘴裡哼著歌，偶爾咬著筆蓋思考
- 二弘抬頭看了一眼，然後看了第二眼，然後第三眼
- 發現自己的視線離不開她被夕陽染成橘色的側臉
- 手指停在鍵盤上——心跳加速的感覺是什麼？Bug 嗎？

**學長視角獨有：**
- 心跳加速。手上的程式碼寫到一半，打出了 `亭` 然後刪掉
- 內心 OS：「⋯⋯這是什麼。心跳頻率超出預期值。不是 bug，那是什麼。」
- 阿成隔天問他「昨天留那麼晚喔」，二弘的耳朵紅了一下：「⋯⋯在趕專題。」阿成意味深長：「嗯，趕專題。」

**學妹視角獨有：**
- 發現學長會在她沒注意到的時候偷看她
- 心裡咚了一下，但裝作沒發現
- 那天回家在鏡子前面看了自己很久：「⋯⋯他到底在看什麼。」
- 傳訊息給小芸，說是在討論專題，其實一半都在講學長
- 小芸：「吳學長提及次數：今日已破 20。」
- （原本「你是在問我，吳二弘是不是喜歡你嗎？」那段對話移到第七章，寒假見不到面的時候）

### 場景 3：校慶當天

**共通事件：**
- 專題展示獲得好評。來參觀的同學和家長都覺得介面設計漂亮
- 王葉聖老師在展示區走了一圈，停在他們的攤位前：「UI 不錯。是你畫的？」（看向亭瑄）
- 亭瑄受到肯定，笑得很開心
- 二弘在旁邊安靜地看著，表情⋯⋯跟平常不太一樣

- 展示結束後，亭瑄拉著二弘去逛攤位
- 二弘被迫吃了五種不同口味的雞蛋糕（「你為什麼每一攤都要試？」「因為每一攤都不一樣啊！」）
- 人潮擁擠中亭瑄抓住了二弘的袖子
- 二弘低頭看了一眼被抓住的袖子——沒有甩開
- 走了好一段路才發現，亭瑄已經鬆手了，但他的袖子上好像還有殘留的溫度

### 場景 4：校慶夜・天台（★分歧點）

**共通事件：**
- 校慶尾聲。攤位收了，大部分人散了
- 二弘一個人回電腦教室拿東西，碰到亭瑄也在
- 亭瑄：「學長，你有去過頂樓嗎？」
- 二弘：「⋯⋯那裡不是禁止進入嗎。」
- 亭瑄已經往樓梯走了：「走啦！」
- 兩人到了教學大樓天台（門沒鎖），臺南的夜景攤開在面前
- 遠處有煙火（附近廟宇的活動，不是校慶的）

- 亭瑄：「學長，你的程式碼很厲害。」
- 二弘：「⋯⋯嗯。」
- 亭瑄：「但你人更厲害。」
- 二弘（沉默。煙火的光映在兩人臉上）

**★ 分歧選項：**

**（學長視角時）：** 亭瑄的話讓你——

- **選項 A「說真心話」：** 「⋯⋯你也是。你讓我第一次覺得⋯⋯教人這件事，沒有那麼糟。」（沒有看她，但耳朵紅透了）（AP+12, TP+8）
- **選項 B「用玩笑帶過」：** 「⋯⋯你這句話有 type mismatch。程式碼不能跟人比較。」亭瑄笑出聲：「你真的完全不會接話欸。」——安全，但錯過了一個更靠近的機會（AP+5, TP+5）

**（學妹視角時）：** 二弘沉默了好久之後——

- **選項 A「繼續推進」：** 「學長？你還活著嗎？」（湊近一點看他的臉）發現他耳朵紅了，心跳漏了一拍。「⋯⋯學長，你的耳朵好紅。」二弘：「是、是風吹的。」（AP+12, TP+8）
- **選項 B「不追問」：** 安靜地並肩站著看煙火。舒服，但什麼都沒有多說（AP+5, TP+5）

### 章末

兩人從天台下來，走在校園的暗路上。

二弘突然停下來：「⋯⋯梁亭瑄。」
亭瑄轉頭：「幹嘛？」
二弘：「⋯⋯明天放學，電腦教室見。」
亭瑄：「你每天都會說這句話欸。」
二弘：「⋯⋯今天想特別說一次。」

亭瑄笑了。「好，明天見。」

## 本章關鍵情感節點

1. **合作模式的轉變** — 從「教與學」變成「夥伴」
2. **夕陽的側臉** — 二弘第一次「看見」亭瑄（不是學妹，是她），卻說不出那是什麼
3. **袖子** — 被抓住卻沒有甩開，無聲的靠近
4. **天台** — 煙火下的真心話（或錯過的真心話），全篇最浪漫的場景之一
5. **「今天想特別說一次」** — 二弘第一次主動打破自己的模式

## 本章 Running Gags 進展

- 便當攻防戰升級：口味開始「剛好」是二弘喜歡的
- 阿成開始有照片證據（偷拍系列）
- 小芸的統計突破 20 次/天
- 二弘的飲料從飯糰升級為木瓜牛奶（亭瑄的影響）
