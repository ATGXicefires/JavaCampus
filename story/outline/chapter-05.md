# 第五章：「壓力測試」

## 基本資訊

| 項目 | 內容 |
|------|------|
| 時間 | 11月中旬～12月上旬 |
| 主題 | 各自面對壓力・學會在不在身邊時支撐對方 |
| 程式隱喻 | 壓力測試 = 檢驗系統在極端條件下還能不能正常運作 |

## 章節概要

二弘面臨丙級/乙級技能檢定，亭瑄要應付第二次段考，同時專題中期報告也在眼前。兩人各自忙碌、見面時間大減。但這次不是第三章的冷戰——而是各自在自己的戰場上戰鬥，同時偷偷地為對方加油。

## 場景流程

### 場景 1：各自的戰場

**學長視角：**
- 技能檢定（術科 + 學科）壓力極大，這關係到技優甄審
- 每天練術科到很晚，已經好幾天沒在放學後去電腦教室
- 但他在練習的空檔，會打開手機看亭瑄傳來的訊息（通常是一張便當照片配上「今天沒人吃所以拍了一張紀念」）
- 有一天深夜，收到亭瑄傳的一張照片——她在圖書館自習，旁邊攤開的是二弘之前給的筆記
- 二弘盯著照片看了很久。阿嬤經過房門口：「阿弘，你最近怎麼一直笑？」他摸了摸臉：「⋯⋯有嗎？」

**學妹視角：**
- 決定不讓二弘分心，自己偷偷去圖書館讀書
- 在 YouTube 上找程式教學影片自學，遇到不會的先記下來而不是馬上問二弘
- 這是她第一次「真心想把程式寫好」——不是為了專題成績，而是想讓二弘看到自己的進步
- 小芸陪她在圖書館讀書，觀察到亭瑄比以前認真一百倍
- 小芸：「你變了欸。」亭瑄：「哪裡？」小芸：「以前你唸書唸半小時就滑手機。現在都兩個小時了。」亭瑄：「⋯⋯因為我想⋯⋯」（停頓）「⋯⋯想及格。」小芸微笑：「嗯，想及格。」

### 場景 2：技能檢定前夜

**學長視角：**
- 考前焦慮到睡不著，在書桌前反覆練習
- 起身去倒水時發現桌上多了一杯木瓜牛奶——不是阿嬤買的
- 旁邊有一張小紙條（亭瑄的字跡，歪歪扭扭的）：
  > 「明天考試加油！（錯誤較少的版本：你一定可以 return true；）」
- 紙條上的 Java 語法還是有一個錯誤（分號用了全形）
- 二弘盯著紙條上歪歪扭扭的字，笑了。把紙條夾進筆記本裡

**學妹視角獨有：**
- 那天放學特地繞到二弘家附近，把木瓜牛奶和紙條托阿嬤轉交
- 阿嬤看到她，笑得合不攏嘴：「妹妹仔你就是阿弘的同學喔？他有提到你。」
- 亭瑄（心跳加速）：「他、他有提到我？說什麼？」
- 阿嬤：「他說你做的便當很好吃。」
- 亭瑄紅著臉跑走了

### 場景 3：段考成績

**共通事件：**
- 技能檢定結束、段考結束
- 亭瑄的程式相關科目從三十幾分進步到六十二分
- 她拿著成績單衝到電腦教室：「學長！你看！！！」
- 二弘接過來看：「六十二分⋯⋯」
- 亭瑄（期待的表情）
- 二弘：「⋯⋯離滿分還差 38 分。」
- 亭瑄（生氣）：「你能不能——」
- 二弘（非常小聲）：「⋯⋯做得好。」
- 亭瑄愣了一下。然後笑了，笑得很開心

### 場景 4：專題中期報告

**共通事件：**
- 亭瑄獨自完成了 UI 的 mockup——不是二弘指導的，是她自己學的
- 畫風簡單但有設計感，色彩搭配很舒服
- 報告時，王葉聖老師停下來看了一會：「梁亭瑄，你的介面設計很有想法。」
- 全班的目光集中在亭瑄身上，她有點不好意思但很開心
- 二弘在旁邊安靜地看著

**學長視角獨有：**
- 看著亭瑄被老師稱讚，心裡的感覺很複雜
- 驕傲——她真的進步了
- 還有一點點⋯⋯「好像不需要我了」的落寞
- 這個念頭只閃過一下，就被他自己關掉了：「——不，這不在變數範圍內。」
- （原本的「我什麼時候開始希望她『需要我』了？」移到第九章，那時他才真的想通）

**★ 分歧選項：**

**（學長視角時）：** 報告結束後亭瑄問「學長，我做得怎麼樣？」

- **選項 A「真心稱讚」：** 「⋯⋯比我預期的好很多。你學得很快。」（認真地看著她）（AP+8, TP+10）
- **選項 B「故作冷淡」：** 「⋯⋯還行。配色可以再調整。」（但聲音比平常輕）（AP+5, TP+3）

**（學妹視角時）：** 被老師稱讚後你想——

- **選項 A「第一個想告訴學長」：** 衝到二弘面前：「學長你看到了嗎！老師說我做得好！」笑得眼睛都瞇起來了（AP+8, TP+10）
- **選項 B「假裝不在意」：** 「嗯，還好啦。」但其實一直偷看二弘的反應（AP+5, TP+3）

### 章末

放學後的電腦教室。兩人很久沒有一起留到這麼晚了。

亭瑄在整理中期報告的文件，二弘在旁邊改程式碼。安靜但舒服。

亭瑄：「學長，技能檢定考得怎麼樣？」
二弘：「⋯⋯過了。」
亭瑄：「我就知道！你一定沒問題的。」
二弘：「⋯⋯你的紙條⋯⋯那個 return true。」
亭瑄（緊張）：「怎、怎麼了？」
二弘：「分號要用半形的。」
亭瑄：「⋯⋯你就不能說聲謝謝嗎！」
二弘（停頓很久）：「⋯⋯謝謝。」

他的聲音很小。但亭瑄聽得很清楚。

## 本章關鍵情感節點

1. **各自戰鬥** — 不在身邊但互相惦記，這是更成熟的在意
2. **木瓜牛奶 + 紙條** — 亭瑄第一次主動去二弘的世界（他家附近），遇到阿嬤
3. **六十二分** — 二弘嘴上嫌棄但心裡驕傲，亭瑄的努力被看見
4. **「好像不需要我了」** — 二弘第一次感到落寞，但馬上把這個念頭關掉。真正想通要等到第九章
5. **「謝謝」** — 二弘說出了最難說的兩個字
