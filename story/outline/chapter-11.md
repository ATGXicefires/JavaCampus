# 第十一章：「無限迴圈」

## 基本資訊

| 項目 | 內容 |
|------|------|
| 時間 | 5月～6月上旬（畢業倒數） |
| 主題 | 感情臨界點・告白 |
| 程式隱喻 | 無限迴圈 = 不想停下來的心情，一直重複想著同一個人 |

## 章節概要

專題進入最後階段，再過幾週就是畢業典禮。倒數的氣氛讓兩人的感情到達臨界點。二弘意識到「畢業之後就沒理由每天見面了」，這個事實讓他胃不舒服。亭瑄從轉科抉擇那時起就很確定自己的心意，卻不確定二弘的想法。

**本章沒有新的分歧選項——所有的走向由前十章的累積數值和關鍵抉擇決定。**

## 場景流程

### 場景 1：倒數的焦慮

**學長視角：**
- 寫了一個計時器程式：「距離畢業典禮還有 X 天」
- 每看到數字減少就覺得不舒服——不是因為畢業，而是因為⋯⋯畢業之後就沒理由每天待在一起了
- 阿成看到他盯著計時器發呆：「你是打算寫一個 while(true) 把畢業典禮卡住嗎？」
- 二弘：「⋯⋯這在技術上是可行的，但沒有意義。」
- 阿成：「那你打算怎麼辦？畢業以後。」
- 二弘沉默

**學妹視角：**
- 已經很確定自己的心意了——但學長呢？
- 他對每個人都這樣嗎？還是只對她？
- 小芸翻出手機：「你這學年提到吳二弘 478 次。」
- 亭瑄：「⋯⋯你真的有在數？」
- 小芸：「我寫了一個 Python 爬蟲分析我們的聊天紀錄。」
- 亭瑄：「⋯⋯你從二弘那裡學壞了。」
- 小芸：「那你叫他『二弘』了喔？」
- 亭瑄（整個人紅了）：「口誤！！！」

### 場景 2：畢業紀念冊（草案）

> 原本的場景 2「聖誕節」移到第六章。這一場是新擬的，請審。

**共通事件：**
- 三年級的畢業紀念冊發下來了，大家互相傳著寫留言
- 二弘的畢冊幾乎是空的，只有阿成寫了一整頁
- 亭瑄拿到他的畢冊，寫了很久，最後只寫了一行（內容待你決定）

### 場景 3：最後的電腦教室夜晚

**共通事件——依路線分歧：**

#### 【True End 路線】（AP≥80, TP≥80, 關鍵抉擇≥2/3）

兩人約在電腦教室做最後的調整。

程式跑起來了——螢幕上是亭瑄畫的角色在二弘寫的程式世界裡活動。兩人並肩看著成品。

亭瑄小聲說：「這是我們一起做的。」
二弘：「⋯⋯嗯。」
亭瑄：「學長，專題交了以後⋯⋯你還會跟我一起寫程式嗎？」

二弘轉過頭看她。窗外遠處有煙火（附近廟宇的活動）。

二弘：「⋯⋯你先看一下專題。」
亭瑄：「蛤？」
二弘：「你輸入⋯⋯」（說了一串特定的指令）

螢幕上跳出了一段隱藏訊息——二弘偷偷寫的 Easter egg：

> 梁亭瑄，我不太會說話。
> 但是和你 pair programming 的這一年，
> 是我人生最少 bug 的時期。
> 如果可以的話，我想跟你繼續 commit 下去。
> // 這段程式碼沒有 expiry date

亭瑄讀完之後，眼眶紅了，然後笑得趴在鍵盤上。

「這是我看過最爛的情書⋯⋯」
（抬起頭，眼睛亮亮的）
「但也是最好的。」

二弘的耳朵紅得像要燒起來。「⋯⋯所以你的回覆是？」
亭瑄：「你覺得呢？笨蛋學長。」
然後她伸手牽住了他的手。

二弘的另一隻手還放在鍵盤上，完全不知道該怎麼辦。
但被牽住的那隻手，握了回去。

#### 【Good End 路線】（AP≥60, TP≥60）

同樣的最後一夜。程式完成了。

但二弘說不出口。他坐在電腦前，腦子裡的話跑了一千遍迴圈，沒有一個版本通過自己的 code review。

亭瑄看著他欲言又止的樣子，嘆了口氣。

第二天，二弘打開電腦——桌面上多了一個 txt 檔案：

> 吳二弘學長：
> 我喜歡你。
> 不是程式語言，是人類語言。
> 請回覆 true 或 false。
> —— 梁亭瑄

二弘一個人在電腦教室坐了半小時。

然後在檔案裡加了第二行：

> true // 但我不確定你會不會後悔 debug 出這個結果

存檔。離開。

隔天亭瑄打開檔案，看到那行回覆。
笑了出來。又哭了出來。
然後加了第三行：

> 我不會。而且這個 bug 是 feature，不接受 patch。

#### 【Normal End 路線】（AP≥40 或 TP≥40）

最後一夜。程式完成了。

兩人都有話想說，但都沒有說出口。空氣裡有很多東西，卻沒有人伸手去抓。

二弘：「⋯⋯專題完成了。」
亭瑄：「嗯。」
二弘：「⋯⋯辛苦了。」
亭瑄：「學長也是。」

她等了一會兒。他沒有再說什麼。
她站起來：「那⋯⋯明天報告見。」
二弘：「⋯⋯嗯。」

門關上之後，二弘對著螢幕打了一行字又刪掉。反覆了很多次。
最後什麼都沒留下。

#### 【Comedy Bad End 路線】（AP<40, TP<40）

專題勉強完成了，但兩人之間沒有建立起真正的默契。二弘還是獨行俠，亭瑄還是想轉科。

最後一夜沒有特別的場景——各自做完自己的部分，道了再見。
像普通的同學一樣。

## 本章關鍵情感節點

1. **倒數的焦慮** — 第一次害怕「結束」，因為結束意味著失去相處的理由
2. **畢業紀念冊** — 寫了很久，只寫得下一行的留言（草案）
3. **告白（依路線）** — 程式裡的 Easter egg / txt 檔 / 未說出口的話 / 什麼都沒有

## 本章 Running Gags 高潮

- README 情書系列最終章：Easter egg 或 txt 告白
- 小芸的統計達到終極版本（Python 爬蟲）
- 阿成受不了了的吐槽：「你們兩個到底要拖到什麼時候」
- 便當攻防戰：亭瑄的便當上用海苔排了心形（「你可以假裝沒看到」）
