## 章節概要

寒假三週，電腦教室關門，兩人第一次這麼久沒見面。二弘回阿嬤的小吃店幫忙過年，順手把國中用 Python 寫的記帳程式改寫成 Java；亭瑄在家自學，卻一直在等手機響。見不到面，反而讓兩人開始察覺對方有多重要——但都還沒有承認。

## 場景流程

### 場景 1：阿嬤的小吃店（學長視角獨有）

- 春節前是小吃店最忙的時候，二弘在店裡幫忙點餐、算帳
- 翻出國中時用 Python 幫阿嬤寫的記帳程式（角色設定：從此覺得「寫程式比跟人說話簡單」）
- 決定改寫成 Java。阿嬤的錢櫃只有阿嬤能開，所以金額要設成 `private`
- 阿嬤發現他一直在看手機，問起那個做便當的同學。二弘差點把帳算錯

### 場景 2：等手機響（學妹視角獨有）

- 在家照著二弘的 PDF 自學，寫到一半就去看 LINE
- 寒假沒有便當可以拍，改拍年菜傳給他（接續第五章「今天沒人吃所以拍了一張紀念」）
- 他回得很慢，而且每次都只有幾個字

**和小芸的對話（原第四章）：**
- 傳訊息給小芸：「你覺得⋯⋯如果一個人會默默幫你買飲料、保留你畫的圖、幫你整理考試筆記，但從來不會說好聽的話——」
- 小芸：「停。你是在問我，吳二弘是不是喜歡你嗎？」
- 亭瑄：「不是！！！我是在問⋯⋯一般性的問題！」
- 小芸：「吳學長提及次數：放寒假以後不減反增。你已經不是一般了。」
- （「放寒假以後不減反增」是改寫，原句是「今日已破 20」，那句留在第四章）

### 場景 3：除夕夜（共通）

- 兩人都在家，都打開了對方的對話框。打了又刪，刪了又打（第三章冷戰時二弘也這樣）
- 午夜十二點，訊息到了。依選項不同，可能是兩人同時送出「新年快樂」，也可能是對方先傳

**學長視角：**
- 第三章的「沒有她在的電腦教室，好安靜」，變成「沒有她的寒假，好安靜」
- 第六章標成 `// TODO` 的那件事又冒出來了。他把它往後延

**學妹視角：**
- 看著訊息笑出來，然後愣住
- 第一次認真想小芸那個問題。想到一半，把手機蓋在枕頭下面

## 本章關鍵情感節點

1. **見不到面** — 第一次這麼久沒見面，才發現對方佔了多少時間
2. **阿嬤的記帳程式** — 二弘回到寫程式的起點，這次寫給阿嬤，心裡卻想著另一個人
3. **小芸的問題** — 亭瑄第一次被問到核心，否認了，卻開始認真想（第八章才想通）

## 程式題方向

- 學長（修／教）：改寫阿嬤的記帳程式。`private int balance`、`deposit()`、`getBalance()`，不能存負數；「整家店今天的營業額」用 `static`
- 學妹（寫）：自己寫一個扭蛋包類別。扭蛋數量設成 `private`，只能透過 `add()` 增加（接續第一章的七個、八個）

## 選項方向（草案）

- 學長：除夕夜——先傳「新年快樂」（熱絡）／等她先傳（冷淡）
- 學妹：同一個時刻——先傳（熱絡）／等他先傳（冷淡）

數值照 `branching.md` 的預算。
