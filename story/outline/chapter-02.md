# 第二章：「Hello World」

## 基本資訊

| 項目 | 內容 |
|------|------|
| 時間 | 9月中旬～下旬 |
| 主題 | 磨合・教與學・第一次合作 |
| 程式隱喻 | Hello World = 一切的起點，最簡單也最重要的第一步 |

## 章節概要

兩人開始了每天放學後的電腦教室時光。二弘嘗試教亭瑄基礎程式，發現「教人」比自己寫難一百倍。亭瑄在挫折和小突破之間搖擺。專題第一階段報告逼近，兩人在磨合中找到了「勉強能合作」的節奏。

## 場景流程

### 場景 1：放學後的電腦教室（日常連續場景）

**Day 1 — 變數**
- 二弘在白板上寫了 `int x = 5;`
- 亭瑄：「所以⋯⋯ int 是什麼？」
- 二弘（深呼吸）：「整數。」
- 亭瑄：「為什麼不直接寫中文？」
- 二弘張了張嘴，第一次認真思考這個問題

**Day 3 — for 迴圈**
- 亭瑄：「所以 for 迴圈就是⋯⋯把同一件蠢事做一百遍？」
- 二弘：「⋯⋯技術上來說是。但我不會用『蠢事』這個詞。」
- 亭瑄：「那你用什麼詞？」
- 二弘：「重複執行的指令區塊。」
- 亭瑄：「⋯⋯果然是外星語。」

**Day 5 — Hello World**
- 亭瑄寫出人生第一個成功執行的程式
- 不是標準 Hello World，而是 `System.out.println("梁亭瑄天才！");`
- 看到 console 印出文字的瞬間，從椅子上跳起來，開心得轉了三圈
- 二弘看著她：「⋯⋯你這程式的輸出文本有嚴重的事實錯誤。」
- 亭瑄（瞪）：「你再說一次？」
- 二弘（小聲）：「⋯⋯恭喜。」
- 亭瑄（笑了）：「你看，你也會說人話嘛。」

### 場景 2：便當攻防戰首次展開

**共通事件：**
- 某天中午，亭瑄拿出便當盒，裡面是兩份
- 「我媽做太多了啦，你要不要？」（事實：她特別拜託媽媽多做的）
- 二弘手上拿著今天的第三個便利商店飯糰
- 亭瑄看到飯糰臉都皺了：「你每天都吃這個嗎？」
- 二弘：「方便。」
- 亭瑄把便當直接放到他桌上：「今天開始你吃這個。」
- 二弘：「⋯⋯我沒有請你——」
- 亭瑄：「我不想看著我的專題夥伴因為營養不良倒在電腦前面。那樣我的專題就完了。」
- 二弘看著便當（明顯比飯糰好吃一百倍）：「⋯⋯那我只是不想浪費食物。」

**學長視角獨有：**
- 二弘打開便當，裡面的菜色擺得很整齊，還有一個用海苔剪的小圖案
- 內心 OS：「⋯⋯這不像是『做太多』的樣子。」
- 但還是安靜地吃完了。飯糰收進書包（隔天還是帶了，但沒吃）

**學妹視角獨有：**
- 偷看二弘吃便當的表情——他沒說好吃，但吃的速度明顯比平常快
- 傳訊息給小芸：「他吃完了！」
- 小芸：「所以呢？」
- 亭瑄：「⋯⋯沒有所以啊，只是跟你說一下。」
- 小芸：「今日吳學長提及次數：3。包含此訊息。」

### 場景 3：第一次合作——專題第一階段報告

**共通事件：**
- 專題第一階段：繳交提案報告（文件 + 5 分鐘口頭簡報）
- 分工：二弘寫技術規格，亭瑄做簡報設計
- 亭瑄做了一份超華麗的 PPT——動畫飛來飛去、每頁都有她畫的插圖、配色很好看
- 但重點完全搞錯：花了三頁講「介面要多好看」，技術架構只有半頁
- 二弘看完：（深呼吸）（再深呼吸）「⋯⋯這個方向不太對。」
- 亭瑄：「哪裡不對！我做了三天欸！」
- 二弘很認真地解釋了為什麼技術架構更重要，但——保留了亭瑄畫的所有插圖
- 亭瑄：「你幹嘛留這些？」
- 二弘（看向螢幕）：「⋯⋯反正版面需要圖片。」

**★ 分歧選項：**

**（學長視角時）：** 面對簡報分工——

- **選項 A「讓她參與」：** 「你負責重新排版面，我把技術的部分補上。你的圖⋯⋯留著。」（AP+3, TP+10）
- **選項 B「自己包辦」：** 「算了，我來改就好。你⋯⋯先去背口頭報告的稿子。」（AP+5, TP+3）

**（學妹視角時）：** 面對簡報被大改——

- **選項 A「虛心接受」：** 「好吧⋯⋯學長你教我什麼是技術架構，下次我不會搞錯了。」（AP+3, TP+10）
- **選項 B「不服氣但配合」：** 「我的圖你至少要留三張！這是底線！」（AP+5, TP+3）

### 場景 4：報告後的傍晚

**共通事件：**
- 報告順利完成，王葉聖老師給了「不錯，但技術細節可以再深入」的評語
- 放學後，兩人在教室門口
- 二弘：「今天的報告⋯⋯你的口頭簡報比我預期的好。」
- 亭瑄：「這是稱讚嗎？」
- 二弘：「是陳述事實。」
- 亭瑄（笑）：「好吧，我就當作是稱讚了。」
- 二弘轉身要走，亭瑄叫住他：「學長！」
- 二弘回頭
- 亭瑄：「明天見。」
- 二弘：「⋯⋯嗯。」

**學長視角獨有：**
- 走在回家的路上，發現嘴角在上揚
- 用力壓下去。沒壓住
- 到家後阿嬤問「今天怎麼回來比較晚」
- 「在做專題。」
- 阿嬤：「你以前不是都一個人做？」
- 「⋯⋯今年規定不一樣。」

**學妹視角獨有：**
- 回家路上，用手機查「什麼是技術架構」
- 查著查著變成查「怎麼讓學程式變簡單」
- 再查著查著變成「編譯器 是什麼意思」（想搞懂學長的綽號）
- 小芸訊息：「你在幹嘛？」
- 亭瑄：「查東西。」
- 小芸：「查什麼？」
- 亭瑄：「⋯⋯程式的東西。」
- 小芸：「你什麼時候開始對程式有興趣了？」
- 亭瑄（慌張）：「才不是有興趣！是專題要用！」

## 本章關鍵情感節點

1. **教與學的過程** — 二弘學會放慢速度，亭瑄學會不放棄
2. **Hello World 的喜悅** — 亭瑄的第一個程式，二弘第一次看到她認真後的笑容
3. **便當** — 關心的開始，兩人都假裝理由很正當
4. **保留插圖** — 二弘嘴上嫌棄但行動尊重，這是他表達在意的方式
