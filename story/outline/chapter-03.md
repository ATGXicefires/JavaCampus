# 第三章：「例外處理」

## 基本資訊

| 項目 | 內容 |
|------|------|
| 時間 | 10月（第一次段考前後） |
| 主題 | 衝突・冷戰・和解 |
| 程式隱喻 | 例外處理 = 程式出錯時的應對機制，也是人與人之間出問題時的修復方式 |

## 章節概要

段考逼近，二弘焦慮於專題進度和考試雙重壓力，脫口說了傷人的話。亭瑄消失了好幾天。兩人各自在冷戰中意識到對方在自己心中的份量，最終以各自的方式達成和解。

**這一章包含全篇最重要的關鍵分歧點，直接決定 True End 和 Good End 的走向。**

## 場景流程

### 場景 1：壓力累積（段考前一週）

**共通事件：**
- 專題進度落後（亭瑄的程式部分進步不夠快）
- 段考在即，兩人見面時間減少
- 二弘開始獨自加班趕進度，臉色越來越差
- 亭瑄感覺到氣氛不對，但不知道該怎麼辦

**學長視角：**
- 內心計算：專題進度 38%、段考準備 50%、睡眠時間被壓縮到 4 小時
- 阿成：「你臉色很差欸。」二弘：「正常。」阿成：「你的『正常』已經不在人類的範圍內了。」
- 看著亭瑄寫的程式碼——一個月了還是會犯基礎錯誤
- 焦慮不斷累積

**學妹視角：**
- 每天回家都在看二弘給的教材，但越看越覺得自己學得太慢
- 看到二弘獨自加班的模樣，有一種「果然我只是在拖後腿」的罪惡感
- 便當還是每天帶，但二弘開始邊吃邊打字，不再像之前那樣停下來

### 場景 2：爆發（電腦教室・放學後）

**共通事件：**
- 亭瑄寫了一段程式交給二弘看，裡面有好幾個基礎錯誤
- 二弘沉默了很久，然後開始修改——全部重寫
- 亭瑄看著螢幕：「⋯⋯我寫的全部不能用嗎？」
- 二弘（沒回頭）：「這個進度根本來不及。」
- 亭瑄：「我已經很努力了啊⋯⋯」
- 二弘（焦慮爆發）：「可是不夠。」
- 空氣凝結
- 亭瑄：「⋯⋯你是說我不認真嗎？」
- 二弘（依然看著螢幕，沒意識到自己的話有多重）：「我是說，以目前的速度——」
- 亭瑄收拾東西，站起來：「我知道了。」
- 門關上。教室裡只剩二弘和跑不完的程式碼
- 二弘直到門關上才轉過頭，對著空椅子發呆

### 場景 3：冷戰（持續 4-5 天）

**學長視角：**
- 第 1 天：開 LINE 看了亭瑄的對話框，打了「今天的進度」，刪掉。打了「你還好嗎」，刪掉
- 第 2 天：在教室裡看到亭瑄的空位，手停在鍵盤上
- 第 3 天：阿成直接講了——「你到底跟那個一年級怎麼了？她這幾天都沒出現。」二弘：「⋯⋯我好像說了不該說的話。」阿成：「你什麼時候會說『該說的話』了？」
- 第 3 天夜裡：做了一件事——打開文件，花了整夜把段考重點整理成筆記，每一頁都用螢光色標記。最後壓縮成 zip 檔
- 第 4 天：傳了那個壓縮檔到 LINE。訊息只有：「段考用的筆記.zip」。zip 裡面除了筆記，還有一個 README.md：「如果看不懂可以問我。時間不限。」

**學妹視角：**
- 在小芸家窩了幾天，不想回電腦教室
- 小芸問她：「你在生氣嗎？」亭瑄想了很久：「⋯⋯不是生氣。是難過。」
- 小芸：「如果換成別人說一樣的話，你會這麼在意嗎？」亭瑄沒回答
- 收到二弘傳的 zip 檔——打開來，看到每一頁都有仔細標記的重點
- 翻到 README.md，看到「如果看不懂可以問我。時間不限。」
- 眼眶紅了。跟小芸說：「他到底是怎樣⋯⋯明明講話那麼難聽，做的事卻⋯⋯」
- 小芸：「所以你到底是生氣還是心動？」亭瑄把抱枕砸過去

### 場景 4：和解（★★★ 核心關鍵分歧點）

**共通事件：**
- 段考結束後的走廊上，兩人撞見彼此
- 短暫的沉默

**★★★ 關鍵分歧選項：**

**（學長視角時）：** 你要——

- **選項 A「主動開口」：** 二弘鼓起勇氣：「上次那句話⋯⋯我的表達有 bug。」亭瑄：「⋯⋯你是在道歉嗎？」二弘：「⋯⋯可以這樣理解。」亭瑄笑了：「你這個人真的是⋯⋯」（AP+10, TP+15，解鎖 True End 路線必要旗標）
- **選項 B「等她先說」：** 站在原地，想開口但說不出來。最後是亭瑄先打破沉默：「⋯⋯那個筆記，謝謝。」二弘：「⋯⋯嗯。」氣氛解凍了，但有什麼沒有被好好處理（AP+5, TP+5）

**（學妹視角時）：** 你要——

- **選項 A「先原諒」：** 亭瑄主動走過去：「學長，筆記我收到了。⋯⋯你的 README 寫得比道歉好多了。」二弘愣住，然後小聲：「⋯⋯對不起。」亭瑄（第一次聽到他道歉，有點受寵若驚）：「嗯，我知道了。」（AP+10, TP+15，解鎖 True End 路線必要旗標）
- **選項 B「保持距離」：** 點了點頭，禮貌但沒有太多話：「⋯⋯段考辛苦了。」然後走了。二弘看著她的背影，知道表面上沒事了，但裡面有裂痕（AP+5, TP+5）

### 場景 5：重新開始

**共通事件：**
- 兩人重新回到電腦教室
- 氣氛跟之前不太一樣——更小心了，但也更認真了
- 二弘第一次問：「你覺得這個功能怎麼做比較好？」（以前都是他直接決定）
- 亭瑄愣了一下，然後認真想了想：「⋯⋯如果是使用者的話，我會想要這邊有個按鈕。」
- 二弘看著她指的位置，想了想：「⋯⋯可以。」

## 本章關鍵情感節點

1. **爆發** — 壓力下的真實反應，不是壞心，是不會處理情緒
2. **段考筆記.zip + README.md** — 二弘的「道歉方式」：他不會說，但會做。README 情書系列的起點
3. **和解的選擇** — 全篇最重要的分歧。主動的一方承擔了風險，也建立了最深的信任
4. **「你覺得怎麼做比較好？」** — 二弘第一次把亭瑄當作「夥伴」而非「學生」

## 本章情感轉折

冷戰期間，兩人各自意識到一件事：

- 二弘：「沒有她在的電腦教室，好安靜。⋯⋯原來我已經習慣了那個吵鬧的聲音。」
- 亭瑄：「我不是在生那句話的氣。我是在難過——因為說那話的人是他。如果是別人，我根本不會在意。」

這是兩人第一次意識到，對方在自己心裡佔了一個位置。只是兩個人都還不知道，那是什麼位置。
