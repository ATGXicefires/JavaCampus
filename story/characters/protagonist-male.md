## 性格

**核心：** 高功能社恐。程式能力極強、邏輯一流，但面對人際互動就像遇到 NullPointerException——直接當機。不是冷漠，是真的不知道怎麼跟人相處。嘴巴很毒但心很軟，吐槽是他唯一會的溝通方式。

- 認真到偏執，一個 bug 不修完不會走
- 極度不善表達情感，但會用行動（而非言語）表示關心
- 有責任感，答應的事一定做到
- 對自己要求極高，習慣一個人扛所有事

## 說話方式

**一句話：** 短、平、沒有語助詞。先停頓，再說一件事。

- **開頭常是「⋯⋯」**：他不是沒話說，是在組織語言。越在意的話，前面停得越久。
- **一句只說一件事**：「⋯⋯吳二弘。坐。」「修好了。」「方便。」很少超過兩個短句。
- **不用語助詞**：嘴上幾乎不出現「啦、欸、喔、嘛、耶」。最多只有「嗯」。
- **不用驚嘆號**：生氣、慌張都不會變大聲，只會變得更短、更硬（第三章：「可是不夠。」）。
- **問感受，答事實**：被問「這是稱讚嗎？」會回「是陳述事實。」
- **稱讚、道謝、道歉都要包裝**：用術語包裝（「我的表達有 bug。」），或者聲音很小、停很久才說（「⋯⋯做得好。」「⋯⋯謝謝。」）。
- **找藉口的固定句型**：「只是剛好⋯⋯」「只是不想浪費。」「反正⋯⋯」「⋯⋯比喻。」
- **臉紅的藉口**：冷氣、風、暖氣。藉口被戳破後只會說「⋯⋯會。」或沉默。
- **教人的方式會變**：第一章滿口術語（「字串常值」「靜態欄位」「標準輸出串流」）；從 PDF 筆記開始改用生活比喻（盒子、滷肉飯、扭蛋）。這個轉變是角色弧線的一部分，第一章以後不要再讓他對亭瑄講第一章那種術語連發。

## 內心 OS

OS 是他話最多的地方，跟嘴上說出口的差很多。寫他的 OS 照這幾條：

1. **用程式邏輯分析狀況**：「expected output 是『了解』。actual output 是『外星語』。」
2. **會不自覺地計數、計時**：「耗時，三小時十二分。」「看了十一次。」「⋯⋯七個。」數字一定要精確。
3. **發現自己在意，馬上否認**：「——不，我為什麼在數。」「——不，這不在變數範圍內。」「——我在幹嘛。」用破折號開頭。
4. **自嘲**：「我的社交能力，大概跟 deprecated API 差不多。」「現實沒有 Ctrl+Z。」
5. **嘴硬到 OS 裡也一樣**：「我沒有在等。只是剛好在看門的方向。」
6. **不在 OS 裡說「喜歡」**：第九章以前，連在 OS 裡都不承認。第六章把那種感覺標成 `// TODO`，第九章在火車上才處理掉。

## 背景

- 父母離異，跟開小吃店的阿嬤住在臺南舊市區
- 家境普通，目標靠技優甄審上大學、減輕家裡負擔
- 國中時自學 Python 幫阿嬤寫記帳程式，從此覺得「寫程式比跟人說話簡單」
- 資訊科成績頂尖，技能檢定和專題都想拚最好

## 強項

- 程式設計能力全校第一
- 邏輯推理
- 獨立解決問題
- 對技術細節的執著

## 弱點

- 社交恐懼
- 不會表達情感（會說「這很簡單啊你怎麼不會」然後被瞪）
- 過度自我要求，不願意依賴別人
- 完全不懂怎麼「教」別人

## 喜劇特質

1. **吐槽體質** — 功力一流但本人完全不覺得自己在吐槽，真心認為只是在「陳述事實」
2. **程式術語口癖** — 一緊張就碎念（「我現在的心跳頻率已經超出預期的 standard deviation」）
3. **食物沙漠** — 對吃完全沒品味，可以連吃三天便利商店飯糰。被亭瑄發現後遭強烈譴責
4. **阿嬤的絨毛玩偶** — 書包裡放滿阿嬤塞的「護身符」，被亭瑄發現後整個人僵掉
5. **無意識的溫柔** — 默默買飲料、默默改簡報、默默寫筆記，但嘴上永遠否認（「只是剛好順路」「只是不想浪費」）

## 角色弧線

開始：獨行俠，認為一個人效率最高，不需要也不想跟人合作

→ 中段：被迫學習「教人」和「等人」，發現自己習慣了有人在身邊吵吵鬧鬧

→ 結尾：學會表達情感和依賴別人，理解「效率」不是人生的唯一指標

## 搭檔反應（`reactions.json`）

- **`二弘`**（學妹視角，他在旁邊看她寫）：一句提示，不給答案。指出去哪裡看（「看紅字標的那一行。」），不說要改成什麼。稱讚只用「嗯。」「可以。」「⋯⋯恭喜。」
- **`二弘OS`**（學長視角，他自己寫）：把錯誤跟自己的社交失敗連在一起自嘲（「Build success。社交方面還是 failed。」）。第一章的 OS 繞著「她會不會生氣」打轉；之後各章要換成那一章他在煩惱的事。

## 寫他的時候不要

- **不要讓他大笑、大喊、講長篇的情話。** 第十一章的告白是寫在 Easter egg 裡的文字，不是當面說的。
- **不要讓他真的冷漠或惡意。** 他的毒舌是「陳述事實」，不是嘲笑；他從不拿別人的外表或家境開玩笑。
- **不要讓他主動撩人。** 他的心動都是被動發現的，而且他會先否認。
- **不要讓他講出自己的心情分析。** 他的心情交給 OS、動作和別人（阿成、阿嬤）的觀察。
- **嘴上不要出現「啦、欸、喔、嘛」。**
- **不要拿父母離異來博取眼淚。** 這只是他跟阿嬤住、想減輕家裡負擔的原因（`story-overview.md`：不是沉重的青春傷痛文學）。
