# 梁亭瑄 — 學妹

## 基本資料

| 項目 | 內容 |
|------|------|
| 姓名 | 梁亭瑄 |
| 年級 | 一年級・資訊科 |
| 代號 | 「Runtime Error」（學長心中的稱呼——她總是在意想不到的時候製造意外狀況） |
| 外貌 | 中等身高，短馬尾，眼睛很亮。制服永遠整整齊齊，但書包上掛了一堆扭蛋玩具和鑰匙圈。笑起來會露出虎牙 |

## 性格

**核心：** 活力充沛的直覺型思考者。社交能力 MAX 但對程式完全無感。不是笨，而是她的聰明用在「讀人」而非「讀 code」上。擅長觀察別人的情緒和需求，是天生的氣氛製造機。做事衝動但很少出於惡意，通常是「想到什麼就做了」。

- 開朗外向，跟誰都能聊起來
- 只對學長傲嬌：對別人有話直說，對他卻是關心要先找藉口、稱讚完要收回（見「對學長的傲嬌」）
- 感情直覺敏銳，但對自己的心意反而後知後覺
- 面對困難先抱怨再處理，但從不真的放棄
- 有創意，擅長把抽象概念視覺化

## 說話方式

**一句話：** 想到就說，語助詞很多，情緒全寫在句尾。

- **語助詞很多**：「啦、欸、喔、嘛、耶、蛤」都會用。跟二弘正好相反。
- **驚嘆號、「！？」**：驚訝和抗議都很大聲（「它、它為什麼紅了！？」）。開心到極點用「！！！」。
- **緊張會結巴**：第一個字重複（「對、對不起。」「怎、怎麼了？」）。
- **先抱怨，再照做**：「每天！？」→「好啦好啦。每天就每天。」
- **把術語翻成生活用語**：「所以 Java 就是外星語。」「for 迴圈就是把同一件蠢事做一百遍？」她不是在裝傻，她真的這樣理解，而且常常翻得意外準。
- **愛取名字**：把東西當成人。紅字時會說「小白是不是討厭我們？」
- **害羞時收回**：話說到一半發現不對，用「⋯⋯算了沒事。」或改口收掉。被逼急了就用「才沒有！」否認。
- **偶爾反殺**：二弘在感情上比她還呆時，她會冷靜地吐槽回去（「教室沒有暖氣。」）。反殺時句子會突然變短、變平，跟平常的語氣反差越大越好笑。

### 常用句

| 情況 | 她會說 |
|---|---|
| 聽不懂 | 「⋯⋯蛤？」「你說的每個字我都聽得懂，連在一起就聽不懂！」 |
| 抗議 | 「學長自己抽籤的時候也遲到啊！」（抓對方的語病回擊） |
| 開竅 | 「我懂了！！！」（經常接一句「⋯⋯大概懂了。」） |
| 被稱讚 | 「這是稱讚嗎？」→「好吧，我就當作是稱讚了。」 |
| 嘴硬 | 「學長好厲害！⋯⋯我是說，還可以啦。」 |
| 約定 | 「明天見。」（第一學期說了一整學期） |

## 對學長的傲嬌

**一句話：** 對所有人都直來直往，只有對他，關心要先包裝、好話要馬上收回。

### 什麼時候會傲嬌

- **對象是二弘本人**，或者**話題是二弘**（小芸、阿嬤、阿成提到他的時候）。
- 其他時候都不傲嬌。對小芸、阿成、王老師、阿嬤、同學，她是開朗外向、有話直說的那個她。
- 這個反差本身就是線索：小芸和阿成一看到她變得嘴硬，就知道話題又是學長了。

### 怎麼說

| 句型 | 例子 |
|---|---|
| 關心先找正當理由 | 「我不想看著我的專題夥伴因為營養不良倒在電腦前面。那樣我的專題就完了。」 |
| 東西說成多出來的 | 「我媽做太多了啦，你要不要？」（其實是她拜託媽媽多做的） |
| 稱讚完馬上收回 | 「學長好厲害！⋯⋯我是說，還可以啦。」 |
| 好話夾在壞話中間 | 「雖然學長你講話真的很機車，但⋯⋯至少你有認真在教。」 |
| 被戳破就大聲否認 | 「才沒有！我只是⋯⋯覺得他一個人吃飯糰很可憐！」 |
| 叫他笨蛋 | 「你這個笨蛋。」「笨蛋學長。」（只在真心話快藏不住的時候用） |

- 「哼」不要用。她的傲嬌是臺灣高中生的口氣，不是動畫腔。
- 嘴硬時一樣是她平常的語氣：語助詞、驚嘆號、結巴都還在。

### 怎麼破功

- **OS 從來不傲嬌。** 嘴上說「很討厭」，OS 已經在想「也許不是那麼討厭⋯⋯吧？」。玩家永遠看得到她真正的想法。
- **身體比嘴巴誠實**：嘴上嫌他，手已經把便當推過去；說完「還可以啦」，虎牙已經露出來了。
- **太開心的時候會忘記傲嬌**：第二章 Hello World 跳起來轉三圈、第五章衝去說「學長你看到了嗎！」。這種時候不要硬加嘴硬。
- **他難過或撐不住的時候不傲嬌**：第三章冷戰、第九章不想拖住他，她都是認真的。

### 隨章節變化

| 章 | 傲嬌的程度 |
|---|---|
| 1 | 一開始還不算傲嬌，是真心覺得他機車。雨中回頭那一刻冒出第一次「——不不不。很討厭。」，章末那句「雖然很機車，但⋯⋯」是傲嬌的雛形 |
| 2～7 | 完整的傲嬌：便當、嘴硬的稱讚、對小芸否認 |
| 8 | 察覺心意之後，嘴硬開始心虛：話還沒說完自己先臉紅 |
| 9～10 | 嘴硬變少，但說到心意的那一句還是會收回 |
| 11～12 | 最後一次傲嬌同時也是坦白：「你覺得呢？笨蛋學長。」 |

### 跟二弘的嘴硬怎麼分

兩個人都會否認，但方式相反，寫的時候不要混在一起：

| | 二弘 | 亭瑄 |
|---|---|---|
| 音量 | 小聲、停頓 | 大聲、搶著說 |
| 藉口 | 冷靜、聽起來合理（「只是不想浪費。」） | 慌張、越解釋越可疑（「才沒有！我只是⋯⋯」） |
| 被戳破 | 沉默，或「⋯⋯會。」 | 更大聲地否認，拿抱枕砸人 |
| 對誰 | 對所有人都一樣不會表達 | 只對學長 |

### 選項怎麼寫

學妹視角的選項，熱絡的多半是「坦率」，冷淡的多半是「嘴硬」。第五章已經是這樣：A「學長你看到了嗎！」、B「嗯，還好啦。」（但一直偷看他的反應）。第六～十章的對話選項也照這個方向寫。

## 內心 OS

1. **想到什麼就是什麼，然後自己吐槽自己**：「他看起來⋯⋯好累。等等，我幹嘛在意他累不累？」
2. **跟自己對話**：「梁亭瑄你冷靜。」「⋯⋯冷靜不了。」叫自己全名。
3. **觀察別人的細節**：二弘的 OS 是在數東西，她的 OS 是在讀人。「⋯⋯他在看門口。啊，移開了。假裝在看螢幕。」「⋯⋯咦。耳朵紅了。」
4. **說出口的跟心裡想的方向相反**：嘴上說「很討厭」，OS 已經在想「也許不是那麼討厭⋯⋯吧？」，然後再否認一次。
5. **情緒轉得很快**：從生氣到心軟，可能只需要一個畫面。
6. **第八章以前，OS 也不承認喜歡**：她讀得懂所有人，唯獨讀不懂自己。第八章「糟了。」那一刻才承認。

## 背景

- 家在臺南市區，父母都是公務員，家境穩定
- 原本想讀普通高中，因國中畢業成績不如預期，被父母安排進成大附工（「至少學個一技之長」）
- 對資訊科沒有熱情，一開始甚至想轉科去廣設科（喜歡畫畫）
- 在跟學長合作的過程中，慢慢發現程式可以是另一種「創作」

## 強項

- 人際溝通
- 情緒觀察力
- 創意發想（專題的「點子」通常是她想的）
- 不怕失敗的勇氣
- 畫畫能力（UI 設計天賦）

## 弱點

- 程式基礎為零
- 容易分心
- 有時太直覺衝動
- 面對困難容易先抱怨

## 喜劇特質

1. **程式翻譯機** — 把術語全部「重新翻譯」（「所以 for 迴圈就是⋯⋯把同一件蠢事做一百遍？」「⋯⋯技術上來說是。」）
2. **戲劇化開竅** — 學東西慢但突然懂的瞬間超戲劇化（從椅子上跳起來喊「我懂了！！！」，嚇到整間電腦教室）
3. **萬物命名癖** — 筆電叫「小白」、USB 叫「阿隨」、debug 用的 printf 叫「報平安」
4. **便當攻勢** — 每天帶超豐盛便當然後「不小心」多帶一份，硬塞給只吃飯糰的學長
5. **否認體質** — 被小芸指出在意學長時，永遠第一反應是否認（「才沒有！我只是⋯⋯覺得他一個人吃飯糰很可憐！」）
6. **只對學長傲嬌** — 跟誰都有話直說，唯獨對他要繞一圈；全班都看得出差別，只有她自己沒發現

## 角色弧線

開始：對資訊科毫無歸屬感，想轉科，覺得程式是外星語言

→ 中段：透過合作發現程式可以是「創作」，開始有了自己的目標。也發現學長不是冰冷的機器，而是不懂得表達的溫暖

→ 結尾：找到了自己的方向（結合設計與程式的 UI/UX），也找到了想一起走下去的人

## 代表物

- 掛滿扭蛋的書包
- 手繪的 UI 草圖
- 每天不同口味的豐盛便當

## 習慣與小動作

- 書包上的扭蛋會變多：第一章第一天七個，第三天八個。二弘每次都會不自覺地數
- 筆電叫「小白」、USB 叫「阿隨」；第六章學了物件以後，每個物件都要取名字
- 畫圖時哼歌、咬筆蓋、咬嘴唇
- 書念半小時就滑手機（第五章以後能念兩個小時）
- 有事第一個打電話給小芸，常常講到一半就說「算了，明天再跟你講」
- 截圖傳給小芸，再傳一句沒講完的話
- 收到重要的紙條和卡片，夾進筆記本

| 喜歡 | 苦手 |

## 家人

- **媽媽**：每天做便當。第二章被拜託「明天便當可以多做一份嗎？」，「多做給誰？」「⋯⋯專題夥伴啦！」。只有聲音，名冊外，灰色名牌。
- **爸媽的期待**：「至少學個一技之長」。爸媽不是壞人，只是保守。第八章她沒有推翻這個期待，而是用 `super` 留下爸媽那一部分，再接上自己的版本。
- 〔新擬〕爸爸在劇本裡不出場；需要時用「爸媽」一起帶過。

## 跟其他人

- **二弘**：見上面「各章的狀態」和「對學長的傲嬌」。她是兩人之中先伸手的那一個（便當、拉他上天台），但伸手時一定附一個藉口；說到心意，她也會退縮。
- **小芸**：國中同班的閨蜜，什麼都跟她說。會抱怨小芸補刀，但最需要人的時候第一個去小芸家。
- **阿成**：〔新擬〕叫他「阿成學長」。知道他在偷拍、在播報，會瞪他，但不討厭他。
- **王老師**：老師一句「UI 不錯。是你畫的？」對她很重要，是第一次在資訊科被大人肯定。
- **阿嬤**：第五章第一次見面，被一句「他說你做的便當很好吃」弄得紅著臉跑走。

## 搭檔反應（`reactions.json`）

- **`亭瑄`**（學長視角，她在旁邊看他寫）：好奇、吵、替電腦配音（「它跑一半就跌倒了欸！」）。稱讚他以後一定補一句嘴硬。
- **`亭瑄OS`**（學妹視角，她自己寫，〔細綱〕新加的鍵）：跟自己對話、一邊寫一邊想到學長又否認（「⋯⋯我才不是在算學長的事。我是在練習。」）。

## 寫她的時候不要

- **不要把她寫成笨蛋或傻白甜。** 她學程式慢，但讀人很快、很準。她的翻譯常常是對的。
- **不要讓她真的放棄。** 她會抱怨、會跑走，但隔天都會回來。
- **不要讓她一直吐槽二弘。** 她的反殺是偶爾的，次數一多就沒有反差了。
- **不要讓傲嬌變成兇。** 她嘴硬，但不罵人、不動手打他、不說真的會傷人的話。拿抱枕砸的是小芸。
- **不要讓她對別人傲嬌。** 對學長以外的人，她都是開朗外向的。
- **不要讓她在二弘面前大哭。** 難過時她會走掉；眼眶紅可以，崩潰留給小芸那邊或結局。
- **不要讓爸媽變成反派。** 轉科的掙扎是她自己的方向問題，不是家庭衝突。
