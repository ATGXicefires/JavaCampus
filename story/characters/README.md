# 角色設定

寫劇本、寫 `reactions.json` 的台詞之前，先看這裡。

| 檔案 | 內容 |
|---|---|
| `protagonist-male.md` | 吳二弘 |
| `protagonist-female.md` | 梁亭瑄 |
| `supporting.md` | 阿成、小芸、王老師、阿嬤、名冊外的角色 |

每個角色都有這幾段：說話方式、內心 OS（主角）、情緒怎麼表現、各章的狀態或出場、搭檔反應、寫的時候不要。

## 標記

- 沒有標記：取自 `story/outline/`、`story/assets/`、`story/detail/`、第一章劇本或 `design/`，有出處。
- 〔新擬〕：這次補上的設定，原本的資料裡沒有，待審。
- 〔草案〕：照抄細綱的草案標記，那一章本身還沒定。

## 兩個主角的對照

寫共通場景時，同一件事兩邊的 OS 要不一樣：

| | 二弘 | 亭瑄 |
|---|---|---|
| OS 在做什麼 | 數東西、算時間、用程式分析 | 讀人、看細節、跟自己對話 |
| 發現自己在意 | 「——不，這不在變數範圍內。」 | 「——不不不。很討厭。超討厭。」 |
| 嘴上 | 短、沒有語助詞、不用驚嘆號 | 語助詞多、驚嘆號、結巴 |
| 臉紅 | 耳朵紅，怪冷氣 | 大聲否認，拿抱枕砸人 |
| 關心人 | 默默做，再補一個正當理由 | 直接塞給對方，再補一個正當理由 |
| 嘴硬的範圍 | 對所有人都不會表達 | 只對學長傲嬌，對其他人開朗外向 |
| 察覺心意 | 第九章 | 第八章 |

## 已統一的設定

原本各檔案寫法不一致，已經改成同一個版本：

- **木瓜牛奶的先後：** 照大綱和細綱的實際順序。亭瑄自己愛喝 → 第四章二弘第一次買給她 → 第五章亭瑄託阿嬤轉交給他，從此互相買 → 第十章不用問就知道對方的甜度。改了 `local-flavor.md` 的「演進」和 `protagonist-male.md` 的代表物。
- **「梁同學」的時間點：** 第一章學長視角的章末已經用了，稱呼演變改成「第一章章末起」。
