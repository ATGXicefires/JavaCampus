# 配角設定

---

## 李有成（阿成）— 學長的損友

| 項目 | 內容 |
|------|------|
| 年級 | 三年級・資訊科 |
| 定位 | 二弘唯一稱得上「朋友」的人 |
| 外貌 | 肩膀寬，刺刺的短髮，耳機掛在脖子上（`design/visuals.md`） |

### 性格
個性外向話多，跟二弘完全相反，但兩人從一年級就認識。像是二弘的「人類翻譯機」，常幫忙翻譯二弘那些聽起來很機車但其實是在關心的話。

### 喜劇定位
負責在旁邊搧風點火的「觀戰解說員」。動不動用電競比賽的語氣播報二弘和亭瑄的互動：

> 「OH！選手吳二弘打出了一手漂亮的 combo！但是！梁亭瑄選手完全沒有接收到！好可惜！」

### 故事功能
- 推動劇情的催化劑
- 在二弘不肯主動時製造「意外」讓兩人獨處
- 二弘的鏡子——讓二弘意識到自己的變化
- 偶爾給出意外正經的建議（反差感）

### 說話方式

**一句話：** 兩種模式。平常是吵的播報員，正經時突然變得很短、很直。

- **播報模式**：「OH！」「選手吳二弘」「這波——」「觀眾朋友們——」。叫人用「選手＋全名」。常常沒講完就被二弘打斷。
- **平常講話**：口語、語助詞多（「欸」「啦」「喔——」），愛拉長音（「喔——那你也沒有完全完蛋嘛。」）。
- **吐槽二弘**：抓住二弘的話往回丟。「你的『正常』已經不在人類的範圍內了。」「你什麼時候會說『該說的話』了？」
- **意味深長的重複**：把二弘的藉口原封不動唸回去。「嗯，趕專題。」「temporary X？」
- **正經模式**：不播報、不開玩笑，一兩句就講完（第八章：不說出口，她不會知道）。這種時候越少越好，一章最多一次。

### 習慣與小動作

- 耳機一直掛在脖子上
- 偷拍：第四章起有「照片證據」系列。發表會之後，他的照片進了製作團隊畫面的特別感謝
- 哭點很低：發表會在後排假裝擦眼淚，畢業典禮哭得比誰都大聲
- 寫程式不太仔細：第四章試玩專題 App，在答案後面多打一個空白被判錯，還堅持「我明明打對了！」
- 〔新擬〕平常在看電競比賽直播，播報腔就是從那裡學來的

### 跟其他人

- **二弘**：從一年級就認識。叫他「二弘」，播報時叫「選手吳二弘」，第十章起多了「temporary X 先生」。〔新擬〕二弘叫他「阿成」，但更常說「閉嘴」。
- **亭瑄**：第三章以前叫她「那個一年級的」，之後〔新擬〕叫「學妹」，播報時叫「梁亭瑄選手」。
- **小芸**：第十章在走廊上碰到，組成「讓他們在一起企劃委員會」。他提供二弘的異常行為，小芸提供提及次數。
- **王老師**：〔新擬〕會在導師時間憋笑，是全班最先起鬨的那一個。

### 各章出場

| 章 | 他做了什麼 |
|---|---|
| 1 | 雨夜的電腦教室：「選手吳二弘，開局第一天就把隊友氣跑！」；聽到「改成人話」後收起笑話 |
| 3 | 「你臉色很差欸。」；第 3 天直接問「你到底跟那個一年級怎麼了？」 |
| 4 | 偷拍兩人並肩看螢幕；隔天「嗯，趕專題」；校慶試玩 App，多打一個空白被判錯 |
| 8 | 難得正經地勸二弘：不說出口，她不會知道 |
| 9 | 瞄到筆記本上被劃掉的「亭瑄」，被一把搶回去 |
| 10 | 委員會成立；導師時間憋笑「temporary X？」 |
| 11 | 「你是打算寫一個 while(true) 把畢業典禮卡住嗎？」；在二弘的畢冊寫了一整頁；「你們兩個到底要拖到什麼時候」 |
| 12 | 發表會假裝擦眼淚；畢業典禮大哭；True End 騎機車經過大喊「學妹要遲到了——」 |

### 搭檔反應（`阿成`）

學長視角、二弘寫程式時在旁邊。播報腔，把錯誤當成比賽轉播（「選手吳二弘發現了 bug！這波——觀眾朋友們——」）；第十章起加上 `tx` 的調侃（「temporary X 先生，今天也很努力呢。」）。

### 寫他的時候不要

- **不要讓他壞心眼。** 他製造的「意外」都是為了二弘好，不會讓兩人真的難堪。
- **不要讓他搶戲。** 他推一把就退場，關鍵的話要留給兩個主角自己說。
- **不要讓正經模式變多。** 正經一出現就要有份量。
- 〔新擬〕**本篇不給他感情線。** 跟小芸只是觀戰聯盟，要不要發展留給 DLC 再決定。

## 燕韋芸（小芸）— 學妹的閨蜜

| 項目 | 內容 |
|------|------|
| 年級 | 一年級・化工科 |
| 定位 | 亭瑄的國中同班好友，一起考進成大附工，但分到化工科 |
| 外貌 | 嬌小，黑長直髮披到背，化工科的實驗護目鏡推在頭頂（`design/visuals.md`） |

### 性格
溫柔文靜、善於傾聽，是亭瑄傾倒心事的對象。但別被溫柔的外表騙了——她對戀愛的嗅覺極其敏銳，毒舌程度不輸任何人。

### 喜劇定位
清醒但毒舌的旁觀者。每次亭瑄不承認自己在意學長時：

> 亭瑄：「我才不是擔心他！」
> 小芸：（默默掏出手機）
> 亭瑄：「你在幹嘛？」
> 小芸：「記錄你今天第幾次提到吳學長的名字。目前 17 次。」

統計方式隨章節演進：手動計數 → 自動計數 → 詞頻分析 → 語氣分析

### 故事功能
- 亭瑄視角時的核心對話對象
- 提供感情線的客觀視角
- 在關鍵抉擇點給亭瑄不同方向的建議
- 偶爾跟阿成形成「場外觀戰聯盟」

### 說話方式

**一句話：** 語氣平、句子短、從不大聲，補刀永遠在最後一句。

「溫柔」指的是她有耐心聽，不是她講話溫柔。她的嗶聲音高完全不變（`design/audio.md`），台詞也照這個感覺寫：面無表情地講出最準的話。

- **最短的回應**：「喔。」「嗯。」「所以呢？」亭瑄每次都會追問「『喔』是什麼意思啦！」
- **不用驚嘆號、不用語助詞**：最多一個「欸」（「你變了欸。」）。
- **數字要精確**：「目前 17 次。」「本週平均 23.6 次/天。」「本學年共 478 次。」數字前後不加形容詞。
- **補刀**：先附和，最後一句才刺（「嗯。罵了很久。」「機車講兩次了。」）。
- **用問題讓亭瑄自己說出答案**：「如果換成別人說一樣的話，你會這麼在意嗎？」問完就不說話。
- **一邊做別的事一邊聽**：「我在寫實驗報告。你繼續講，我有在聽。」

### 習慣與小動作

- 推一下頭頂的護目鏡再說話
- 統計亭瑄提到學長的次數，工具一章比一章厲害：正字 → Excel → 計數 App → 詞頻分析 → Python 爬蟲（`running-gags.md`）
- 拍照：發表會拍了一百張
- 很少笑。第五章看到亭瑄認真念書時微笑了一下，這種時候要寫出來
- 〔新擬〕選化工科是因為喜歡實驗：照步驟做，數字會說話

### 跟其他人

- **亭瑄**：國中同班。〔新擬〕叫她「亭瑄」。亭瑄什麼都跟她說，她每一句都有在聽。
- **二弘**：沒什麼交集。在亭瑄面前叫他「吳學長」，統計也是用「吳學長」計數；第十一章起改叫「吳二弘」或「二弘」來逗亭瑄。
- **阿成**：委員會的搭檔。〔新擬〕叫他「阿成學長」，語氣跟對亭瑄一樣平。
- **王老師**：不同科，沒有交集。

### 各章出場

| 章 | 她做了什麼 |
|---|---|
| 1 | 化工科走廊：「你確定不是因為那個學長嗎？」；電話裡「機車講兩次了」 |
| 2 | 「今日吳學長提及次數：3。包含此訊息。」 |
| 3 | 亭瑄窩在她家；「如果換成別人說一樣的話，你會這麼在意嗎？」「所以你到底是生氣還是心動？」 |
| 4 | 「今日已破 20。」 |
| 5 | 陪亭瑄在圖書館念書：「你變了欸。」 |
| 6 | 把 commit message 卡片翻譯成「以他的標準來說，這大概已經是情書等級了」 |
| 7 | 「你是在問我，吳二弘是不是喜歡你嗎？」 |
| 8 | 〔草案〕給出意料之外的建議：去廣設科，「你喜歡畫畫，我知道」 |
| 9 | 聽亭瑄說不想拖住學長。這次沒有吐槽 |
| 10 | 委員會成立 |
| 11 | 「你這學年提到吳二弘 478 次。」「那你叫他『二弘』了喔？」 |
| 12 | 發表會拍一百張照片；True End：「最終統計報告已生成。」 |

### 搭檔反應（`小芸`）

學妹視角、亭瑄寫程式時在旁邊（第三、七章的細綱有寫到）。計數和對照：「嗯。第 3 次紅字。」「這題你寫了 12 分鐘，比你滑手機短。」不教程式、不給提示，只陳述數據。

### 寫她的時候不要

- **不要讓她大聲、慌張或用驚嘆號。**
- **不要讓她替亭瑄做決定。** 她只問問題、給數據；第八章的建議也是給「另一個方向」，讓亭瑄自己選。
- **不要讓吐槽變成傷人。** 她只刺亭瑄不肯承認的事，不刺亭瑄在乎的事（畫畫、程式學得慢）。
- **認真的時候不吐槽。** 第三章和第九章亭瑄真的難過時，她只聽。

## 王葉聖老師 — 資訊科導師 / 專題指導

| 項目 | 內容 |
|------|------|
| 年齡 | 三十出頭 |
| 背景 | 從業界轉任教職的年輕老師 |
| 外貌 | 比學生高、肩膀寬但不厚，旁分的整齊短髮（`design/visuals.md`） |

### 性格
教學認真但偶爾冒出「業界黑話」讓學生一臉問號。對學生之間的感情動態心知肚明但裝作不知道，只在關鍵時刻不經意地推一把。

### 喜劇定位
看似隨意但精準的「助攻者」：

> 王老師：「這個 demo 嘛⋯⋯吳二弘你跟梁亭瑄兩個一起上台報告好了。」
> 二弘：「老師，我一個人可以——」
> （老師已經走了）

導師時間的不經意炸彈：

> 王老師：「吳二弘，你最近的作業裡面有一個變數叫 tx，是什麼意思？」
> （全班安靜）
> 二弘：「⋯⋯那是、那是 temporary 的縮寫。」
> 阿成（憋笑）：「temporary X？」
> 二弘：「⋯⋯閉嘴。」

### 故事功能
- 專題進度的推動者
- 在學生遇到低潮時給出不著痕跡的建議
- 代表「大人的視角」，偶爾說出點醒學生的話
- 最後專題發表時的見證者

### 說話方式

**一句話：** 從容、不趕，交代完就走。

- **句尾常帶「喔」「嘛」**：「早點習慣比較好喔。」「業界做專案，也不能挑隊友嘛。」
- **叫學生全名**：「吳二弘。」「梁亭瑄。」
- **把學校的事講成業界的事**：「業界做專案，也不能挑隊友嘛。」〔新擬〕其他可用的黑話方向：deadline、demo、scope、上線、code review。用在學生聽不懂的地方，才有笑點。
- **稱讚短而具體**：「UI 不錯。是你畫的？」「梁亭瑄，你的介面設計很有想法。」不用「很棒」「很厲害」這種空泛的詞。
- **說完就走**：他的炸彈都是一句話，丟完就離開，不等學生反應。
- **交代規定時很清楚**：「提案下週報告。題目還沒交的組，這週五前交。」

### 習慣與小動作

- 拿著咖啡，開口前先喝一口
- 在展示區、教室裡慢慢走一圈，停在某一組前面
- 〔新擬〕在辦公室跟其他老師說「年輕真好」，被吐槽「你三十幾歲吧」（`comedy-romance.md`「Debug 就是約會」）

### 寫他的時候不要

- **不要讓他明講感情。** 他永遠裝作不知道；就算是 `tx` 那一次，他問的也只是「是什麼意思」。
- **不要讓他長篇說教。** 點醒學生的話一句就夠。
- **不要讓他偏心。** 他的助攻看起來都要像是在處理專題。

## 阿嬤 — 二弘的阿嬤

| 項目 | 內容 |
|------|------|
| 身分 | 二弘的阿嬤，在臺南舊市區開小吃店 |
| 出場 | 第二章起（嗶聲、代表色已經在 `Cast` 裡，繪製器還沒做） |
| 定位 | 二弘家裡唯一的大人；從蛛絲馬跡看出孫子的變化 |
| 〔新擬〕外貌 | 個子小，背有一點駝，圍著店裡的圍裙。剪影的辨識點待定（`design/visuals.md` 還沒有她的輪廓） |

### 性格

慈祥、直接、觀察力很強。看不懂程式，但看得懂孫子。二弘以為自己藏得很好，阿嬤一眼就看出來他「最近回來都笑笑的」。

她不會當面逼問二弘；她會問一句，看他的反應，然後去多做幾道菜。

### 說話方式

- **國語夾台語詞**：叫他「阿弘」，叫亭瑄「妹妹仔」。〔新擬〕整句台語只在情緒最滿的時候用一次（`running-gags.md` 的「妹妹仔你就是讓阮孫會笑的人喔？」），其他時候用國語，玩家才都看得懂。
- **問句很直接**：「你以前不是都一個人做？」「阿弘，你最近怎麼一直笑？」
- **愛餵人**：關心等於給食物。「以後常常來喔。」
- **看程式只看顏色**：「阿弘，這是什麼字？」「紅色的是不是寫錯了？」「好啦好啦，你寫，阿嬤去煮麵。」

### 習慣與小動作

- 在二弘的書包塞絨毛玩偶當「護身符」
- 看到孫子有變化就多做菜，叫他帶去學校分享
- 〔新擬〕小吃店賣麵和湯（細綱裡她說「阿嬤去煮麵」，第十二章端出一碗湯）
- 錢櫃只有她能開（第七章 `private` 的由來）

### 各章出場

| 章 | 她做了什麼 |
|---|---|
| 2 | 「今天怎麼回來比較晚？」「你以前不是都一個人做？」 |
| 4 | 做了二弘喜歡的菜，要他帶去學校分享 |
| 5 | 「阿弘，你最近怎麼一直笑？」；幫亭瑄轉交木瓜牛奶：「他說你做的便當很好吃。」 |
| 7 | 春節小吃店；看他一直看手機，問起那個做便當的同學 |
| 12 | 偷偷來看專題發表，坐在最後一排紅了眼眶；True End：「以後常常來喔。」 |

### 搭檔反應（`阿嬤`）

學長視角第七章，二弘改寫記帳程式時在旁邊看。看不懂程式，只看得懂紅字和孫子的表情，最後總是去煮麵。

### 寫她的時候不要

- **不要寫成悲情的角色。** 家裡只有祖孫兩人，但她過得很好，很忙，很有精神。
- **不要讓她解釋程式或講道理。** 她的力量來自「看得懂人」。
- **不要讓她提起二弘的爸媽。** 那是背景，不是劇情。

## 名冊外的角色

不在 `Cast` 裡，灰色名牌，不用畫。

| 角色 | 出場 | 寫法 |
|---|---|---|
| 亭瑄的媽媽 | 2 | 只有聲音。「多做給誰？」 |
| 飲料店老闆娘 | 10 | 「小弟又帶女朋友來啦？」「喔好好好。」（完全不信） |
| 同學甲、乙／全班 | 1 起 | 傳聞和起鬨：「⋯⋯居然是編譯器。」「學妹保重。」「噢——！」 |
| 試玩的學弟 | 4 | 〔草案〕校慶試玩專題 App，指著「分號」說「這個好像吳學長」 |
