# 校園戀愛喜劇 — 劇情總覽

## 作品概要

以「國立成功大學附屬臺南工業高級中等學校」資訊科為舞台的校園戀愛喜劇。
日輕風格，融合甜系日常與歡樂吐槽，講述學長與學妹因專題製作而相遇的故事。

## 基本設定

| 項目 | 內容 |
|------|------|
| 地點 | 成大附工・資訊科 |
| 時間 | 一個學期（9月～隔年1月） |
| 類型 | 校園戀愛喜劇 |
| 風格 | 甜系日常 + 歡樂吐槽（日輕風） |
| 視角 | 可選學長或學妹 |
| 結構 | 分支選項 → 4 種結局 |

## 資料夾結構

```
story/
├── characters/       — 角色設定
├── outline/          — 故事大綱與系統設計
├── scripts/          — 各章對話腳本（按章節分資料夾）
│   ├── ch01/ ～ ch07/
└── assets/           — 喜劇/浪漫/在地元素設計資料
```

## 主要角色

- **吳二弘**（學長）— 三年級，綽號「編譯器」
- **梁亭瑄**（學妹）— 一年級，代號「Runtime Error」
- **李有成**（阿成）— 學長損友
- **燕韋芸**（小芸）— 學妹閨蜜
- **王葉聖老師** — 資訊科導師

## 篇章規劃

### 第一篇章（本篇）— 上學期
7 章，從開學組隊到期末專題發表，完整講述相遇到告白的過程。

### 後續篇章（預留）
可擴充下學期、暑假、畢業季等篇章。
