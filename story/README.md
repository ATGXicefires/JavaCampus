# 校園戀愛喜劇 — 劇情總覽

## 作品概要

以「國立成功大學附屬臺南工業高級中等學校」資訊科為舞台的校園戀愛喜劇。
日輕風格，融合甜系日常與歡樂吐槽，講述學長與學妹因專題製作而相遇的故事。

## 基本設定

| 項目 | 內容 |
|------|------|
| 地點 | 成大附工・資訊科 |
| 時間 | 一個學年（9月～隔年6月，到二弘畢業） |
| 類型 | 校園戀愛喜劇 |
| 風格 | 甜系日常 + 歡樂吐槽（日輕風） |
| 視角 | 可選學長或學妹 |
| 結構 | 分支選項 → 4 種結局 |

## 資料夾結構

```
story/
├── characters/       — 角色設定
├── outline/          — 故事大綱與系統設計
├── detail/           — 細綱：每場戲的段落和程式題，寫劇本前的設計（第 2～12 章）
├── scripts/          — 各章對話腳本（按章節分資料夾）
│   ├── ch01/ ～ ch12/
└── assets/           — 喜劇/浪漫/在地元素設計資料
```

## 主要角色

- **吳二弘**（學長）— 三年級，綽號「編譯器」
- **梁亭瑄**（學妹）— 一年級，代號「Runtime Error」
- **李有成**（阿成）— 學長損友
- **燕韋芸**（小芸）— 學妹閨蜜
- **王葉聖老師** — 資訊科導師

## 篇章規劃

### 本篇 — 一個學年
12 章，從開學組隊到畢業典禮。上學期 6 章，從相遇走到離不開的搭檔；下學期 6 章，從察覺心意走到畢業前夕的告白。

### 大學 DLC（預留）
二弘上大學之後的篇章，接著教本篇沒教到的 Java（路線圖見 `design/curriculum.md`）。
