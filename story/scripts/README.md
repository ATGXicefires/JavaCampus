# 劇本語法

遊戲直接讀這個資料夾裡的劇本。格式沿用 `ch01-common.md` 原本的寫法，只多加了內心 OS、選項效果和 `@` 開頭的演出指令。

## 檔案

```
story/scripts/
├── chapters.json        — 章節清單：章號、章名、資料夾、專題進度
├── docs/                — 可以打開來看的文件（PDF、README、紙條⋯⋯）和文件裡的圖
└── ch01/
    ├── ch01-common.md   — 共通場景庫
    ├── ch01-senpai.md   — 學長視角從頭到尾的播放順序
    └── ch01-kouhai.md   — 學妹視角從頭到尾的播放順序
```

- 遊戲從 `ch01-senpai.md` 或 `ch01-kouhai.md` 的第一行開始播。
- 共通場景寫在 `ch01-common.md`，視角檔用 `@共通 [場景名稱]` 插進來。

## 章節清單

```
{"id": "ch01", "number": 1, "title": "編譯錯誤", "dir": "ch01", "progress": 5},
{"id": "ch02", "number": 2, "title": "Hello World"},
```

- `dir` 是劇本資料夾，`progress` 是這一章結束時的專題進度（%），章末的進度條用。
- **還沒寫的章節不寫 `dir`。** 章節選擇照樣列出章號和章名，但是鎖住不能點；遊戲也不會播到它。寫好之後補上 `dir` 和 `progress` 就能玩了。

## 註解

以下這些行遊戲不會讀，可以照常寫給自己看的筆記：

- `#` 開頭的標題
- `>` 開頭的說明
- 單獨一行的 `---`

## 場景

```
[抽籤現場]
```

單獨一行、用方括號包住的名稱就是場景的開頭，也是跳轉的目標。同一章裡場景名稱不能重複。

## 台詞

```
亭瑄：「學長，你在跟我說外星語嗎？」
二弘：「⋯⋯這是 Java。」
亭瑄：（瞪）「你再說一次？」
```

- 冒號用全形的 `：`，半形的 `:` 也可以。
- 台詞前面的 `（動作）` 會用小字顯示在台詞前面。
- 名牌顯示的就是你寫的名字，所以「二弘」「吳二弘」「吳學長」都可以寫。只要是下表裡的寫法，就會用那個角色的代表色和嗶聲。

| 角色 | 可以寫成 |
|---|---|
| 吳二弘 | 二弘、吳二弘、學長、吳學長 |
| 梁亭瑄 | 亭瑄、梁亭瑄、學妹 |
| 李有成 | 阿成、李有成 |
| 燕韋芸 | 小芸、燕韋芸 |
| 王葉聖 | 王老師、王葉聖 |
| 阿嬤 | 阿嬤 |

不在表裡的名字（例如「全班」「同學」「老闆娘」）也可以用，會顯示成中性的灰色。

## 內心 OS

```
二弘（OS）：⋯⋯這不像是「做太多」的樣子。
```

名字後面加 `（OS）`。不顯示名牌，文字用斜體，前後加括號，也沒有嗶聲。

## 旁白與舞台指示

```
--- 旁白 ---
窗外開始下雨，二弘完全沒注意到。

（亭瑄站了一會兒，搖搖頭跑走了。）
```

- 沒有角色名的一般文字就是旁白。`--- 旁白 ---` 可寫可不寫。
- 單獨一行、整行用全形括號包住的舞台指示，也當作旁白顯示。

## 選項

```
【選項】
A. 不會 AP+8 TP+5
    二弘：「⋯⋯反正已經配對了。我不習慣留 bug 不修。」
B. 會 AP+5 TP+8
    二弘：「會。但那是我的問題，不是你的。」
    （頓了一下）
    二弘：「意思是⋯⋯我會想辦法。」

亭瑄：（笑了一下）「⋯⋯嗯。」
```

- `【選項】` 後面接 `A.`、`B.`⋯⋯，最多四個。
- 選項文字後面可以加效果：`AP+8`、`TP+5`，關鍵抉擇再加 `★`。
- **縮排**（兩個以上空白，或一個 Tab）的行是選了那個選項才會播的內容。播完之後接回選項區塊下面的第一行（上例的「⋯⋯嗯。」）。
- 選項要直接跳到別的場景，就寫 `A. 主動開口 AP+10 TP+15 ★ → [和解・主動]`，跳過去不會回來。

## 演出指令

`@` 開頭，一行一個。

| 指令 | 範例 | 作用 |
|---|---|---|
| `@背景 名稱 [變體]` | `@背景 電腦教室 傍晚` | 換背景 |
| `@登場 角色 位置 [表情]` | `@登場 二弘 右 無言` | 角色登場；位置是 左／中／右 |
| `@表情 角色 表情` | `@表情 二弘 害羞` | 換表情 |
| `@退場 角色` | `@退場 亭瑄`、`@退場 全部` | 角色退場 |
| `@音樂 曲名` | `@音樂 Debug 日常`、`@音樂 停` | 換 BGM |
| `@環境 名稱` | `@環境 雨`、`@環境 停` | 換環境音；`雨` 也會顯示雨 |
| `@音效 名稱` | `@音效 鐘聲` | 播一次音效 |
| `@特效 名稱` | `@特效 震動`、`@特效 夕陽`、`@特效 夕陽 關` | 畫面特效 |
| `@暗場` | `@暗場` | 淡到黑再淡回來，用來換時間或地點 |
| `@等待 秒` | `@等待 1.5` | 停頓 |
| `@手機 對象` ⋯ `@手機 收起` | `@手機 小芸`、`@手機 專題群組` | 中間的台詞變成手機訊息，對象顯示在手機上方，可以是人名或群組名稱。視角角色本人的訊息靠右，其他人靠左 |
| `@附件 檔名 → 文件` | `@附件 程式基礎教學筆記.pdf → 教學筆記` | 在手機裡傳一個可以點開的附件，算是緊接在後面那則訊息的人傳的 |
| `@電話 對象` ⋯ `@電話 掛斷` | `@電話 小芸` | 通話中；中間的台詞照常顯示 |
| `@文件 名稱` | `@文件 術語文件` | 打開 `docs/` 裡的文件，看完關掉才繼續 |
| `@程式 題目` | `@程式 ch01-k2` | 進入程式題，過關後回到下一行 |
| `@旗標 名稱` | `@旗標 看到雨中的窗戶` | 記下一個旗標 |
| `@數值 效果` | `@數值 AP+3` | 不經過選項，直接加數值 |
| `@簡介 文字` | `@簡介 亭瑄問二弘：如果她真的學不會，他會不會覺得很煩。` | 玩家按「跳過」時顯示的劇情簡介，平常播放時看不到（見下面「劇情簡介」） |
| `@如果 條件 → [場景]` | `@如果 AP>=80 TP>=80 關鍵>=2 → [最後一夜・True]` | 條件全部成立就跳過去，否則往下 |
| `@跳到 [場景]` | `@跳到 [章末]` | 跳到那個場景 |
| `@只限 視角` ⋯ `@結束` | `@只限 學長` | 中間的內容只有那個視角會播 |
| `@共通 [場景]` | `@共通 [抽籤現場]` | 在視角檔裡播一段共通場景，播完回來 |
| `@章末 文字` | `@章末 Day 1：教會梁同學什麼是變數。` | 章末筆記本畫面 |

**視角角色本人不會站上舞台。** 學長視角裡寫給二弘的 `@登場`、`@表情`、`@退場` 都不會讓他上台，學妹視角裡寫給亭瑄的也一樣。所以共通場景可以兩個人都寫，不用為兩個視角各寫一份。

他開口說話時，對話框左邊會貼一張他的大頭照，表情是最近一次寫給他的 `@表情`（`@登場` 後面帶的表情也算，沒帶就是一般）。其他不在台上的角色說話時也會貼大頭照，例如講電話的小芸，表情一律是一般；名冊外的角色（全班、同學）沒有照片。內心 OS、旁白和手機訊息不貼照片。

`@如果` 可以用的條件，用空白隔開，全部成立才算成立：
- `AP>=80`、`TP<40`：比較符號可以用 `>=`、`<=`、`>`、`<`、`=`。
- `旗標:名稱`：有沒有記過這個旗標。
- `關鍵>=2`：記過幾個 ★ 旗標。
- `結局=True`：依目前數值判定的結局，值是 `True`、`Good`、`Normal`、`Bad`。

## 劇情簡介

```
亭瑄：「如果我真的學不會，你不會覺得很煩嗎？」
@簡介 亭瑄問二弘：如果她真的學不會，他會不會覺得很煩。
【選項】
```

玩家按快捷選單的「跳過」，會一路跳到下一個選項、`@程式` 或 `@章末`，再把路上經過的 `@簡介` 依序列出來。

- `@簡介` 寫在選項、`@程式`、`@章末` 的**前面**，交代從上一個停點到這裡發生的事。要寫在最後一句台詞之後，不然玩家從那句之後開始跳，就看不到這則簡介。
- 一段劇情也可以分好幾則寫，例如每個場景一則，跳過時會全部列出來。
- 視角不同的段落用 `@只限` 包起來，各寫各的。
- 測試會檢查每一種選法下，每個停點前面都有簡介；漏寫的話會指出是哪個檔案的第幾行。

## 名稱清單

| 種類 | 第一章可以用的名稱 |
|---|---|
| 背景 | 電腦教室（白天、傍晚、雨夜）、校門口（雨）、化工科實驗室外、亭瑄的房間（夜） |
| 表情 | 一般、笑、生氣、害羞、驚訝、疑惑、無言、冒汗、心動、難過 |
| 音樂 | 放學後的電腦教室、Debug 日常、吐槽模式、心跳超出預期值、窗外的雨 |
| 環境 | 雨、電腦教室、蟬鳴、走廊人聲 |
| 音效 | 鐘聲、手機通知、撥號、接通、開門、關門、全班噢、吐槽、心跳、翻頁 |
| 特效 | 震動、閃白、心跳、夕陽、回憶 |

寫了清單裡沒有的名稱，測試會指出是哪個檔案的第幾行。

背景的變體也決定手機上顯示的時間：白天 12:20、傍晚 17:35、雨 17:50、雨夜 19:40、夜 22:10。

## 文件

`docs/` 裡一個文件一個檔案。第一行寫外觀，其餘是內容；單獨一行的 `---` 是換頁。

```
外觀：PDF

# 程式基礎教學筆記

變數就像一個有名字的盒子。

---

# if-else

如果有滷肉飯就吃滷肉飯，否則吃控肉飯。
```

外觀有四種：`PDF`、`術語文件`、`程式檔`、`手寫`。內容支援段落、`**粗體**`、`` `程式碼` `` 和程式碼區塊。

### 圖片

```
**2. 系統架構圖**

![系統架構圖](系統架構圖.svg)
```

- 單獨一段只寫 `![說明](檔名.svg)`，就會顯示 `docs/` 裡的那張 SVG 圖，縮放到跟文件一樣寬。
- 只認得 SVG 的一小部分：`rect`、`line`、`polyline`、`polygon`、`path`、`circle`、`ellipse`、`text`，和只能用 `translate(x, y)` 平移的 `g`。顏色和線條用 `fill`、`stroke`、`stroke-width`、`stroke-dasharray`；文字用 `font-size`、`font-weight`、`font-family`、`text-anchor`。寫在 `svg` 或 `g` 上的這些屬性會套到裡面每個圖形。
- `<svg>` 要寫 `viewBox`。箭頭不能用 marker，請直接畫成 `polygon`。
- 字型用遊戲附帶的 `Source Han Sans TC`（沒寫 font-family 時的預設）或 `Maple Mono NF CN`。
- 找不到圖或畫不出來時，會顯示方括號裡的說明文字；測試會指出是哪份文件的哪張圖。

## 完整範例

```
[留下的選擇]
@背景 電腦教室 傍晚
@環境 電腦教室
@音樂 Debug 日常

（第二天放學，亭瑄出現在電腦教室門口。）

@只限 學長
二弘（OS）：⋯⋯我沒有在等。只是剛好在看門的方向。
@結束

@登場 二弘 右 一般
@登場 亭瑄 左 一般
亭瑄：「⋯⋯那個 PDF，我看了。」
二弘：「⋯⋯然後？」
亭瑄：「我還是覺得程式很難。」
亭瑄：（笑）「但你寫的比喻很好笑。滷肉飯那個。」
@表情 二弘 害羞
二弘：「那只是為了讓你理解 if-else。」

@只限 學妹
二弘：「你⋯⋯還想繼續做這個專題嗎？」
【選項】
A. 留下 AP+8 TP+5
    亭瑄：「嗯。雖然學長你講話真的很機車，但⋯⋯至少你有認真在教。」
B. 猶豫 AP+5 TP+8
    亭瑄：「我不確定⋯⋯但如果學長願意等我跟上的話。」
@結束
```
