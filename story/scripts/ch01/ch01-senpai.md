# Ch01 學長視角 — 「編譯錯誤」

> 吳二弘視角從頭到尾的播放順序。共通場景寫在 `ch01-common.md`。
>
> 獨有場景
> 1. [一個人的教室]：亭瑄離開後，二弘留在教室改文件（ch01-s1），阿成的損友吐槽
> 2. [轉科的傳聞]：聽到轉科的傳聞，寫「程式基礎教學筆記」（ch01-s2），傳 PDF 到專題群組
> 3. 共通 [留下的選擇] 裡的學長版：修她照抄出錯的程式（ch01-s3）
>
> 內心獨白風格
> - 會用程式邏輯分析情況（「這個狀況的 expected outcome 是⋯⋯」）
> - 情感相關的想法會被他自己壓下去（「——不，這不在變數範圍內。」）
> - 偶爾的自嘲（「我的社交能力大概跟 deprecated API 差不多。」）
