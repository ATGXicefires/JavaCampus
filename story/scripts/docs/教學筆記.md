# 讓電腦說話

電腦是一個非常聽話、但完全不會猜你在想什麼的人。你寫什麼，它就做什麼，一個字都不會幫你補。

要它說話，就寫這一行：

```
System.out.println("你好");
```

意思是：把引號裡的字，原封不動印出來。

引號要用半形的 `"`，不能用中文輸入法的「」。每一句最後面要加半形的分號 `;`，就像句號。

一個 `println` 印一行。想印兩行，就寫兩行。

出現紅字不用慌。紅字是電腦在說「這裡我看不懂」，它會告訴你是第幾行。大部分是三種錯：全形符號、少了分號、大小寫打錯。

# 變數就像一個有名字的盒子

盒子外面貼著名字，裡面裝著東西。

```
String box = "扭蛋";
int gacha = 7;
```

`String` 是裝文字的盒子，`int` 是裝整數的盒子。等號不是「等於」，是「把右邊的東西放進左邊的盒子」。

要拿出來看，就叫它的名字：

```
System.out.println(gacha);
```

印出來的是 `7`，不是 `gacha`。叫名字，拿到的是盒子裡的東西。

盒子裡的東西可以換：

```
gacha = 8;
```

換的時候不用再寫一次 `int`，盒子已經在了。

# if-else 就像你選午餐

如果有滷肉飯就吃滷肉飯，否則吃便當。

```
boolean hasLuRouFan = true;

if (hasLuRouFan) {
    System.out.println("吃滷肉飯");
} else {
    System.out.println("吃便當");
}
```

`boolean` 是只能裝 `true`（有）或 `false`（沒有）的盒子。

`if` 後面的括號裡放一個問題。答案是 `true`，就做第一組大括號裡的事；是 `false`，就做 `else` 裡的事。

兩個只會做一個。不會兩個都吃。
