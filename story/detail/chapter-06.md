### ch06-k2「出生就有名字」

學妹・寫｜場景 1｜搭檔：二弘｜類別｜題目變數：`String[] names = {"麻糬", "黑糖", "珍奶"}`

| 步驟 | 目標 | 驗證 |
|---|---|---|
| 1 建構子 | 幫 `Item` 加上建構子 `Item(String name, String kind)`，讓名字在 `new` 的時候就決定。 | 數值 `new Item("小白", "筆電").name`、`new Item("阿隨", "USB").kind` |
| 2 扭蛋全家福 | 用 for 把 `names` 裡的每個名字都 `new` 成扭蛋（種類是 `扭蛋`），放進 `Item[] bag`，再印出 `麻糬（扭蛋）`⋯⋯ | 輸出；換 `names = {"仙草"}` |

- 第 1 步的說明直接教標準寫法 `this.name = name;`。
- 扭蛋名字全是甜點，這是她的命名品味。
- 解鎖筆記：`constructor`、`this`

### ch06-k3「小老師會說話」

學妹・寫｜場景 1 App 重新整理｜搭檔：二弘｜類別

| 步驟 | 目標 | 驗證 |
|---|---|---|
| 1 小老師的設計圖 | 寫 `class Mascot`：欄位 `name`、`line`，加上建構子，和方法 `void speak()`，印出 `滷肉：「沒關係，再跑一次！」`。`new` 出滷肉和分號，各自 speak。 | 輸出 |
| 2 交回一句話 | 加上 `String greet(String user)`，交回 `滷肉：「梁亭瑄，歡迎回來！」`。 | 數值 `new Mascot("滷肉", "沒關係，再跑一次！").greet("梁亭瑄")`、`new Mascot("分號", "分號。").greet("新同學")` |

- 對照第四章的 `say(who, line)`：以前要把「誰」傳進去，現在是小老師自己知道自己是誰。
- 解鎖筆記：`obj-method`

### ch06-s3「名字一直是 null」

學長・修｜場景 1 App 重新整理｜搭檔：亭瑄｜類別

起始碼是亭瑄寫的小老師：建構子裡寫成 `name = name;`、`line = line;`，所以印出 `null：「null」`。

| 步驟 | 目標 | 驗證 |
|---|---|---|
| 1 null 說了 null | 修到印出 `滷肉：「沒關係，再跑一次！」`。 | 輸出 |
| 2 還沒取名的 | 她加了 `int nameLength()`（畫名牌底線要用），還沒取名的小老師一呼叫就跌倒。修到名字是 null 時交回 0。 | 數值 `new Mascot(null, "⋯⋯").nameLength()`、`new Mascot("滷肉", "嗨").nameLength()` |

- 解鎖筆記：`null`

## 筆記條目

| id | 標題 | 一句話 |
|---|---|---|
| `class` | 類別是設計圖 | `class Item { String name; }` 只是設計圖，還不是東西。 |
| `object` | 物件是照設計圖做出來的東西 | `new Item()` 才真的做出一個。一張設計圖可以做很多個，每個的欄位各自一份。 |
| `constructor` | 建構子 | `new` 的那一刻第一個執行的方法。名字和類別一樣，沒有回傳型別。名字在出生時就決定。 |
| `this` | this 是「我自己的」 | `this.name = name;`：左邊是物件自己的欄位，右邊是傳進來的參數。 |
| `obj-method` | 物件的方法 | 不加 `static` 的方法屬於每個物件：`roufan.speak()` 就是滷肉在說話。 |
| `null` | null 是空盒子 | 還沒放東西的物件欄位是 `null`。對 null 呼叫方法會跌倒，先檢查 `name == null`。 |

兩個視角各自都會解鎖全部 6 條。學妹在 k1～k4 解鎖；學長在 s1、s2、s3 解鎖。
