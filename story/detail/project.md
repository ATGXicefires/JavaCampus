# 專題設定：小白學程式（暫名）

> 整份都是草案，待審。

## 一句話

一個 Java 學習 App，對象是完全沒寫過程式的新生。把二弘的「程式基礎教學筆記」PDF 做成 App，由亭瑄畫的小老師帶著學。

## 怎麼來的（第二章）

- 第一階段報告前，王老師要還沒交題目的組在這週交出題目。
- 二弘的規劃書（第一章的術語文件）把架構、時程、測試計畫都寫好了，系統名稱卻還是「待定」。也就是說，他把怎麼做都想好了，還沒想要做什麼。
- 亭瑄：「那就把你的 PDF 做成 App。給跟我一樣什麼都不會的人用。」
- 這是二弘第一次讓別人的點子決定自己要做什麼。和角色設定的「專題的點子通常是她想的」一致。
- 取名的時候，亭瑄的萬物命名癖發作：她要叫它「小白」，跟她的筆電同名。
  - 二弘：「⋯⋯『小白』在網路上是新手的意思。」
  - 亭瑄：「那不是剛好嗎！」

## 誰做什麼

| | 亭瑄 | 二弘 |
|---|---|---|
| 負責 | 畫面（UI）、小老師、說明文字的語氣、使用流程 | 題目判斷、計分、資料、整體架構 |
| 在程式題裡 | 學妹視角寫畫面那一半 | 學長視角寫後端那一半 |

兩個視角各自從自己那一半看同一個 App。第十章兩半合併，第十二章一起上台：亭瑄介紹介面和使用流程，二弘負責技術說明（第十二章大綱）。

## 兩個小老師

| | 滷肉 | 分號 |
|---|---|---|
| 樣子 | 一碗會說話的滷肉飯，眼睛是兩顆滷蛋 | 小小的人，戴黑框方眼鏡，頭頂翹一撮毛 |
| 個性 | 很樂天。答錯也說「沒關係，再跑一次！」 | 話很少，只會很短的提醒：「分號。」「⋯⋯引號是半形。」 |
| 從哪來 | 第一章 PDF 裡的滷肉飯比喻 | 二弘本人。他第一章的提示就是這種語氣 |

- 「分號」是誰，所有人都看得出來，只有二弘本人看不出來。第四章校慶有人說「這個好像吳學長」，阿成笑到蹲下，二弘：「⋯⋯哪裡像。」亭瑄：「眼鏡。」
- 第十一章最後一夜，「螢幕上是亭瑄畫的角色在二弘寫的程式世界裡活動」，指的就是這兩個小老師。

## App 的內容就是她這一年學會的東西

- App 的每一課，對應遊戲裡一章的教學筆記。亭瑄每學會一章，App 就多一課；同一章的筆記條目也在遊戲裡解鎖。
- 第十二章的 v1.0 有 12 課，就是這一年。

## 版本與進度

進度是 `chapters.json` 的 `progress`，章末的進度條會用到；寫到那一章的劇本時再填進去。

第三章大綱裡，二弘段考前一週心算「專題進度 38%」，所以前段進度比較快：他提前準備了半年的架構，題目一定案就能直接套上去。後段是整合和打磨，進度慢下來，剛好配合感情的慢熱。

## 藏在 App 裡的東西

- **Easter egg：** 在答題框輸入「學長，你在說外星語嗎？」，也就是亭瑄在第一章印出的第一句話，就會跳出隱藏訊息。第十一章學長題做出這個機關，訊息先寫成 `// TODO`，之後各路線不同：
  - True：他把訊息寫完了，就是第十一章大綱那段「梁亭瑄，我不太會說話。」
  - Good：他寫不出來。第二天，她先留了 txt。
  - Normal：門關上之後他「打了一行字又刪掉」，刪的就是這段。
  - Bad：收尾時，他把它當成沒用的功能刪掉。
- **製作團隊畫面（第十二章）：** 介面設計 梁亭瑄、程式 吳二弘，再加上特別感謝：阿嬤的菜、小芸的統計、阿成的照片、王老師。

## 和現有設定的關係

- 第一章的術語文件（專題製作規劃書草案 v0.9）是二弘原本一個人做的版本。裡面的技術選擇（Java、JavaFX）照用，只是終於有了題目。
- 第三章場景 5「如果是使用者的話，我會想要這邊有個按鈕」：使用者就是像她這樣的新生，這句話成了 App 的第一個設計決定。
- 第十二章發表會上，有人問「這個介面是誰設計的」，二弘回答：「我的⋯⋯夥伴。」
