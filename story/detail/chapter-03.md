## 程式題

### ch03-k1「段考前的複習卷」

學妹・寫（複習）｜場景 1，晚上在家｜搭檔：亭瑄OS｜片段｜題目變數：`int total = 312`、`int days = 7`

二弘在 PDF 最後加了幾題練習〔草案〕。

| 步驟 | 目標 | 驗證 |
|---|---|---|
| 1 五科平均 | 段考 5 科的總分是 `total`，算出平均 `avg`，要有小數。 | 數值 `avg`；換 `total = 300` |
| 2 及格嗎 | 平均 60 以上印 `及格`，否則印 `再加油`。 | 輸出；換 `total = 250` |
| 3 倒數 | 用 for 從 `days` 倒數：`段考倒數 7 天` 到 `段考倒數 1 天`。 | 輸出；換 `days = 3` |

- 第 3 步要用 `i--`。這是 `i++` 的反方向，提示裡帶一句就好。
- 解鎖筆記：無（複習第 1～2 章）

### ch03-k2「一排置物櫃」

學妹・寫｜場景 1，隔天在電腦教室｜搭檔：二弘｜片段｜題目變數：`int[] scores = {72, 58, 65, 80, 49}`（成績頁的測試資料：五個新生的小考分數）

| 步驟 | 目標 | 驗證 |
|---|---|---|
| 1 第一格和最後一格 | 印出第一個分數和最後一個分數，一個一行。 | 輸出；換 `scores = {90, 85}`、`{60}` |
| 2 全部加起來 | 用 for 把分數加總，存在 `sum`。 | 數值 `sum`；換 `scores = {90, 85}` |
| 3 平均 | 算出平均 `avg`，要有小數。 | 數值 `avg`；換 `scores = {90, 85}` |

- 第 1 步的最後一格要寫 `scores[scores.length - 1]`，換一組長度不同的資料才會對。
- 解鎖筆記：`array`、`index`、`array-loop`

### ch03-k3「跑一半跌倒」

學妹・修｜場景 3 冷戰第一天晚上，小芸家｜搭檔：小芸｜片段｜題目變數：`int[] scores = {72, 58, 65, 80, 49}`

起始碼是她交給二弘、被全部重寫的成績頁。

| 步驟 | 目標 | 驗證 |
|---|---|---|
| 1 它停在哪一行 | 執行，看例外訊息停在哪一行，修到加總不會跌倒。 | 數值 `sum`；換 `scores = {90, 85}` |
| 2 平均怪怪的 | 平均應該是 64.8，修到印出 `平均：64.8`。 | 輸出；換 `scores = {90, 85}` |

起始碼裡的錯：
1. `for (int i = 0; i <= scores.length; i++)`：走到第 5 格，可是只有 0～4 格。例外訊息是 `Index 5 out of bounds for length 5`。
2. `double avg = sum / scores.length;`：整數除法，64.8 變成 64.0。

- 學妹的題目平常是「寫」。這一題特意讓她修自己的程式：她用自己的力氣，找到被退回的原因。
- 搭檔反應（小芸）方向：「嗯。第 3 次紅字。」「這題你寫了 12 分鐘，比你滑手機短。」
- 解鎖筆記：`exception`

### ch03-k4「成績等第」

學妹・寫｜場景 3，zip 裡的筆記｜搭檔：小芸｜片段｜題目變數：`int score = 85`、`int[] scores = {72, 58, 65, 80, 49}`

| 步驟 | 目標 | 驗證 |
|---|---|---|
| 1 五個等第 | 用 if／else if／else 把 `score` 換成等第印出來：90 以上 A、80 以上 B、70 以上 C、60 以上 D、其他 F。 | 輸出；換 `score = 95`、`72`、`60`、`59` |
| 2 整排都換 | 用 for 把 `scores` 的每個分數換成等第，印成 `72 C` 這樣。 | 輸出；換 `scores = {100, 59}` |

- 筆記裡寫著「很多人第一次寫等第，會先判斷 >= 60」。那就是她成績頁裡的錯，筆記沒有點名。
- 解鎖筆記：`else-if`

### ch03-k5「README 說可以問」

學妹・寫｜場景 3，zip 裡筆記的最後一節｜搭檔：小芸｜片段｜題目變數：`String input = "85"`、`int total = 240`、`int count = 3`

| 步驟 | 目標 | 驗證 |
|---|---|---|
| 1 字變成數字 | 答題框拿到的是字串。用 `Integer.parseInt` 把 `input` 變成 int，存在 `score`。 | 數值 `score`；換 `input = "62"` |
| 2 打了國字 | 用 try-catch：是數字就印 `收到：85`，不是就印 `要輸入數字喔，例如 80`。 | 輸出；換 `input = "八十"`、`input = "62"` |
| 3 還沒有成績 | 印出平均 `平均：80`；`count` 是 0 時會除以零，接住它，印 `還沒有成績`。 | 輸出；換 `count = 0` |

- 這一節的情境是 App 的答題框：新生打的字不一定是數字。
- 解鎖筆記：`parse-int`、`try-catch`

### ch03-s1「她這個月寫的」

學長・修（複習）｜場景 1｜搭檔：二弘OS｜片段｜題目變數：`int score = 60`、`int total = 312`、`int days = 7`

| 步驟 | 目標 | 驗證 |
|---|---|---|
| 1 又是全形 | 修到分數剛好 60 時印 `剛好及格`，其他分數什麼都不印。 | 輸出；換 `score = 59` |
| 2 平均又是整數 | 修到 `avg` 有小數。 | 數值 `avg`；換 `total = 300` |
| 3 少印一天 | 修到從 1 印到 `days`：`第 1 天`⋯⋯ | 輸出；換 `days = 3` |

起始碼裡的錯：
1. `if (score = 60)` 和行尾的全形 `；`：`=` 是放進去，比較要用 `==`。紅字是 int 不能轉成 boolean。
2. `double avg = total / 5;`：整數除法。
3. `for (int i = 1; i < days; i++)`：少跑一次，和第二章「多跑一次」的錯剛好相反。

- 做完的 OS 方向：⋯⋯又是全形分號。一個月了。
- 做題目時改成三份練習、一步一份，各有自己的起始碼：同一份程式裡，第 3 步的迴圈會印東西，玩家提早修好的話，第 1 步的輸出比對就對不上。
- 解鎖筆記：無（複習第 1～2 章）

### ch03-s2「全部重寫」

學長・修｜場景 2 爆發｜搭檔：二弘OS（建議用專用的反應組，見「引擎需求」）｜片段｜題目變數：`int[] scores = {72, 58, 65, 80, 49}`

起始碼是亭瑄交來的成績頁：加總、平均、每個分數的等第。

| 步驟 | 目標 | 驗證 |
|---|---|---|
| 1 跑一半掛掉 | 看例外訊息，修到加總不會跌倒。 | 數值 `sum`；換 `scores = {90, 85}` |
| 2 平均 | 修到 `avg` 是 `64.8`。 | 數值 `avg`；換 `scores = {90, 85}` |
| 3 等第全是 D | 修好條件的順序，每個分數印出正確的等第。 | 輸出；換 `scores = {95, 85, 75, 65, 55}` |

起始碼裡的錯：
1. `i <= scores.length`：超出最後一格。
2. `sum / scores.length`：整數除法。
3. 條件先判斷 `>= 60`，所以 60 分以上全部是 D；也沒有 A。

- 學妹視角的 k3、k4 會碰到同一份程式的同樣三個錯：學長在爆發時修掉，學妹在冷戰時自己修好。
- 做完接劇情：「⋯⋯我寫的全部不能用嗎？」
- 做題目時把第 2 步改成比對數值：程式後面還會印出等第，玩家提早修好等第的話，第 2 步的輸出比對就對不上。
- 解鎖筆記：`array`、`index`、`array-loop`、`exception`、`else-if`

### ch03-s3「段考筆記：陣列與等第」

學長・教｜場景 3 冷戰第三天夜裡｜搭檔：二弘OS｜片段｜題目變數：`int[] scores = {72, 58, 65, 80, 49}`、`int score = 85`

| 步驟 | 目標 | 驗證 |
|---|---|---|
| 1 置物櫃 | 用 for 印出每一格：`第 0 格：72`⋯⋯讓她看到索引從 0 開始。 | 輸出；換 `scores = {90, 85}` |

## 筆記條目

| id | 標題 | 一句話 |
|---|---|---|
| `array` | 陣列是一排置物櫃 | `int[] scores = {72, 58, 65};` 一排三格，每格放一個分數。 |
| `index` | 索引從 0 開始 | 第一格是 `scores[0]`，最後一格是 `scores[scores.length - 1]`。 |
| `array-loop` | 走過每一格 | `for (int i = 0; i < scores.length; i++)`。是 `<`，不是 `<=`。 |
| `else-if` | else if 是排隊問問題 | 從上往下問，第一個回答「是」的就停。所以先問 90 分，再問 80 分。 |
| `exception` | 例外是程式在執行時跌倒 | 紅字是還沒跑就看不懂；例外是跑到一半跌倒。看它停在哪一行。 |
| `parse-int` | 字串變數字 | `Integer.parseInt("85")` 得到 85。打的不是數字就會跌倒。 |
| `try-catch` | try-catch 是先準備好接住 | 可能跌倒的放進 `try`，跌倒時要做的事放進 `catch`。 |
