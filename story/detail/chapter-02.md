### ch02-k1「int 是什麼」

學妹・寫｜場景 1 Day 1｜搭檔：二弘｜片段｜題目變數：`int gacha = 8`（第一章結束時，她書包上有 8 個扭蛋）

| 步驟 | 目標 | 驗證 |
|---|---|---|
| 1 三種新盒子 | 做三個盒子：`double temp` 放 `33.5`、`boolean hot` 放 `true`、`String city` 放 `"臺南"`。 | 數值 `temp`、`hot`、`city` |
| 2 掛勾 | 8 個扭蛋平均掛在 3 個掛勾上：算出每個掛幾個（`perHook`）、剩幾個（`left`）。 | 數值 `perHook`、`left`；換 `gacha = 10`、`gacha = 12` |
| 3 除不盡 | 算出精確的平均 `avg`，要有小數。 | 數值 `avg`；換 `gacha = 10` |

- 第 1 步的 33.5 是臺南九月的氣溫。
- 第 3 步會先碰到 `gacha / 3` 只有 2。提示帶出「整數除以整數，小數直接丟掉」，改成 `gacha / 3.0` 或 `(double) gacha / 3`。
- 解鎖筆記：`types`、`arith`、`int-div`、`cast`

### ch02-s2「她的型別錯誤」

學長・修｜場景 1 Day 2（學長獨有）｜搭檔：二弘OS｜片段

| 步驟 | 目標 | 驗證 |
|---|---|---|
| 1 3.5 個扭蛋 | 修好第一行，讓 `half` 裝得下 `3.5`。 | 數值 `half` |
| 2 總共 34 個？ | 修到印出 `總共 7 個`。 | 輸出 |
| 3 平均是 3？ | 修到 `avg` 是 `3.5`。 | 數值 `avg` |

起始碼裡的錯：
1. `int half = 3.5;`：小數放不進 int，紅字是 possible lossy conversion。
2. `System.out.println("總共 " + 3 + 4 + " 個");`：字串先接上 3、再接上 4，印出「總共 34 個」。要寫成 `"總共 " + (3 + 4) + " 個"`。
3. `double avg = 7 / 2;`：先算整數除法得到 3，才放進 double，所以是 3.0。

- 解鎖筆記：`int-div`、`cast`

### ch02-s3「多跑一次的 for」

學長・修｜場景 1 Day 3｜搭檔：亭瑄｜片段｜題目變數：`int times = 5`

| 步驟 | 目標 | 驗證 |
|---|---|---|
| 1 多罰了一遍 | 修到剛好印 `times` 行，編號從 1 開始：`第 1 遍：我不會再用全形分號`。 | 輸出；換 `times = 100` |
| 2 總共花幾秒 | 修好累加，讓 `total` 是 1 加到 `times` 的和。 | 數值 `total`；換 `times = 100` |

起始碼裡的錯：
1. `for (int i = 0; i <= times; i++)` 搭配 `"第 " + i + " 遍：⋯"`：從 0 數到 times，多跑一次，編號也從 0 開始。如果改成 `"第 " + i + 1 + " 遍"`，會印出「第 01 遍」，又是串接順序的問題。
2. 迴圈裡寫成 `total = i;`，每次都蓋掉前面的值，最後只剩 times。要寫 `total += i;`。

- 解鎖筆記：`compare`、`inc`、`for`

## 筆記條目

| id | 標題 | 一句話 |
|---|---|---|
| `types` | 型別是盒子的尺寸 | `int` 裝整數，`double` 裝小數，`boolean` 只裝 true／false，`String` 裝文字。 |
| `arith` | 四則運算與 `%` | `%` 是除完剩下的：8 個扭蛋掛 3 個掛勾，剩 2 個。 |
| `int-div` | 整數除以整數 | 兩個整數相除，小數直接丟掉：`7 / 2` 是 3。 |
| `cast` | 型別轉換 | 要小數，就讓其中一邊變成 double：`7 / 2.0`、`(double) 7 / 2`。 |
| `concat` | 字串串接 | `+` 碰到字串就變成接起來；要先算的數字，加括號。 |
| `compare` | 比大小 | `<` `<=` `>` `>=` `==` `!=` 的答案是 boolean。`=` 是放進去，`==` 才是比。 |
| `inc` | `i++` 與 `+=` | `i++` 是加一，`total += i` 是把 i 加進 total。 |
| `for` | for 是把同一件事做 N 遍 | `for (int i = 1; i <= 5; i++)`：從 1 數到 5，每數一次做一遍。 |
