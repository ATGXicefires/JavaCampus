## 程式題

完整程式不吃題目變數，要換資料驗證時，改用「隱藏測資」：直接呼叫 `Main` 裡的方法。清單的測資寫成 `new java.util.ArrayList<>(java.util.List.of(…))`。

### ch10-k1「第一個 Main.java」

學妹・寫｜場景 1｜搭檔：二弘｜完整程式

| 步驟 | 目標 | 驗證 |
|---|---|---|
| 1 從 main 開始 | 寫 `public class Main`，裡面放 `public static void main(String[] args)`，印出 `小白學程式 v0.9`。 | 輸出 |

## 筆記條目

| id | 標題 | 一句話 |
|---|---|---|
| `main` | 完整程式從 main 開始 | `public class Main` 裡的 `public static void main(String[] args)` 是起點。以前的片段，現在都要放進 main。 |
| `files` | 一個類別一個檔案 | `public class` 的名字要和檔名一樣。每個檔案自己 import 自己要用的。 |
| `arraylist` | ArrayList 是會變長的清單 | `add` 加進去、`get(0)` 拿第一個、`size()` 有幾個、`contains` 有沒有。陣列的長度固定，清單可以一直加。 |
| `for-each` | for-each 是每一個都來一次 | `for (String s : screens)`：不用索引，一個一個拿出來。 |
| `generics` | 角括號寫清楚裝什麼 | `ArrayList<String>` 只裝字串。數字要寫 `Integer`，不能寫 `int`，角括號裡只能放類別。 |
| `hashmap` | HashMap 是對照表 | `put("tx", "梁亭瑄")` 放進去、`get("tx")` 查出來、`containsKey` 先問有沒有。 |

兩個視角各自都會解鎖全部 6 條。學妹在 k1～k3 解鎖；學長在 s1～s3 解鎖。
