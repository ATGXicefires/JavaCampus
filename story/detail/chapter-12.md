## 場景流程

### 2. [發表會的早上]（共通・電腦教室）〔草案〕

### 3. [專題發表會]（發表會場）〔大綱〕

- 資訊科專題發表會，全校師生和部分家長來參觀。
- 二弘和亭瑄的作品：亭瑄設計的介面加上二弘寫的後端邏輯。
- 上台報告時，亭瑄負責介紹 UI 和使用流程（〔草案〕就是 k1 寫的那個流程），二弘負責技術說明。
- 亭瑄比預期的流暢，她真的理解了這個程式在做什麼。
- 二弘的技術說明簡潔精準，但依然不看觀眾的眼睛。〔草案〕他講的全是白話，是第一章那份術語文件的反面。
- 〔草案〕現場試玩：一個一年級新生點開第 1 課，第一次寫 println 就打了全形分號。螢幕上的「分號」說：「分號。」全場笑出來。二弘：「⋯⋯」亭瑄：（笑到發抖）

**台下**〔大綱〕
- 阿成在後排假裝擦眼淚，被旁邊的人白眼。
- 小芸拍了一百張照片。
- 王葉聖老師在評審席微笑。
- 二弘的阿嬤偷偷來了（二弘不知道），坐在最後一排。看到孫子上台報告時，紅了眼眶。

### 4. [畢業典禮]（禮堂→校門口）〔大綱，草案〕

### ch12-k3「發表前十分鐘的 bug」

學妹・修｜場景 2 發表會的早上｜搭檔：二弘｜完整程式

起始碼是她的 `ProgressBar`：`"□".repeat(total - done)`。第一位試玩的老師答了獎勵題，`done` 比 `total` 多，`repeat` 收到負數就跌倒了。

| 步驟 | 目標 | 驗證 |
|---|---|---|
| 1 多答了一題 | 修到完成數超過總數時，畫成全滿。main 畫出 `(3, 5)` 和 `(6, 5)` 兩條。 | 輸出 |
| 2 百分比也要擋 | `percent()` 超過 100 時就顯示 100。 | 隱藏測資 `new ProgressBar(6, 5).percent()`、`new ProgressBar(3, 4).percent()` |

- 解鎖筆記：無

## 筆記條目

| id | 標題 | 一句話 |
|---|---|---|
| `import` | import 與 package | `import java.util.ArrayList;` 寫在檔案最上面。`package` 是把類別分資料夾放的名字，這個遊戲的沙盒會忽略它，正式的專案才用得到。 |
| `full-program` | 完整的專題 | 好幾個檔案，各自 import 自己要用的，從 Main 開始跑。這一年學的東西，全部在裡面。 |
| `last-page`〔草案〕 | （最後一頁） | True End 之後才解鎖：術語文件最後一頁的那段備註。 |

`import`、`full-program` 兩個視角都會解鎖：學妹在 k1、k2，學長在 s1。`last-page` 只在 True End 解鎖。
