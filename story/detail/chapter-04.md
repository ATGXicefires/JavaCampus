## 場景流程

### 1. [新的合作模式]（電腦教室・放學後）〔大綱〕

**共通**〔大綱〕
- 二弘改變了教學方式：不再直接講術語，而是先問「你覺得應該怎麼做？」，讓亭瑄用自己的方式思考。
- 亭瑄負責專題的 UI 設計，她畫的介面簡單但有設計感。兩人開始有了「分工」而不只是「教學」的關係。
- 阿成路過電腦教室門口，看到兩人並肩看著同一個螢幕，默默拍了一張照。二弘完全不知道。

**分工的約定**〔草案〕
- 二弘在白板上寫下每個方法的「簽章」：名字、要給什麼、會交回什麼。【文件】分工表
  - 亭瑄負責：`say`、`bar`、`hint`、`isCorrect`。
  - 二弘負責：`total`、`percent`。
- 二弘：「簽章就是約定。裡面怎麼寫，各自決定。」
- 學妹：二弘問她「小老師說話的方法，你覺得該怎麼寫？」接【程式】ch04-k1「小老師說話」。
- 學長：【程式】ch04-s1「後端的第一個方法」。寫到一半，她問「為什麼不直接印出來就好？」，那就是第 3 步。

**學長**〔大綱〕
- 發現亭瑄問的問題越來越有深度，不是「這是什麼」，而是「為什麼要這樣做」。
- 第一次覺得「教她」這件事⋯⋯有點成就感。也注意到自己開始會在意她的建議。

**學妹**〔大綱〕
- 發現學長變了：會解釋「為什麼」，會等她跟上，會問她的想法。不是很明顯的溫柔，而是很他的方式。
- 開始在回家路上也想著專題的事，不是壓力，是期待。

## 程式題

### ch04-k1「小老師說話」

學妹・寫｜場景 1｜搭檔：二弘｜方法

| 步驟 | 目標 | 驗證 |
|---|---|---|
| 1 打招呼 | 寫 `static void hello()`，印出 `滷肉：「歡迎來到小白！」`，再呼叫它兩次。 | 輸出 |
| 2 誰說什麼 | 寫 `static void say(String who, String line)`，讓滷肉說 `沒關係，再跑一次！`、分號說 `分號。`，格式是 `滷肉：「沒關係，再跑一次！」`。 | 輸出 |
| 3 交回一句話 | 寫 `static String line(String who, String text)`：這次不印，把排好的那句話交回來。 | 數值 `line("分號", "分號。")`、`line("滷肉", "好耶")` |

- 第 3 步對照第 2 步：印出來和交回來不一樣。交回來的可以再拿去用。
- 解鎖筆記：`method`、`param`、`return`

### ch04-k2「學習進度條」

學妹・寫｜場景 2｜搭檔：二弘｜方法

| 步驟 | 目標 | 驗證 |
|---|---|---|
| 1 一格一格 | 寫 `static String bar(int done, int total)`：完成幾課就幾個 `■`，剩下的用 `□`，例如 `bar(3, 5)` 是 `■■■□□`。 | 數值 `bar(3, 5)`、`bar(0, 4)`、`bar(4, 4)` |
| 2 加上數字 | 寫 `static String progress(int done, int total)`，交回 `■■■□□ 3/5`，裡面呼叫自己寫的 `bar`。 | 數值 `progress(3, 5)`、`progress(1, 2)` |
| 3 標題底線 | 寫 `static String underline(String title)`，交回和標題一樣長的 `=`。 | 數值 `underline("第 1 課")`、`underline("變數")` |

- 解鎖筆記：`string-methods`

### ch04-k3「答對了沒」

學妹・寫｜場景 2 彩排之後｜搭檔：二弘｜方法

| 步驟 | 目標 | 驗證 |
|---|---|---|
| 1 提示的第一個字 | 寫 `static String hint(String answer)`：只露出第一個字，其他用 `＿`。`hint("吃滷肉飯")` 是 `吃＿＿＿`。 | 數值 `hint("吃滷肉飯")`、`hint("小白")` |
| 2 多打的空白 | 寫 `static boolean isCorrect(String typed, String answer)`：先用 `trim()` 去掉前後空白，再用 `equals` 比。 | 數值 `isCorrect(" 吃滷肉飯", "吃滷肉飯")`、`isCorrect("吃控肉飯", "吃滷肉飯")`、`isCorrect("吃滷肉飯 ", "吃滷肉飯")` |

- 第 2 步的測資刻意帶空白：`trim()` 會產生新的字串，這時候用 `==` 比一定是 false，只有 `equals` 會過。
- 二弘的解釋方向：「`==` 比的是是不是同一個盒子，`equals` 比的是裡面的字一不一樣。」
- 解鎖筆記：`equals`

### ch04-k4「五種口味的雞蛋糕」

學妹・寫｜場景 3 校慶後的電腦教室｜搭檔：亭瑄OS｜方法｜題目變數：`String[] flavors = {"原味", "巧克力", "芋頭", "花生", "黑糖"}`、`int[] stars = {3, 4, 5, 2, 4}`

起始碼裡已經有二弘寫的 `total(int[] counts)` 和 `percent(int part, int whole)`，註解寫著「學長寫的，不要改」。

| 步驟 | 目標 | 驗證 |
|---|---|---|
| 1 總共幾顆星 | 用學長的 `total` 算出總星數，存在 `sum`。 | 數值 `sum`；換 `stars = {1, 1, 1, 1, 1}` |
| 2 排行榜 | 每種口味印一行，例如 `芋頭 ★★★★★ 27%`。星星用 `repeat`，百分比用學長的 `percent(stars[i], sum)`。 | 輸出；換 `stars = {5, 5, 5, 5, 5}` |

- 重點是不用看學長的方法裡面怎麼寫，照簽章給對東西就能用。
- 做題目時把例子的 28% 改成 27%：`percent` 用整數算，5 × 100 ÷ 18 是 27。
- 解鎖筆記：`signature`

### ch04-s1「後端的第一個方法」

學長・自己｜場景 1｜搭檔：亭瑄｜方法

| 步驟 | 目標 | 驗證 |
|---|---|---|
| 1 加總 | 寫 `static int total(int[] counts)`，交回全部加起來的和。 | 數值 `total(new int[]{3, 4, 5})`、`total(new int[]{})`、`total(new int[]{7})` |
| 2 百分比 | 寫 `static int percent(int part, int whole)`，交回整數的百分比；`whole` 是 0 時交回 0。 | 數值 `percent(1, 4)`、`percent(2, 3)`、`percent(0, 0)` |
| 3 她問為什麼 | 寫 `static void report(int part, int whole)`，呼叫 `percent`，印出 `完成 25%`；再呼叫 `report(1, 4)`、`report(3, 4)`。 | 輸出 |

- 第 3 步回答她的問題「為什麼不直接印出來就好？」：交回來的值可以再拿去用，印出來的就只能看。
- 解鎖筆記：`method`、`param`、`return`

### ch04-s2「接上她的方法」

學長・自己｜場景 2｜搭檔：亭瑄｜方法｜題目變數：`String[] units = {"讓電腦說話", "型別與重複"}`、`int[] done = {3, 1}`、`int[] total = {3, 4}`

起始碼裡已經有亭瑄寫的 `bar(int done, int total)` 和 `say(String who, String line)`。

| 步驟 | 目標 | 驗證 |
|---|---|---|
| 1 照約定呼叫 | 每一課印一行，例如 `讓電腦說話 ■■■ 3/3`，進度條用她的 `bar`。 | 輸出；換 `done = {0, 4}` |
| 2 完成的時候 | 已經完成的課，下一行讓滷肉說 `這一課完成了！`（呼叫她的 `say`）。 | 輸出；換 `done = {3, 4}` |

- 第 1 步的起始碼是他自己的草稿，寫成了 `bar(total[i], done[i])`，順序顛倒。約定是先給完成數、再給總數。
- 解鎖筆記：`signature`

### ch04-s3「`==` 不是那個等於」

學長・修｜場景 2 彩排｜搭檔：阿成（新的反應組，電競播報的語氣）｜方法

起始碼是亭瑄寫的 `isCorrect`：`return typed == answer;`

| 步驟 | 目標 | 驗證 |
|---|---|---|
| 1 多打了空白 | 修到前後多打的空白不算錯。 | 數值 `isCorrect("吃滷肉飯 ", "吃滷肉飯")`、`isCorrect(" 小白", "小白")`、`isCorrect("小黑", "小白")` |
| 2 答案也有空白 | 題庫裡的答案也可能多了空白，兩邊都要處理。 | 數值 `isCorrect("小白", "小白 ")`、`isCorrect(" 小白 ", " 小白")` |

- 只加 `trim()`、還是用 `==` 的話，第 1 步照樣失敗。這就是要教 `equals` 的那一刻。
- 解鎖筆記：`equals`、`string-methods`

### ch04-s4「提示的第一個字」

學長・修｜場景 2 彩排｜搭檔：阿成｜方法

起始碼是亭瑄寫的 `hint`：`return answer.substring(1, 2) + "＿".repeat(answer.length());`

| 步驟 | 目標 | 驗證 |
|---|---|---|
| 1 露錯字了 | 修到 `hint("吃滷肉飯")` 是 `吃＿＿＿`。 | 數值 `hint("吃滷肉飯")`、`hint("小白")`、`hint("滷")` |

起始碼裡的錯：
1. `substring(1, 2)` 切出的是第二個字，第一個字是 `substring(0, 1)`。
2. `repeat(answer.length())` 多了一格，應該是 `length() - 1`。

- 解鎖筆記：無

### ch04-s5「雞蛋糕評分」

學長・自己｜場景 3 校慶後的電腦教室｜搭檔：亭瑄｜方法｜題目變數：`String[] flavors = {"原味", "巧克力", "芋頭", "花生", "黑糖"}`、`int[] sweet = {2, 4, 3, 3, 5}`

| 步驟 | 目標 | 驗證 |
|---|---|---|
| 1 一句話評語 | 寫 `static String review(int sweetness)`：1～2 交回 `可以。`，3～4 交回 `甜。`，5 交回 `太甜。`。 | 數值 `review(1)`～`review(5)` |
| 2 附在排行榜上 | 每種口味印一行，例如 `芋頭：甜。`。 | 輸出；換 `sweet = {5, 5, 5, 5, 5}` |

- 亭瑄的反應方向：「你五種的評語，加起來只有三種欸！」
- 做題目時拿掉評語開頭的 `⋯⋯`（理由同第二章 k4），也多測了 2 和 4 這兩個邊界。
- 解鎖筆記：無

## 筆記條目

| id | 標題 | 一句話 |
|---|---|---|
| `method` | 方法是分工 | 把一件事包起來、取個名字：`static void hello() { … }`。要用的時候叫它的名字。`static` 先照寫，之後再講。 |
| `param` | 參數是交給對方的東西 | `say(String who, String line)`：呼叫時給什麼，方法裡就用什麼。 |
| `return` | 回傳值是對方交回來的東西 | `return` 把結果交回去；`void` 是什麼都不交回。 |
| `signature` | 方法簽章就是約定 | 名字、要給什麼、交回什麼，先說好。裡面怎麼寫，各自決定。 |
| `string-methods` | 字串的方法 | `length()` 有幾個字、`substring(0, 1)` 切出第一個字、`repeat(3)` 重複三次、`trim()` 去掉前後空白。 |
| `equals` | 比字串要用 equals | `==` 比的是不是同一個盒子，`equals` 比的是裡面的字一不一樣。字串一律用 `equals`。 |

兩個視角各自都會解鎖全部 6 條。學妹在 k1～k4 解鎖；學長在 s1、s2、s3 解鎖。
