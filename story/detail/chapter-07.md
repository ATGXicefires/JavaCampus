章名的比喻〔大綱〕：封裝就是把欄位設成 `private`，外面只能透過指定的方法存取。兩個人都把心事 private 起來，LINE 上只開放「在幹嘛」「沒事」這兩個方法。

## 概念

| 代號 | 概念 | 學妹 | 學長 |
|---|---|---|---|
| C1 | `private` 欄位：外面不能直接碰 | k1、k4 | s1 |
| C2 | getter／setter：只開放指定的方法 | k1、k4 | s1 |
| C3 | 在方法裡把關：擋負數、擋超過上限 | k2 | s2 |
| C4 | `static` 欄位：大家共用的，和每個物件各自的 | k3 | s3 |
| C5 | ★`static final` 常數 | k2 | s4 |

## 程式題

### ch07-k1「只有我能開的扭蛋包」

學妹・寫｜場景 2｜搭檔：亭瑄OS｜類別

| 步驟 | 目標 | 驗證 |
|---|---|---|
| 1 鎖起來 | 寫 `class GachaBag`：欄位 `private int count`，方法 `void add()` 加一個、`int getCount()` 交回數量。`new` 一個叫 `bag` 的扭蛋包，加 8 個。 | 數值 `bag.getCount()` |
| 2 從外面改不了 | 起始碼的最後一行偷偷寫了 `bag.count = 99;`，紅字說 count 是 private。刪掉，改成用 `add()` 再加一個。 | 數值 `bag.getCount()` |

- 第 1 步加 8 個，接續第一章的七個、八個。
- 解鎖筆記：`private`、`getter-setter`

### ch07-k2「最多十二個」

學妹・寫｜場景 2｜搭檔：亭瑄OS｜類別

| 步驟 | 目標 | 驗證 |
|---|---|---|
| 1 掛不下了 | 加上常數 `static final int MAX = 12;` 和建構子 `GachaBag(int count)`。`add()` 改成交回 boolean：還沒滿就加一個、交回 true，滿了就不加、交回 false。 | 數值 `new GachaBag(11).add()`、`new GachaBag(12).add()` |
| 2 一開始就太多 | 建構子收到超過 MAX 的數量時只放 MAX 個，收到負數就放 0。 | 數值 `new GachaBag(20).getCount()`、`new GachaBag(-3).getCount()`、`new GachaBag(5).getCount()` |
| 3 改不了的上限 | 起始碼裡有一行 `GachaBag.MAX = 20;`，紅字說 final 不能改。刪掉，改成印出 `最多 12 個`。 | 輸出 |

- 解鎖筆記：`guard`、`final`

### ch07-k3「小芸的寒假統計」

學妹・寫｜場景 2 和小芸的對話之後｜搭檔：小芸｜類別｜題目變數：`int[] daily = {3, 5, 4, 8, 7, 9, 12}`

| 步驟 | 目標 | 驗證 |
|---|---|---|
| 1 每一天各自算 | 寫 `class Day`：欄位 `int mentions` 和建構子；再加一個 `static int total`，每 `new` 一天，就把那天的次數加進去。用 for 照 `daily` 把每一天都 `new` 出來。 | 數值 `Day.total`；換 `daily = {1, 1}` |
| 2 每天的累計 | 每 `new` 一天就印一行：`第 1 天：3 次，累計 3 次`。 | 輸出；換 `daily = {1, 2}` |

- `day.mentions` 是每一天自己的，`Day.total` 是大家共用的。
- 沙盒每次執行都從乾淨的狀態開始，`total` 不會跨次累加。
- 搭檔反應（小芸）方向：「嗯。你在統計自己提到學長的次數。」
- 解鎖筆記：`static-field`

### ch07-k4「沒事」

學妹・寫｜場景 3 除夕夜｜搭檔：亭瑄OS｜類別

| 步驟 | 目標 | 驗證 |
|---|---|---|
| 1 真心話放在 private | 寫 `class Heart`：`private String real` 放你真正想說的話；方法 `String status()` 只交回 `沒事`，`String whatAreYouDoing()` 只交回 `在幹嘛`。 | 數值 `new Heart().status()`、`new Heart().whatAreYouDoing()` |
| 2 打了又刪 | 寫 `class Draft`：`private String text`（一開始是空字串）、`void type(String s)` 接在後面、`void clear()` 清空、`String preview()` 交回目前的內容。`new` 一個 `draft`：打「學長」，清空，再打「新年快樂」。 | 數值 `draft.preview()` |

- 第 1 步的 `real` 要放什麼，玩家可以自己打。反正它是 private，永遠不會被印出來，這就是封裝。
- 對應大綱的比喻：LINE 上只開放「在幹嘛」「沒事」這兩個方法。
- 解鎖筆記：無（複習 `private`、`getter-setter`）

### ch07-s2「錢櫃只有阿嬤能開」

- 解鎖筆記：`final`

## 筆記條目

| id | 標題 | 一句話 |
|---|---|---|
| `private` | private 是只有自己能開的抽屜 | `private int count;` 只有這個類別自己能碰，外面要透過它開放的方法。 |
| `getter-setter` | getter 和 setter | `getCount()` 讓外面看，`add()` 讓外面照規矩改。開放什麼，自己決定。 |
| `guard` | 在方法裡把關 | 錢不能存負數、扭蛋不能超過上限。規則寫在方法裡，誰都繞不過去。 |
| `static-field` | static 是大家共用的 | `static int todayTotal` 整家店只有一份，`amount` 每一桌各一份。第四章照寫的 `static` 就是這個意思：屬於類別，不屬於哪一個物件。 |
| `final` | final 是寫死的 | `static final int MAX = 12;` 設定一次就不能再改。常數的名字習慣全部大寫。 |

兩個視角各自都會解鎖全部 5 條。學妹在 k1～k3 解鎖；學長在 s1～s4 解鎖。
