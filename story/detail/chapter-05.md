## 程式題

### ch05-k1「及格了沒」

學妹・寫｜場景 1 圖書館｜搭檔：小芸｜方法

| 步驟 | 目標 | 驗證 |
|---|---|---|
| 1 及格線 | 寫 `static boolean isPass(int score)`：60 分以上交回 true。 | 數值 `isPass(59)`、`isPass(60)`、`isPass(61)`、`isPass(0)`、`isPass(100)` |
| 2 不合理的分數 | 分數小於 0 或大於 100 就是打錯了。寫 `static boolean isValid(int score)`。 | 數值 `isValid(-1)`、`isValid(0)`、`isValid(100)`、`isValid(101)` |
| 3 提早交回 | 寫 `static String judge(int score)`：不合理就先交回 `分數打錯了`，再判斷 `及格` 或 `不及格`。 | 數值 `judge(-5)`、`judge(60)`、`judge(59)` |

- 第 1 步的測資刻意排在 59、60、61：邊界上的錯最容易漏。
- 解鎖筆記：`bool-method`、`boundary`、`logic`

### ch05-k2「存錢買扭蛋」

學妹・寫｜場景 1 圖書館｜搭檔：小芸｜方法｜題目變數：`int price = 50`、`int perDay = 15`

| 步驟 | 目標 | 驗證 |
|---|---|---|
| 1 要存幾天 | 每天存 `perDay` 元，扭蛋一次 `price` 元。用 while 算出要存幾天才夠，存在 `days`。 | 數值 `days`；換 `price = 100`、`perDay = 20` |
| 2 寫成方法 | 寫 `static int daysToSave(int price, int perDay)`。 | 數值 `daysToSave(50, 15)`、`daysToSave(30, 30)`、`daysToSave(0, 10)` |

- `daysToSave(0, 10)` 是 0：條件一開始就不成立，while 一次都不會跑。
- 解鎖筆記：`while`

### ch05-k4「三十幾分到六十二分」

學妹・寫｜場景 3 拿到成績那天｜搭檔：二弘｜方法｜題目變數：`int[] myScores = {34, 41, 62}`

| 步驟 | 目標 | 驗證 |
|---|---|---|
| 1 最高分 | 寫 `static int max(int[] a)`。 | 數值 `max(new int[]{34, 41, 62})`、`max(new int[]{62, 41, 34})`、`max(new int[]{-3, -7})`、`max(new int[]{5})` |

### ch05-s5「幫她的程式做壓力測試」

學長・自己｜場景 4 報告前｜搭檔：二弘OS｜方法

起始碼裡已經有亭瑄寫的 `isPass`、`max`、`showBadge`，都是對的。

| 步驟 | 目標 | 驗證 |
|---|---|---|
| 1 比對 | 寫 `static String check(boolean actual, boolean expected)`：一樣交回 `PASS`，不一樣交回 `FAIL`。 | 數值 `check(true, true)`、`check(true, false)` |
| 2 邊界全部測一遍 | 把測資放進陣列 `{59, 60, 61, 0, 100}`，預期結果也放進陣列，用迴圈印出 `isPass(59) PASS` 這樣的每一行。 | 輸出 |
| 3 自己寫一份對照 | 寫 `static int myMax(int[] a)`，拿它檢查她的 `max`：三組刁鑽的測資，每組印一行 `PASS` 或 `FAIL`。 | 輸出 |

- 第 3 步是真正的測試手法：自己另外寫一份，兩邊比對。
- 全部 PASS。OS 方向：⋯⋯全部通過。她不需要我改任何一行。
- 解鎖筆記：`test-data`、`max-min`

## 筆記條目

| id | 標題 | 一句話 |
|---|---|---|
| `bool-method` | boolean 方法 | 交回 true／false 的方法，名字常用 is 開頭：`isPass(60)`。想到答案就可以提早 `return`。 |
| `boundary` | 邊界值 | 60 分及格，就要測 59、60、61。bug 最喜歡躲在邊界。 |
| `test-data` | 測資 | 一組資料對，不代表都對。換很多組，包括奇怪的：0、負數、只有一個。 |
| `logic` | 且／或／不是 | `&&` 兩個都要成立，`\|\|` 有一個成立就好，`!` 把答案反過來。 |
| `while` | while 是「還沒好就繼續」 | `while (存的錢 < 價錢) { 再存一天 }`。條件一開始就不成立，就一次都不做。 |
| `nested` | 巢狀迴圈 | 迴圈裡再放一個迴圈：外面跑一列，裡面跑那一列的每一格。 |
| `max-min` | 找最大最小 | 先把第一格當成目前最大，再一格一格比。不要從 0 開始比。 |

兩個視角各自都會解鎖全部 7 條。學妹在 k1、k2、k4、k5 解鎖；學長在 s1、s2、s3、s5 解鎖。
