### ch11-k1「478 次」

學妹・寫｜場景 1｜搭檔：小芸｜完整程式（兩個檔案）

起始碼有兩個分頁：她的 `Main.java`，和小芸給的 `ChatLog.java`（`static String[] load()` 交回這一學年的聊天紀錄，用程式產生，剛好有 478 則提到「學長」）。

| 步驟 | 目標 | 驗證 |
|---|---|---|
| 1 用 for 數 | 寫 `static int count(String[] log, String word)`，用 for 數出有幾則訊息包含 `word`。main 印出 `478 次`。 | 輸出 |
| 2 改成 while | 寫 `static int countWhile(String[] log, String word)`，改用 while。 | 隱藏測資 `Main.countWhile(new String[]{"學長早", "便當", "學長！"}, "學長")`、`Main.countWhile(new String[]{}, "學長")` |
| 3 再統計一次？ | 小芸的爬蟲每次跑完都問「再統計一次？」。main 裡寫好 `String[] answers = {"好", "好", "不要"}`，用 do-while：至少統計一次，回答是「好」就再來，每次印 `第 1 次：478 次`。 | 輸出 |

- 字串的 `contains` 第一次在這裡用，提示帶一句。
- 第 2 步改寫時最常忘了 `i++`：程式會停不下來，3 秒後被強制停止。學妹第一次碰到逾時就在這裡，提示專門講這件事。
- 解鎖筆記：`do-while`、`infinite-loop`

### ch11-s2「while(true) 卡住畢業典禮」

學長・自己｜場景 1 阿成的玩笑之後｜搭檔：阿成｜完整程式

起始碼：`int day = 0; while (true) { day++; }`

| 步驟 | 目標 | 驗證 |
|---|---|---|
| 1 技術上可行 | 先按執行：程式停不下來，3 秒後被強制停止。加上出口：`day` 到 30 就 `break`，最後印出 `第 30 天：畢業典禮`。 | 輸出 |
| 2 迴圈後面 | 起始碼在 `while (true)` 後面多了一行 `System.out.println("然後呢？");`，沒有 break，紅字說這一行永遠跑不到。讓它跑得到。 | 輸出（`第 30 天：畢業典禮`、`然後呢？`） |

- 第 1 步的起始碼會逾時，所以「起始碼要失敗」成立。逾時的訊息沿用 `Diagnostics.timeout`。
- 第 2 步的「然後呢？」接阿成那句「那你打算怎麼辦？畢業以後。」
- 解鎖筆記：`break`、`infinite-loop`

## 筆記條目

| id | 標題 | 一句話 |
|---|---|---|
| `do-while` | do-while 是先做再問 | `do { … } while (條件);` 至少做一次，做完才問要不要再來。最後的分號別忘了。 |
| `break` | break 是提早離開 | 找到就停：`if (找到了) break;` 直接跳出迴圈。 |
| `continue` | continue 是跳過這一次 | `if (週末) continue;` 這一圈剩下的不做，直接下一圈。 |
| `infinite-loop` | 無限迴圈 | 條件永遠成立，迴圈就停不下來。`while (true)` 一定要留一個 `break` 當出口。程式跑超過 3 秒會被強制停止。 |

兩個視角各自都會解鎖全部 4 條。學妹在 k1～k3 解鎖；學長在 s1～s3 解鎖。
