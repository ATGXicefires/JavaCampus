# 喜劇與浪漫場景設計

## 心動場景類型

### 1. 不經意的距離縮短
兩人因為某個理由物理距離忽然拉近，卻沒有人退開。

**範例場景：**
- 一起看同一個螢幕 debug 時肩膀靠得很近
- 走廊上人多被擠到一起
- 一起看手機上的教學影片，頭湊得很近
- 翻同一本參考書時手碰到了

**設計原則：** 「不退開」比「靠近」更重要——是無聲的接受。

### 2. 看到對方認真的側臉
發現自己一直在看對方，然後慌張移開目光。

**範例場景：**
- 二弘專注寫程式時推眼鏡的動作
- 亭瑄認真畫設計稿時咬嘴唇的習慣
- 對方跟別人說話時露出的表情（自己不曾見過的一面）

**設計原則：** 「他/她不知道我在看」的偷偷摸摸感是心動的核心。

### 3. 無聲的體貼
不說出口的關心，用行動表達。

**範例場景：**
- 二弘默默買的木瓜牛奶（「剛好經過順便買的」）
- 亭瑄準備的考前紙條
- 下雨天多帶的傘（「反正家裡多一把」）
- 冷氣太強時脫下來搭在椅背上的外套（「我不冷」）
- 二弘把亭瑄常打錯的程式碼寫成自動補全

**設計原則：** 觀眾（和另一個角色）看到了，但做這件事的人裝作理由很正當。

### 4. 只有我看到的另一面
看到對方在別人面前不會展現的樣子。

**範例場景：**
- 二弘在阿嬤面前露出的笨拙微笑
- 亭瑄獨自在圖書館苦讀程式的認真模樣
- 二弘書包裡的絨毛玩偶
- 亭瑄畫的 UI 草圖上有小小的二弘 Q 版（以為沒人會看到）

**設計原則：** 「反差」產生心動——「原來他/她也有這一面」。

### 5. 曖昧的誤會
被起鬨、說錯話、意外的親密接觸後的手忙腳亂。

**範例場景：**
- 被同學問「你們是不是在交往」時同步否認又同步紅臉
- 手機打錯字傳錯訊息的瞬間慌張
- 差點說出真心話又硬拗成別的：「我覺得你⋯⋯很⋯⋯很適合寫前端。」

**設計原則：** 否認得越用力，觀眾越確定。

## 吐槽喜劇場景設計

### 吐槽 / 呆萌（ツッコミ / ボケ）動態

**基本配置：**
- 二弘 = 天然吐槽役（但他不覺得自己在吐槽）
- 亭瑄 = 天然呆萌役（但她偶爾反殺）

**角色反轉時刻：**
當二弘在感情方面表現得比亭瑄更呆時，角色對調：
> 亭瑄：「學長，你寫的 Easter egg 裡面那句話⋯⋯」
> 二弘：「那只是一個隱藏功能的測試文本——」
> 亭瑄（直視他的眼睛）：「你臉紅了。」
> 二弘：「⋯⋯是暖氣。」
> 亭瑄：「教室沒有暖氣。」
> 二弘：「⋯⋯」

### 群像喜劇場景

**電腦教室生態系（Ch4 校慶趕工期間）：**
- 各組都在趕專題，教室像戰場
- 有人邊打遊戲邊寫程式（被王老師抓到假裝在 debug）
- 有人拿投影機看動畫（理由：「這是 UI 設計的參考資料」）
- 有人在公開討論「我們的專題可以改成遊戲嗎」
- 整間教室的人都在偷看二弘和亭瑄，但兩人完全沒發現

**場外觀戰聯盟（阿成 × 小芸）：**
- 阿成和小芸在走廊上偶然碰到
- 「你也在觀察他們？」「嗯。」
- 兩人交換情報：阿成提供二弘的異常行為，小芸提供亭瑄的提及次數
- 形成非正式的「讓他們在一起企劃委員會」

## 資訊科專屬喜劇場景

### Debug 就是約會
兩人「留下來 debug」其實就是放學後的約會，但所有人（包括他們自己）都假裝不知道。

> 王老師在辦公室：「最近吳二弘和梁亭瑄的專題進度特別好，每天都自主加班。」
> 其他老師：「⋯⋯是喔。」
> 王老師：「年輕真好。」
> 其他老師：「⋯⋯你三十幾歲吧。」

### 程式碼裡的暗號
- 二弘的變數命名風格變化：從 `temp`, `result` 到偶爾出現 `tx`（亭瑄 initials）
- 亭瑄的 commit message 從「不知道改了什麼」進化到帶顏文字的版本
- 二弘寫的註解越來越長——因為他在寫給亭瑄看的說明

### 技能檢定梗
> 亭瑄在考場外面舉著手寫的「加油」牌子
> 上面畫了 Java logo 但 logo 畫歪了
> 旁邊的人：「你是他女朋友嗎？」
> 亭瑄：「不是！我是他的——」（停頓三秒想不到該怎麼介紹）「——專題夥伴！」
> 旁邊的人露出了「我懂了」的表情

## 浪漫氛圍營造要素

### 時間
- **放學後的電腦教室** — 最日常也最重要的空間。夕陽透過窗戶灑進來的傍晚
- **深夜的 LINE 對話** — 文字比當面更容易說出真心話
- **清晨的通勤** — 在 T-Bike 站「偶然」遇到的五分鐘

### 物件
- **木瓜牛奶** — 從飲料變成兩人的「暗號」
- **便當** — 每天的關心，不需要言語
- **螢幕上的程式碼** — 另一種情書
- **皺巴巴的制服 vs 整齊的制服** — 兩人的反差
- **書包上的扭蛋** — 亭瑄的個性標誌

### 聲音
- 鍵盤敲擊的聲音（兩人一起寫程式的日常 BGM）
- 亭瑄哼歌的聲音（她畫圖時的習慣）
- 「叮——」程式成功編譯的提示音
- 二弘小聲說「做得好」
