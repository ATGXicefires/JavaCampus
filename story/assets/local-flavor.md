# 臺南 / 成大附工 在地元素

## 真實地點

### 國華街商圈
- **用途：** 放學後的散步路線，兩人的固定外食區
- **出場：** Ch2 起作為日常場景
- **細節：**
  - 鱔魚意麵——二弘帶亭瑄吃「臺南人才知道的店」，亭瑄第一次吃被嚇到但意外好吃
  - 水仙宮市場的木瓜牛奶——兩人的代表飲料
  - 永樂市場的春捲
  - 固定去的飲料店，老闆娘已經會自動出兩杯：「小弟又帶女朋友來啦？」二弘：「不是女朋友。」老闆娘：「喔好好好。」（完全不信）

### 赤崁樓 / 孔廟周邊
- **用途：** 假日討論專題的場所
- **出場：** Ch4 假日趕專題
- **細節：**
  - 孔廟旁邊的咖啡店安靜又有 Wi-Fi
  - 亭瑄在赤崁樓前拍照硬拉二弘入鏡（二弘的表情像在做數學題）

### 安平 / 漁光橋
- **用途：** 關鍵浪漫場景
- **出場：** 可用在 Ch4 或 Ch11 的重要時刻；Ch10 的大綱草案用在漁光橋那一場
- **細節：**
  - 安平的夕陽是天然的告白背景
  - 漁光橋上看夕陽——風很大，頭髮會被吹亂

### 花園夜市 / 大東夜市
- **用途：** 被同學約去夜市的群體場景
- **出場：** Ch4 校慶前後
- **細節：**
  - 臺南夜市的輪替制（花園四六日、大東一二五）是在地常識
  - 人很多、很吵、走著走著手就碰到了
  - 二弘被強迫吃各種東西（他對吃完全沒意見，但亭瑄堅持要他嘗每一攤）

### 臺南火車站 / T-Bike 站
- **用途：** 日常通勤場景
- **細節：**
  - 二弘騎 T-Bike 上學
  - 某天發現亭瑄在同一站等車——「偶然」遇到的頻率越來越高

## 在地美食元素

### 木瓜牛奶（核心象徵物）
- 兩人的「代表飲料」，貫穿全篇
- **演進：** 亭瑄自己愛喝 → 二弘第一次買給她（第四章）→ 亭瑄託阿嬤轉交給他（第五章），從此互相買給對方 → 二弘開始知道亭瑄喜歡的甜度 → 不用問就知道要點什麼（第十章：她半糖、他正常甜）
- 象徵關係的進展：從陌生到默契

### 鱔魚意麵
- 二弘帶亭瑄吃的「在地體驗」
- 亭瑄的反應是喜劇素材：「這個⋯⋯是蛇嗎？」二弘：「⋯⋯是鱔魚。」

### 椪餅
- 傳統臺南點心，可在和解場景使用
- 「掰開分著吃」的動作象徵重新分享和連結

### 楊桃湯
- Good End 場景中的飲料
- 在永樂市場買的，清甜微酸

### 便當文化
- 臺南小吃太強，但學校午餐不一定好吃
- 帶便當反而是「認真對待午餐」的表現
- 亭瑄的便當是她媽媽做的（後來她自己也學會做一些菜色）

## 成大附工 / 技職學校元素

### 實習工廠 / 電腦教室
- 資訊科的實習不是焊接——是在電腦教室組裝、配線、設定伺服器
- **喜劇場景：** 亭瑄第一次拆電腦主機差點把 CPU 插反，二弘臉都綠了
- 電腦教室是兩人的「主場景」——大部分的重要場景都在這裡發生

### 專題製作
- 全篇核心驅動力
- 從選題 → 開發 → 中期報告 → 最終發表，每個階段推進劇情
- 專題成品是兩人關係的具體呈現

### 技能檢定
- 丙級是基本門檻，乙級是加分（技優甄審需要）
- **考試氛圍：** 准考證掉了的驚魂、術科時間壓力、考完對答案的緊張
- Ch5 的核心壓力來源

### 升學 vs 就業
- 三年級面臨的人生抉擇
- 二弘：堅定要靠技優甄審上科技大學——目標明確但壓力大
- 亭瑄：還在找方向——知道自己喜歡畫畫但不確定職涯怎麼走
- 兩人對未來的不同態度是衝突來源也是互補點

### 導師時間 / 班會
- 技職學校的導師時間長且密集，老師對學生生活了解多
- **喜劇場景：** 王葉聖老師在導師時間不經意的「炸彈」
  - 「吳二弘，你最近的作業裡有一個變數叫 tx，是什麼意思？」（全班安靜）

### 科展 / 技藝競賽
- 額外壓力源或成就點（可用可不用）
- 二弘被推去參加全國技藝競賽 → 亭瑄第一次獨自顧專題（成長的時刻）

## 臺南的氣候與氛圍

- **秋天（9~11月）：** 還很熱，教室裡冷氣很強。二弘把外套搭在亭瑄椅背上（「我不冷」——其實在發抖）
- **冬天（12~1月）：** 臺南的冬天不太冷但有東北季風。放學路上風很大，走近一點很自然
- **雨季：** 臺南秋天偶爾有大雨。共撐一把傘是經典場景（但二弘的傘是透明塑膠傘，很醜）
