# 常駐笑點設計 (Running Gags)

## 1.「你又用程式說話了」

**模式：** 二弘用程式術語表達情感 → 亭瑄翻譯成人話 → 二弘否認

**隨章節演進：**

| 章節 | 二弘的話 | 亭瑄的翻譯 |
|------|---------|-----------|
| Ch1 | 「這是 Java。」 | 「外星語。」 |
| Ch2 | 「我覺得我們的 pair programming efficiency 有所提升。」 | 「你是說你開始喜歡跟我一起寫程式了？」 |
| Ch3 | 「我的表達有 bug。」 | 「你是在道歉嗎？」 |
| Ch4 | 「你這句話有 type mismatch。」 | 「你在害羞。」 |
| Ch5 | 「你的 return true 分號用錯了。」 | 「你是在說謝謝。」 |
| Ch11 | 「我想跟你繼續 commit 下去。」 | （不需要翻譯了——她懂了） |

**反轉時刻：** 當二弘在感情方面笨得離譜時，亭瑄會反過來吐槽：
> 「學長你連 if-else 都會寫，怎麼連『我想跟你一起吃午餐』這句話都說不出口？」

## 2. 便當攻防戰

**模式：** 亭瑄「不小心」多帶便當 → 二弘「不得已」吃掉 → 全班都知道只有他們裝不知道

**隨章節升級：**

| 階段 | 便當變化 | 二弘的反應 |
|------|---------|-----------|
| Ch2 初期 | 「我媽做太多了」的普通便當 | 「只是不想浪費食物。」 |
| Ch2 中期 | 上面開始出現手繪小圖案 | 看了一眼，什麼都沒說 |
| Ch4 | 口味「剛好」是二弘喜歡的 | 「⋯⋯你怎麼知道我喜歡這個。」「猜的！」 |
| Ch5 | 阿嬤加入戰局——二弘也開始帶阿嬤做的菜 | 兩人互相餵食循環 |
| Ch7（草案） | 寒假暫停，改傳年菜照片 | 回得很慢，每次都只有幾個字 |
| Ch11 高潮 | 便當上用海苔排了心形 | 「⋯⋯這個形狀是——」「你可以假裝沒看到！」 |

**阿成的電競播報版：**
> 「場上情勢膠著！梁亭瑄選手祭出了招牌技——愛心海苔便當！吳二弘選手⋯⋯表面上若無其事但耳朵已經全紅了！觀眾朋友們——」
> 二弘：「你能不能閉嘴。」

## 3. 小芸統計表

**模式：** 小芸追蹤亭瑄提到二弘的次數，且統計工具隨章節升級

| 章節 | 統計方式 | 數據 |
|------|---------|------|
| Ch2 | 手動計數（在備忘錄裡畫正字） | 「今日 17 次。」 |
| Ch3 | Excel 表格 | 「冷戰期間反而變多了欸。」 |
| Ch4 | 自動關鍵詞計數 App | 「本週平均 23.6 次/天。」 |
| Ch5 | 詞頻分析 | 「『學長』出現頻率高於『吃飯』。你把他看得比食物重要。」 |
| Ch7（草案） | 寒假也照樣統計 | 「放寒假以後不減反增。」 |
| Ch11 | Python 爬蟲分析聊天紀錄 | 「本學年共 478 次。含情緒分析：正面情感佔 89%。」 |

**固定反應：**
- 亭瑄崩潰但從來沒有否認核心事實
- 小芸每次都面無表情地展示數據

## 4. README.md 情書

**模式：** 二弘所有關心人的行為都包裝成技術文件格式

| 章節 | 形式 | 內容 |
|------|------|------|
| Ch3 | 段考筆記.zip + README.md | 「如果看不懂可以問我。時間不限。」 |
| Ch5 | 紙條上的 Java 語法 | `return true;`（有 bug 的版本更有溫度） |
| Ch6 聖誕卡 | commit message 風格 | 「感謝你這學期的 contribution」 |
| Ch9（草案） | 亭瑄傳的加油訊息 | 程式碼還是有一個 bug（她寫給他的版本） |
| Ch11 告白 | 程式裡的 Easter egg | 「我想跟你繼續 commit 下去」 |
| Ch11 Good End | txt 檔回覆 | `true // 但我不確定你會不會後悔` |

**設計邏輯：** 二弘在「技術文件」的框架裡反而能說出最真實的話——因為那是他最熟悉的語言。

## 5. 阿嬤連鎖反應

**模式：** 阿嬤從蛛絲馬跡判斷出孫子的變化

| 階段 | 阿嬤觀察到的 | 阿嬤的行動 |
|------|-------------|-----------|
| Ch2 | 「阿弘最近回來都笑笑的」 | 開始多做菜 |
| Ch4 | 「阿弘說他有『專題夥伴』」 | 做了二弘喜歡的菜要他帶去學校分享 |
| Ch5 | 亭瑄登門送木瓜牛奶 | 「妹妹仔你就是讓阮孫會笑的人喔？」 |
| Ch7（草案） | 阿弘過年一直在看手機 | 問起那個做便當的同學 |
| Ch12 | 偷偷跑來看專題發表 | 在最後一排紅了眼眶 |

**殺招場景（第十二章 True End 限定）：**
> 畢業之後，亭瑄第一次正式拜訪阿嬤的小吃店。
> 阿嬤端出一碗免費的湯：「以後常常來喔。」
> 二弘整個人僵在旁邊。

## 6. 阿成的電競播報（補充 Gag）

雖然不是獨立的 running gag，但阿成每次看到二弘和亭瑄的互動都會用電競主播語氣播報，形成系列：

> 「OH！選手吳二弘使用了『沉默三秒後小聲說謝謝』！超絕技！觀眾席一片歡呼！」

> 「完了完了——梁亭瑄選手使用了禁招『虎牙微笑』，吳二弘選手直接紅屏！系統疑似過熱！」

> 「等等等等——兩位選手目前的物理距離已經小於 15 公分！這在競技規則上是否合法？裁判呢？裁判人呢？」
